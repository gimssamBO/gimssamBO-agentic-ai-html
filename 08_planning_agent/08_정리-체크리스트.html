정리 & 체크리스트

8강에서 배운 것

8강에서는 큰 목표를 다루는 Planning Agent와, 현업 프레임워크 LangChain을 처음 도입했습니다.

  • Plan-and-Execute: 큰 목표는 ① 계획 세우고 → ② 실행. ReAct(즉흥형)와 대비.
  • 구조화 출력: Pydantic 클래스 + with_structured_output으로 답을 객체로 받기(3강 JSON의 발전형).
  • create_agent: 7강의 while 루프를 LangChain이 한 줄로 대신해 줌.
  • 계획 검증·재계획: 계획도 틀릴 수 있어 검증하고, 실패하면 피드백 주고 다시 짠다.

한눈에 보는 핵심 코드

from pydantic import BaseModel, Field
from langchain_core.tools import tool
from langchain.agents import create_agent
from common import get_chat, DATA

llm = get_chat(provider="openai")

# (1) Planner — 구조화 출력으로 목표 분해
class Plan(BaseModel):
    goal: str = Field(description="원래 목표")
    steps: list[str] = Field(description="순서대로 실행할 하위 작업(4~7개)")

plan = llm.with_structured_output(Plan).invoke("가을 패딩 출시를 분해하라")
print(plan.steps)                          # ['시장조사', '콘셉트확정', ...]

# (2) Executor — create_agent로 ReAct 에이전트 한 줄
@tool
def list_tasks(status: str = "전체") -> str:
    """프로젝트 작업을 상태별로 조회한다."""
    ...

agent = create_agent(llm, tools=[list_tasks], system_prompt="너는 PM이다 ...")
result = agent.invoke({"messages": [{"role": "user", "content": "다음 할 일 추천"}]})
print(result["messages"][-1].content)

8강부터 LangChain 세계로 들어왔습니다. 이후 강의는 대부분 이 라이브러리들을 씁니다.

raw SDK → LangChain 대응표

7강까지의 raw SDK와 8강부터의 LangChain을 비교하면 이해가 쉽습니다.

하는 일 raw SDK (1~7강) LangChain (8강~)
모델 가져오기 get_genai_client() get_chat(provider="openai")
도구 만들기 평범한 함수 @tool 데코레이터
에이전트 while 루프 직접 create_agent(...) 한 줄
구조화 출력 response_mime_type + json.loads with_structured_output(Pydantic)
호출 generate_content(...) agent.invoke({"messages": [...]})

원리는 같고, 표현만 더 간결해졌습니다.

체크리스트

  • [ ] Plan-and-Execute가 ReAct와 어떻게 다른지 설명할 수 있다.
  • [ ] with_structured_output으로 계획을 Pydantic 객체로 받을 수 있다.
  • [ ] @tool과 create_agent로 LangChain 에이전트를 만들 수 있다.
  • [ ] agent.invoke({"messages": [...]}) 입출력 형식을 안다.
  • [ ] 계획을 검증하고 실패 시 재계획하는 흐름을 구현했다.

한 줄 핵심

큰 목표는 계획부터 세운다. LangChain의 with_structured_output(계획)과 create_agent(실행)로, 7강에서 손으로 짜던 걸 한 줄씩 자동화한다.
