2. Plan 스키마 정의 (04번 복습)

목표 분해 결과의 "형태"를 Pydantic 클래스로 선언합니다.

class Plan(BaseModel):
    """목표를 실행 가능한 하위 작업으로 분해한 결과(원하는 출력 형태를 클래스로 선언)."""
    goal: str = Field(description="원래 목표")
    steps: list[str] = Field(description="순서대로 실행할 하위 작업 목록(4~7개)")

goal(목표 문자열)과 steps(단계 리스트)를 가진 구조입니다.

3. make_plan — 목표를 분해하는 함수

with_structured_output(Plan)으로 LLM 답을 Plan 객체로 받습니다.

def make_plan(goal: str) -> Plan:
    """목표 문자열을 받아 Plan(goal, steps) 구조로 분해해 돌려준다."""
    # with_structured_output(Plan): LLM 응답을 Plan 스키마(JSON)에 맞춰 강제로 받아낸다
    planner = llm.with_structured_output(Plan)
    prompt = (
        "너는 승승장구몰의 프로젝트 매니저다. 다음 목표를 실행 순서대로 "
        f"4~7개의 구체적 하위 작업으로 분해하라.\n목표: {goal}"
    )
    return planner.invoke(prompt)

planner.invoke(prompt)의 결과는 Plan 객체입니다. dict가 아니라서 .goal, .steps로 바로 접근할 수 있죠.

4. 실행 — 목표를 분해해 보기

plan = make_plan("승승장구몰 신상품 '가을 패딩' 출시")
print("목표:", plan.goal)
for i, step in enumerate(plan.steps, start=1):
    print(f"  {i}. {step}")

예상 출력

목표: 승승장구몰 신상품 '가을 패딩' 출시
  1. 타깃 고객과 경쟁 패딩 제품 시장조사
  2. 상품 콘셉트와 가격 정책 확정
  3. 상세페이지 기획·디자인
  4. 초기 재고 발주 및 입고
  5. 사전예약 이벤트/마케팅 캠페인 실행
  6. 출시 후 성과 리포트 작성

큰 목표 한 줄이 실행 가능한 6단계로 분해됐습니다. plan.steps가 리스트임이 보장되니 for로 안심하고 반복할 수 있죠(04번).

5. 무엇을 했나

  • LangChain 모델(get_chat)을 가져왔습니다.
  • Pydantic으로 Plan 스키마를 선언했습니다.
  • with_structured_output(Plan)으로 목표를 구조화된 단계 목록으로 받았습니다.

이게 Plan-and-Execute의 ①계획(Plan) 부분입니다. 다음 절에서 ②실행(Execute) 부분 — 진행상황을 보며 다음 할 일을 제안하는 에이전트 — 를 만듭니다.

핵심 정리

  • 8강 설치: pip install langchain langchain-openai langchain-google-genai langgraph pydantic.
  • get_chat은 LangChain 모델(ChatOpenAI, ChatGoogleGenerativeAI)을 준다(raw SDK와 다름).
  • with_structured_output(Plan)으로 목표를 Plan 객체(goal + steps)로 받는다.
  • plan.steps가 리스트임이 보장되어 바로 반복할 수 있다.
  • 다음 절에서 create_agent로 실행 에이전트를 만듭니다.
