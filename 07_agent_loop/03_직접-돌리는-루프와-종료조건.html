직접 돌리는 루프와 종료 조건

한 줄 요약

Agent Loop는 5강의 "결정→실행→전달"을 while로 여러 번 반복하는 것입니다. 단, 반복에는 종료 조건이 필수입니다 — (1) 모델이 더 이상 도구를 안 부를 때(정상 종료), (2) 최대 반복 횟수(max_steps, 안전장치) 도달.

1. 루프의 뼈대

5강에서 "모델은 결정, 실행은 우리"라고 했습니다. Agent Loop은 그 한 스텝을 while로 감싼 것뿐입니다.

while True:
    resp = 모델_호출(대화기록 + 도구목록)
    if resp.function_calls:              # 모델이 도구를 부르려 한다 (Action)
        결과 = 도구_실행(...)             # 우리가 실행 (Observation)
        대화기록에 [모델의 호출] + [결과] 추가   # 관찰을 되돌려줌
        continue                         # 다음 스텝으로
    else:                                # 더 부를 도구가 없다 → 최종 답
        print(resp.text)
        break

매 바퀴마다 모델은 "도구를 더 부를지" 아니면 "이제 답할지"를 정합니다. 도구를 부르면 실행해서 결과를 되돌리고, 안 부르면 그게 최종 답입니다.

2. 종료 조건이 왜 필요한가

while True는 무한 루프의 위험이 있습니다. 만약 모델이 계속 도구만 부르면? 영원히 안 끝나고 토큰(비용)을 끝없이 태웁니다. 그래서 종료 조건을 둘 둡니다.

종료 조건 의미 종류
모델이 도구를 안 부름 "이제 답할 수 있다"고 판단 정상 종료
최대 반복 횟수 도달 max_steps에 도달 안전장치

3. 종료 조건 ① — 정상 종료

모델이 function_calls를 비워서 돌려주면, "더 부를 도구가 없다 = 이제 답할 수 있다"는 뜻입니다. 그게 최종 답입니다.

if not resp.function_calls:        # 도구를 안 부름
    print("최종 답변:", resp.text)  # 이게 답!
    return resp.text

예를 들어 재고(3개)와 기준(30개)을 둘 다 확인한 뒤, 모델은 더 이상 도구를 부르지 않고 "재주문이 필요합니다"라고 답합니다. 그게 정상 종료죠.

4. 종료 조건 ② — max_steps 안전장치

가장 중요한 안전장치입니다. for step in range(1, max_steps + 1)로 반복 횟수에 상한을 둡니다.

def run_agent(question: str, max_steps: int = 6):
    ...
    for step in range(1, max_steps + 1):   # 최대 max_steps 번만 반복
        resp = 모델_호출(...)
        if not resp.function_calls:
            return resp.text               # 정상 종료
        # ... 도구 실행 ...

    print("[종료] 최대 스텝 도달 — 안전장치 작동")   # max_steps 초과
    return None

max_steps=6이면 아무리 꼬여도 6번 안에 멈춥니다. 모델이 버그나 혼란으로 같은 도구를 무한히 부르려 해도, 이 상한이 비용 폭탄을 막아 줍니다.

실무에서 max_steps(보통 5~10)는 반드시 둡니다. 이건 선택이 아니라 필수입니다. "혹시 모를 무한 루프"를 막는 마지막 방어선이거든요. (더 정교한 반복 방지는 06번에서 배웁니다.)

5. max_steps는 몇으로?

  • 너무 작으면(예: 1~2): 정상적인 다단계 작업도 끝나기 전에 잘립니다.
  • 너무 크면(예: 100): 사고가 나도 한참 토큰을 태운 뒤에야 멈춥니다.
  • 적당히(5~10): 대부분의 작업은 몇 스텝이면 끝나므로, 이 정도면 정상 작업은 통과시키고 사고는 막습니다.

작업의 성격에 맞게 정하면 됩니다. 재고 확인 같은 2~3스텝 작업엔 6 정도가 넉넉합니다.

핵심 정리

  • Agent Loop = 5강의 "결정→실행→전달"을 while(또는 for)로 반복.
  • 종료 조건 둘: 모델이 도구를 안 부름(정상) + max_steps 도달(안전장치).
  • max_steps는 무한 루프·비용 폭탄을 막는 필수 안전장치.
