문제 1 — 검색어 생성 과정 관찰

code/ch09_search.py의 질문 q를 "무선 이어버드 시장의 최근 경쟁사 프로모션을 3가지 조사해줘."로 바꾸고, stream 루프 안에서 각 메시지의 tool_calls를 출력하도록 한 줄을 추가하세요.

  • 기대 결과: 에이전트가 검색 도구에 넘긴 실제 검색어가 콘솔에 찍히고, 그 결과를 한국어 3줄로 요약한 최종 답이 출력되면 성공.
해답 보기 
import sys, pathlib
sys.path.append(str(pathlib.Path(__file__).resolve().parent))
from langchain.agents import create_agent
from langchain_community.tools import DuckDuckGoSearchResults
from common import get_chat

llm = get_chat(provider="gemini")
search = DuckDuckGoSearchResults()
agent = create_agent(llm, tools=[search],
                     system_prompt="너는 승승장구몰의 시장조사 담당자다. 필요하면 검색해 한국어로 요약하라.")

q = "무선 이어버드 시장의 최근 경쟁사 프로모션을 3가지 조사해줘."

try:
    for step in agent.stream({"messages": [{"role": "user", "content": q}]}, stream_mode="values"):
        msg = step["messages"][-1]
        # LLM이 만든 검색어(도구 호출)를 출력
        if getattr(msg, "tool_calls", None):
            for tc in msg.tool_calls:
                print("🔎 LLM이 만든 검색어:", tc["args"])
        msg.pretty_print()
except Exception as e:
    print("검색 중 오류:", e)
**예상 출력** 
🔎 LLM이 만든 검색어: {'query': '무선 이어버드 경쟁사 프로모션 2026'}
...
================================== Ai Message ==================================
경쟁사 프로모션 3가지:
1) A사 - 신제품 출시 기념 20% 할인
2) B사 - 구형 모델 재고 정리 세일
3) C사 - 멤버십 가입 시 케이스 증정
**해설**: `msg.tool_calls`에는 LLM이 검색 도구에 넘긴 인자(`{'query': ...}`)가 들어 있습니다. 이걸 출력하면 "LLM이 내 질문을 어떤 검색어로 바꿨는지"를 직접 볼 수 있습니다. 에이전트의 속을 들여다보는 디버깅 기법이죠.

문제 2 — 검색 결과 + 파일 저장

code/ch09_search.py에 최종 요약 답을 data/research_note.md에 타임스탬프와 함께 append 저장하는 코드를 추가하세요.

  • from datetime import datetime 사용
  • 기대 결과: 실행 후 data/research_note.md에 실행 시각과 검색 요약이 누적 기록되면 성공.
해답 보기 
import sys, pathlib
from datetime import datetime
sys.path.append(str(pathlib.Path(__file__).resolve().parent))
from langchain.agents import create_agent
from langchain_community.tools import DuckDuckGoSearchResults
from common import get_chat, DATA

llm = get_chat(provider="gemini")
search = DuckDuckGoSearchResults()
agent = create_agent(llm, tools=[search],
                     system_prompt="너는 승승장구몰의 시장조사 담당자다. 필요하면 검색해 한국어로 요약하라.")

q = "요즘 인기 있는 무선 이어버드 트렌드를 3가지로 요약해줘."

try:
    result = agent.invoke({"messages": [{"role": "user", "content": q}]})
    answer = result["messages"][-1].content
    print(answer)

    # 타임스탬프와 함께 append 저장
    note_path = DATA / "research_note.md"
    stamp = datetime.now().strftime("%Y-%m-%d %H:%M")     # (현재 시각 문자열)
    with open(note_path, "a", encoding="utf-8") as f:     # "a" = append 모드
        f.write(f"\n## [{stamp}] {q}\n\n{answer}\n")
    print(f"\n저장 완료: {note_path}")
except Exception as e:
    print("검색 중 오류:", e)
**예상 출력** 
무선 이어버드 트렌드 3가지: ...
저장 완료: .../data/research_note.md
그리고 `data/research_note.md` 파일 내용: 
## [2026-06-07 14:30] 요즘 인기 있는 무선 이어버드 트렌드를 3가지로 요약해줘.

무선 이어버드 트렌드 3가지:
1) ANC 성능 경쟁 ...
**해설**: `open(..., "a")`의 `"a"`는 **append(추가)** 모드로, 기존 내용을 지우지 않고 **뒤에 이어 씁니다.** 그래서 실행할 때마다 조사 결과가 **누적**됩니다. 타임스탬프(`datetime.now()`)를 붙이면 "언제 조사한 내용인지" 추적할 수 있죠. 이렇게 검색 에이전트의 결과를 파일로 남기면, 22강(리서치 에이전트)에서 보는 "자동 리포트 생성"의 기초가 됩니다.

정리

  • 문제 1로 에이전트가 만든 검색어를 관찰하는 디버깅을 익혔습니다.
  • 문제 2로 검색 결과를 파일에 누적 저장하는 법을 배웠습니다(→ 22강 리포트).
