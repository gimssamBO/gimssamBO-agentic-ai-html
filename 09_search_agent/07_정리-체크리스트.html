정리 & 체크리스트

9강에서 배운 것

9강에서는 LLM에게 웹 검색이라는 눈을 달아 최신 정보로 답하게 만들었습니다.

  • 지식 컷오프: LLM은 학습 시점 이후를 모른다 — 최신 정보에 약하고 환각이 생긴다.
  • 검색 에이전트: LLM이 스스로 검색어를 만들고, 검색하고, 결과를 요약한다.
  • DuckDuckGoSearchResults: 무료·키 불필요한 LangChain 기본 도구.
  • 신뢰성 검증: 검색 결과는 틀릴 수 있어 "불충분하면 확인 필요" + 교차확인.
  • 네트워크 대응: 지수 백오프 재시도 + 폴백으로 죽지 않게.

한눈에 보는 핵심 코드

from langchain.agents import create_agent
from langchain_community.tools import DuckDuckGoSearchResults
from common import get_chat

llm = get_chat(provider="gemini")
search = DuckDuckGoSearchResults()              # 그 자체로 도구

agent = create_agent(llm, tools=[search],
                     system_prompt="너는 시장조사 담당자다. 필요하면 검색해 한국어로 요약하라.")

# 과정 관찰 + 오류 대비
try:
    for step in agent.stream({"messages": [{"role": "user", "content": q}]},
                             stream_mode="values"):
        step["messages"][-1].pretty_print()
except Exception as e:
    print("검색 오류:", e)

체크리스트

  • [ ] LLM의 지식 컷오프와 환각 문제를 설명할 수 있다.
  • [ ] DuckDuckGoSearchResults를 도구로 에이전트에 연결했다.
  • [ ] stream으로 검색어 생성·검색·요약 과정을 관찰했다.
  • [ ] 검색 결과를 "불충분하면 확인 필요"로 신중히 요약하고 교차확인했다.
  • [ ] 네트워크 오류에 지수 백오프 재시도 + 폴백을 적용했다.

한 줄 핵심

검색 도구로 LLM의 지식 컷오프를 보강한다. 단, 검색은 재검증이 필수이고, 네트워크 실패에 대비해 재시도·폴백을 둔다.

다음 강 예고

10강에서는 Code Execution Agent를 만듭니다. LLM은 계산기가 아니라서 정확한 계산·집계가 약합니다(4강 복습). 그래서 LLM이 pandas 코드를 생성하고, 우리가 그 코드를 실행해 정확한 결과를 얻는 방식을 배웁니다. "계산은 코드에게, 판단은 LLM에게" 맡기는 거죠. 코드 실행의 보안 문제도 함께 다룹니다.
