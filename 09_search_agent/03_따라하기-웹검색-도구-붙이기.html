따라하기 — 웹 검색 도구 붙이기

목표

DuckDuckGoSearchResults 검색 도구를 create_agent에 붙여 검색 에이전트를 만듭니다. 실제 파일은 code/ch09_search.py 입니다.

0. 실습 준비 (설치)

검색 라이브러리를 설치합니다. DuckDuckGoSearchResults는 내부적으로 ddgs 패키지를 씁니다.

conda activate agentic

# 9강에서 처음 쓰는 라이브러리
#  - langchain-community : DuckDuckGoSearchResults 등 커뮤니티 도구 모음
#  - ddgs                : DuckDuckGo 검색 실제 엔진 (키 불필요)
pip install langchain-community ddgs

설치하지 않으면 from langchain_community.tools import DuckDuckGoSearchResults 사용 시 에러가 납니다. 또한 이 실습은 인터넷 연결이 필요합니다.

1. 공통 시작부 + 검색 도구

DuckDuckGoSearchResults는 그 자체로 LangChain 도구이므로, 별도 @tool 작성 없이 바로 씁니다.

# 실행: python code/ch09_search.py
import sys, pathlib
sys.path.append(str(pathlib.Path(__file__).resolve().parent))
from langchain.agents import create_agent
# DuckDuckGoSearchResults = 무료·키 불필요 웹 검색 도구(내부적으로 ddgs 패키지 사용)
from langchain_community.tools import DuckDuckGoSearchResults
from common import get_chat

llm = get_chat(provider="gemini")
# DuckDuckGoSearchResults 는 그 자체로 LangChain 도구라 @tool 작성 없이 바로 쓴다
search = DuckDuckGoSearchResults()

8강의 @tool로 함수를 감싸던 것과 비교해 보세요. 이미 LangChain 도구로 만들어진 것(DuckDuckGoSearchResults)은 그대로 가져다 쓰면 됩니다. 실무에서는 이런 기성 도구를 조합해 쓰는 일이 많습니다.

2. 검색 도구 단독 테스트

에이전트에 붙이기 전에, 도구가 잘 도는지 직접 호출해 봅니다(5강에서 배운 디버깅 습관).

print(search.invoke("무선 이어버드 트렌드"))

예상 출력

[snippet: 2026년 무선 이어버드는 ANC(노이즈 캔슬링) 성능 강화가 ...,
 title: 올해 주목할 이어버드 트렌드, link: https://...]
[snippet: 멀티포인트 연결과 공간음향이 ..., title: ..., link: ...]

제목·스니펫(요약)·링크가 담긴 검색 결과가 나옵니다. 이걸 LLM이 읽고 요약하게 됩니다.

3. 검색 에이전트 구성

create_agent에 검색 도구를 연결합니다(8강과 똑같은 방식).

search_agent = create_agent(
    llm,
    tools=[search],   # 검색 도구 하나
    system_prompt="너는 승승장구몰의 시장조사 담당자다. 필요하면 검색 도구로 최신 정보를 찾아 한국어로 요약하라.",
)

8강의 planning_agent와 형태가 똑같죠? create_agent(llm, tools=[...], system_prompt=...). 도구만 검색 도구로 바뀌었을 뿐입니다. 한 번 익힌 패턴이 계속 재사용됩니다.

시스템 프롬프트에 "필요하면 검색 도구로 최신 정보를 찾아" 라고 적은 게 포인트입니다. 이게 에이전트에게 "최신 정보가 필요한 질문엔 검색을 써라"라고 알려 주는 거죠.

4. 간단 실행

q = "요즘 인기 있는 무선 이어버드 트렌드를 조사해서 핵심만 3가지로 요약해줘."
result = search_agent.invoke({"messages": [{"role": "user", "content": q}]})
print(result["messages"][-1].content)

예상 출력

무선 이어버드 트렌드 핵심 3가지:
1) 능동 소음 차단(ANC) 성능 경쟁 심화
2) 멀티포인트 동시 연결 등 편의 기능 보편화
3) 공간음향·저지연 게이밍 모드 확대

에이전트가 스스로 검색어를 만들고, 검색하고, 결과를 읽어 3가지로 요약했습니다. 우리는 검색어도, 요약 방법도 지정하지 않았죠.

실제 결과는 시점·네트워크 상황에 따라 달라집니다. 핵심은 "에이전트가 스스로 검색하고 답을 구성한다" 는 흐름입니다.

핵심 정리

  • 9강 설치: pip install langchain-community ddgs.
  • DuckDuckGoSearchResults는 그 자체로 도구라 @tool 없이 바로 쓴다.
  • 에이전트에 붙이기 전 search.invoke(...)로 단독 테스트한다.
  • create_agent(llm, tools=[search], ...) — 8강과 똑같은 패턴, 도구만 교체.
