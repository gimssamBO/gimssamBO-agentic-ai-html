검색 결과 신뢰성과 재검증

한 줄 요약

검색은 틀린 정보·낚시성 글도 함께 끌고 옵니다. 그대로 요약하면 환각을 사실처럼 전달하게 됩니다. "출처가 불충분하면 '확인 필요'라고 답하라" 는 지시로 신중히 요약하고, 핵심 주장을 다른 검색어로 재검색해 교차확인합니다.

1. "검색했으니 사실"이 아니다

검색 도구를 붙였다고 답이 항상 맞는 건 아닙니다. 검색 결과에는 이런 것들이 섞여 있습니다.

  • 광고·홍보성 글 (특정 제품을 띄우려는)
  • 오래된 기사 (몇 년 전 정보를 최신처럼)
  • 낚시성·잘못된 정보 (클릭 유도용 과장)

LLM이 이런 걸 그대로 믿고 요약하면, 환각을 "검색으로 확인된 사실"인 양 전달합니다. 오히려 더 위험할 수 있죠. "검색해 봤더니"라는 말이 신뢰를 주니까요.

비유: 인터넷에서 본 글을 무조건 믿으면 안 되는 것과 같습니다. 출처가 어디인지, 여러 곳에서 같은 말을 하는지 따져 봐야죠. 에이전트도 그래야 합니다.

2. 방어 ① — "모르면 모른다고 답하라"

첫 번째 방어선은 3강에서 배운 그 원칙입니다 — "근거가 불충분하면 지어내지 말고 '확인 필요'라고 답하라." (실습 파일: code/ch09_search_safe.py)

def summarize_with_caution(question: str, evidence: str) -> str:
    """검색 근거를 받아, 출처가 불충분하면 '확인 필요'라고 답하도록 신중히 요약한다."""
    answer_llm = get_chat(provider="openai", temperature=0.3)
    prompt = (
        "너는 승승장구몰의 시장조사 담당자다. 아래 검색 결과만 근거로 질문에 답하라.\n"
        "[규칙] 검색 결과에서 근거를 찾을 수 없거나 출처가 불충분하면, 지어내지 말고 "
        "반드시 '확인 필요'라고 답하라. 확실한 부분만 한국어로 간결히 요약하라.\n\n"
        f"질문: {question}\n\n검색 결과:\n{evidence}"
    )
    return answer_llm.invoke(prompt).content

핵심은 "검색 결과만 근거로" + "불충분하면 확인 필요" 입니다. LLM이 검색 결과 밖의 지식(자기 환각)으로 빈칸을 채우지 못하게 막는 거죠.

3. 방어 ② — 교차확인(cross-check)

한 번의 검색은 한쪽 출처에 치우칠 수 있습니다. 그래서 핵심 주장을 다른 검색어로 다시 찾아 같은 내용이 반복되는지 봅니다. 서로 다른 출처가 같은 말을 하면 신뢰도가 올라갑니다.

def cross_check(claim: str) -> str:
    """핵심 주장 1개를 다른 검색어로 재검색해 교차확인 결과를 돌려준다."""
    requery = f"{claim} 사실 확인 후기 비교"      # 다른 각도의 검색어
    evidence2 = safe_search(requery)
    verify_llm = get_chat(provider="openai", temperature=0.3)
    prompt = (
        "아래 두 번째 검색 결과가 다음 주장을 뒷받침하는지 판단하라.\n"
        "뒷받침되면 '교차확인됨', 근거가 약하거나 상반되면 '확인 필요'로 시작해 "
        "한 문장으로 한국어로 답하라.\n\n"
        f"주장: {claim}\n\n두 번째 검색 결과:\n{evidence2}"
    )
    return verify_llm.invoke(prompt).content

claim(첫 검색에서 나온 주장)을 다른 키워드로 재검색해, 두 번째 결과가 그 주장을 뒷받침하는지 LLM이 판단합니다.

비유: 기자가 기사를 쓸 때 두 개 이상의 독립된 취재원에게 확인하는 것과 같습니다. 한 사람 말만 듣고 쓰면 오보가 나죠. 서로 다른 출처가 같은 말을 해야 믿을 수 있습니다.

4. 전체 흐름 — 검색 → 신중 요약 → 교차확인

question = "요즘 인기 있는 무선 이어버드 트렌드를 핵심만 알려줘."

# STEP 1: 1차 검색
evidence = safe_search("무선 이어버드 최신 트렌드 2026")

# STEP 2: 신뢰성 강조 요약(불충분하면 '확인 필요')
summary = summarize_with_caution(question, evidence)
print(summary)

# STEP 3~4: 핵심 주장 1개를 골라 교차확인
claim = "노이즈 캔슬링(ANC) 탑재가 무선 이어버드의 핵심 트렌드다."
verdict = cross_check(claim)
print("교차확인 결과:", verdict)

예상 출력

[요약] ANC 성능 강화와 멀티포인트 연결이 주요 트렌드로 보입니다.
       (가격대별 차이는 출처가 불충분하여 확인 필요)
[교차확인] 교차확인됨 — 여러 출처가 ANC를 핵심 트렌드로 언급합니다.

요약에서 불확실한 부분은 "확인 필요" 로 표시했고, 핵심 주장은 재검색으로 교차확인했습니다. 이렇게 하면 환각을 사실처럼 전달하는 사고를 크게 줄입니다.

5. 실무의 황금률

"검색은 재검증이 필수다."

검색 결과를 그대로 믿지 말고:

  1. 모르면 모른다고 답하게 하고(불충분하면 '확인 필요'),
  2. 다른 출처로 교차확인하고,
  3. 출처 링크를 함께 보여 줘 사람이 최종 검증하게 합니다.

특히 시장조사·의사결정처럼 중요한 판단에 쓰는 정보는 반드시 사람이 출처를 확인해야 합니다. 에이전트는 "1차 조사"를 빠르게 해 주는 도구이지, 최종 판단자가 아닙니다.

핵심 정리

  • 검색 결과에는 광고·오래된 글·잘못된 정보가 섞여 있다.
  • 방어 ①: "불충분하면 '확인 필요'" 지시로 신중히 요약(환각 차단).
  • 방어 ②: 핵심 주장을 다른 검색어로 교차확인(서로 다른 출처의 동의).
  • 황금률: "검색은 재검증이 필수", 중요한 정보는 사람이 출처 확인.
  • 다음 절에서 네트워크 오류에 견디는 재시도를 배웁니다.
