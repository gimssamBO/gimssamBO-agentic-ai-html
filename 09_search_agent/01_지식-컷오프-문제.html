지식 컷오프 문제

한 줄 요약

LLM은 학습한 시점까지의 지식만 갖습니다. 그 이후의 신제품·최신 유행·어제 뉴스는 모르고, 모르면서 아는 척하는 환각도 생깁니다. 이 한계를 지식 컷오프(knowledge cutoff) 라고 합니다.

1. LLM은 '특정 시점에 멈춰 있다'

LLM은 방대한 텍스트로 학습되지만, 그 학습은 어느 시점에 끝납니다. 그 시점 이후의 정보는 학습에 포함되지 않았으므로 모릅니다.

시간을 축으로 보면, 컷오프 시점을 기준으로 둘로 나뉩니다.

  • 컷오프 이전: 학습된 지식 → 알고 있음
  • 컷오프 이후: 학습에 없던 정보 → 모름

예를 들어 이런 질문은 컷오프 이후의 정보라 답하기 어렵습니다.

  • "올해 가장 인기 있는 무선 이어버드는?"
  • "어제 발표된 경쟁사 신제품 사양은?"
  • "지난주 환율은 얼마였어?"

2. 8강과 이어지는 문제

8강에서 "가을 패딩 출시" 계획을 세웠는데, 첫 단계가 "시장조사" 였습니다. "요즘 인기 있는 패딩 트렌드는?"을 알려면 오늘의 시장을 알아야 합니다. 그런데 LLM은 학습 시점 이후의 트렌드를 모릅니다.

ask("2026년 무선 이어버드 최신 트렌드 알려줘")
# → "제가 학습한 시점 이후의 정보는 알 수 없습니다 ..." (모름)
# → 또는 그럴듯하게 지어냄 (환각!)

3. 더 위험한 건 환각

"모른다"고 답하면 차라리 낫습니다. 진짜 문제는 LLM이 모르면서 아는 척 지어내는 것입니다(1강 환각 복습).

"2026년 최신 이어버드 트렌드는 'XYZ 노이즈 캔슬링 5.0' 기술이 대세입니다."

이런 답이 그럴듯하게 나오지만, 존재하지 않는 기술일 수 있습니다. 시장조사 보고서에 이런 환각이 들어가면 큰일이죠.

비유: LLM은 몇 년 전 유학을 떠나 소식이 끊긴 친구입니다. 옛날 일은 잘 알지만 "요즘 뭐가 유행해?"라고 물으면 모릅니다. 그런데 모른다고 하기 민망해서 옛날 기억으로 대충 둘러대면, 그게 환각입니다.

4. 해결책 — 검색이라는 '눈'을 달아 준다

해결책은 간단합니다. LLM에게 웹 검색 도구를 쥐여 주는 것입니다. 그러면 모르는 최신 정보를 그때그때 찾아서 답할 수 있습니다.

질문: "최신 이어버드 트렌드?"

  1. LLM: "이건 내 지식 밖이네. 검색해야겠다"
  2. 검색 도구로 웹 검색 → 최신 기사·스니펫 획득
  3. LLM: 검색 결과를 읽고 요약 → 최신 정보 기반 답변!

5강에서 배운 것과 똑같습니다 — 도구를 붙여 LLM의 한계를 넘는다. 다만 이번 도구는 "재고 조회"가 아니라 "웹 검색"일 뿐입니다.

5. 이 강에서 만들 것

무료이고 API 키가 필요 없는 DuckDuckGo 검색 도구를 create_agent에 붙여, 최신 시장 정보를 조사하는 에이전트를 만듭니다.

항목 설명
도구 DuckDuckGoSearchResults (무료, API 키 불필요)
입력 검색어 문자열
출력 제목·스니펫·링크가 담긴 검색 결과
주의 인터넷 연결 필요, 호출 제한 시 일시적 오류 가능

핵심 정리

  • LLM은 학습 시점(컷오프) 이후를 모른다 — 최신 정보에 약하다.
  • 모르면서 지어내는 환각이 더 위험하다.
  • 해결책은 웹 검색 도구를 붙이는 것(5강 도구 원리의 응용).
