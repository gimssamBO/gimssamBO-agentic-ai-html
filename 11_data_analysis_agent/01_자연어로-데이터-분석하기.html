자연어로 데이터 분석하기

한 줄 요약

10강에서는 매출 한 컬럼만 다뤘지만, 현실의 주문 데이터는 취소·환불이 섞이고 이상치가 있습니다. "카테고리별 매출 top3 뽑아줘"라고 한국어로 말하면 알아서 분석해 주는 에이전트를 만듭니다. 핵심은 데이터 함정을 다루는 것입니다.

1. 현실의 데이터는 지저분하다

10강의 데이터(sales_daily.csv)는 date, sales 두 컬럼뿐인 깨끗한 데이터였습니다. 하지만 진짜 주문 데이터(orders.csv)는 훨씬 복잡하고 지저분합니다.

order_id, order_date, customer_id, product_id, product_name,
category, quantity, unit_price, amount, channel, status

그리고 이런 함정들이 숨어 있습니다.

  • 취소·환불 건: status가 '취소'나 '환불'인 주문 — 매출에 넣으면 안 됨
  • 이상치: 누군가 실수로 quantity에 999를 입력
  • 음수 금액: 환불이 음수 amount로 기록되어 합계를 왜곡

분석가가 매번 "취소/환불 빼고, 이상치 거르고, 카테고리로 묶어서…" 코드를 짜는 건 번거롭습니다.

2. 자연어로 분석하는 에이전트

10강의 코드 실행 에이전트를 발전시킵니다. 분석 규칙을 가르쳐, 한국어 질문에 알아서 올바르게 분석하게 합니다.

agent.invoke("배송완료된 주문 기준으로 카테고리별 매출 top3 알려줘.")
# → LLM이 "취소/환불 제외하고 groupby('category')..." 식을 생성
# → 실행 → "1위 가전, 2위 전자기기 ..." 정리

우리는 한국어로 묻고, 에이전트가 데이터 함정을 피해 분석합니다. 진짜 데이터 분석가의 일을 자동화하는 거죠.

비유: 신입 분석가에게 "매출 분석해줘"라고 하면, 그 신입이 회사 규칙("취소/환불은 매출에서 빼")을 모르면 틀린 보고서를 냅니다. 그래서 규칙을 먼저 가르쳐야 합니다. 에이전트도 똑같습니다.

3. 흐름 — 10강과 같지만 데이터가 복잡

질문: "카테고리별 매출 top3"

  1. LLM: 식 생성 (규칙 반영: 취소/환불 제외) — orders[orders.status=='배송완료'].groupby('category')['amount'].sum()...
  2. run_pandas 도구: 실행 — 결과 표 (가전 6855만, 전자기기 4354만, …)
  3. LLM: 한국어 정리 — "1위 가전, 2위 전자기기 …"

10강과 흐름은 같습니다. 차이는 두 가지입니다.

  • 데이터가 복잡: 여러 컬럼, 여러 상태
  • 규칙이 필요: 취소/환불 제외, 이상치 처리

4. 이 강에서 배울 것

목차 내용

데이터는 data/orders.csv(주문)와 data/products.csv(상품)를 씁니다.

핵심 정리

  • 현실의 주문 데이터는 취소·환불·이상치가 섞여 지저분하다.
  • 한국어 질문에 데이터 함정을 피해 분석하는 에이전트를 만든다.
  • 핵심은 분석 규칙(취소/환불 제외 등)을 가르치는 것.
  • 10강 코드 실행의 흐름에 규칙과 복잡한 데이터를 더한 것.
