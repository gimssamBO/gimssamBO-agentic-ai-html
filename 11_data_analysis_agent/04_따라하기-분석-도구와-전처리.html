1. 공통 시작부 + 데이터 로드/전처리

데이터를 로드하면서 전처리도 합니다. 월별 집계를 쉽게 하려고 month 파생 컬럼을 미리 만듭니다.

# 실행: python code/ch11_data_analysis.py
import sys, pathlib
sys.path.append(str(pathlib.Path(__file__).resolve().parent))
import pandas as pd
from langchain_core.tools import tool
from langchain.agents import create_agent
from common import get_chat, DATA

llm = get_chat(provider="gemini")

# 주문·상품 데이터 로드
orders = pd.read_csv(DATA / "orders.csv")
products = pd.read_csv(DATA / "products.csv")

# 전처리: 날짜 타입 변환 + 월(YYYY-MM) 파생 컬럼 추가 → 월별 집계가 쉬워진다
orders["order_date"] = pd.to_datetime(orders["order_date"])
orders["month"] = orders["order_date"].dt.strftime("%Y-%m")

전처리가 두 가지입니다.

  • pd.to_datetime: order_date를 문자열에서 날짜 타입으로 변환 → 날짜 연산이 쉬워짐
  • month 파생 컬럼: 2026-01-15 → 2026-01로 변환 → 월별 그룹화가 쉬워짐

이렇게 미리 손질해 두면, LLM이 월별 분석을 할 때 month 컬럼을 바로 쓸 수 있습니다.

2. run_pandas 도구 — 여러 객체 다루기

10강과 달리 두 개의 DataFrame(orders, products)을 다룹니다. 화이트리스트에 둘 다 넣습니다.

@tool
def run_pandas(expr: str) -> str:
    """미리 로드된 주문 데이터로 pandas 식을 실행해 결과를 문자열로 반환한다.
    사용 가능한 객체:
      - orders : 주문 DataFrame. 컬럼 = order_id, order_date(datetime),
                 month('YYYY-MM'), customer_id, product_id, product_name,
                 category, quantity, unit_price, amount, channel,
                 status('배송완료'/'배송중'/'결제완료'/'취소'/'환불')
      - products : 상품 DataFrame (product_id, product_name, category, price, ...)
      - pd : pandas
    분석 주의사항:
      * 매출(amount) 집계는 보통 status가 '취소','환불'인 건을 제외한다.
      * amount 에 음수(환불 오류)나 quantity=999 같은 이상치가 섞여 있을 수 있다.
    예: "orders[orders['status']=='배송완료'].groupby('category')['amount']
         .sum().sort_values(ascending=False).head(3)"
    """
    allowed = {"orders": orders, "products": products, "pd": pd}  # 화이트리스트
    try:
        result = eval(expr, {"__builtins__": {}}, allowed)
    except Exception as e:
        return f"실행 오류: {e}"
    return str(result)

3. docstring이 매우 상세한 이유

이 도구의 docstring은 10강보다 훨씬 깁니다. 왜일까요?

LLM은 데이터의 구조를 모르기 때문입니다. docstring에:

  • 모든 컬럼명과 의미: LLM이 올바른 컬럼을 쓰게
  • status 값들: '배송완료'/'취소'/'환불' 등 실제 값을 알려 줘야 필터링 가능
  • 분석 주의사항: 함정(이상치·취소/환불)을 알려 줌
  • 사용 예시: 복잡한 식의 형태를 참고

데이터가 복잡할수록 docstring을 상세히 써야 LLM이 올바른 분석을 합니다. 이게 "도구 설명 = 도구 성능"(6강)의 데이터 분석 버전입니다.

4. 도구 단독 테스트

에이전트에 붙이기 전, 직접 호출해 봅니다.

# 카테고리별 매출 top3 (배송완료 기준)
expr = "orders[orders['status']=='배송완료'].groupby('category')['amount'].sum().sort_values(ascending=False).head(3)"
print(run_pandas.invoke({"expr": expr}))

예상 출력

category
가전      68550000
전자기기    43540000
패션의류    23360000
Name: amount, dtype: int64

도구가 잘 돕니다. 이제 이걸 에이전트에 붙여, 자연어로 같은 분석을 하게 만들 차례입니다(다음 절).

핵심 정리

  • 데이터 로드 시 전처리(날짜 변환, month 파생 컬럼)를 미리 한다.
  • run_pandas에 여러 객체(orders, products)를 화이트리스트로 넣는다.
  • docstring에 컬럼·status 값·주의사항·예시를 상세히 적는다(복잡할수록 더).
  • 도구를 단독 테스트해 동작을 확인한다.
  • 다음 절에서 이 도구로 자연어 분석을 합니다.
