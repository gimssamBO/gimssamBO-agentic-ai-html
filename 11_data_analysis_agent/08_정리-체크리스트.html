정리 & 체크리스트

11강에서 배운 것

11강에서는 진짜 주문 데이터를 자연어로 분석하는 에이전트를 만들었습니다.

  • 데이터 함정: 취소/환불, quantity 이상치, 음수 금액 — 분석 전 처리 필수.
  • 규칙 주입: 분석 규칙을 시스템 프롬프트에 명시하면 에이전트가 자동 준수.
  • 데이터 품질 체크: 분석 전 결측·중복·이상치를 pandas로 진단(LLM 없이).
  • 시각화: matplotlib으로 차트를 그려 분석 결과를 전달.

한눈에 보는 핵심 코드

import pandas as pd
from langchain_core.tools import tool
from langchain.agents import create_agent
from common import get_chat, DATA

llm = get_chat(provider="gemini")
orders = pd.read_csv(DATA / "orders.csv")
orders["month"] = pd.to_datetime(orders["order_date"]).dt.strftime("%Y-%m")  # 전처리

@tool
def run_pandas(expr: str) -> str:
    """주문 데이터 분석. orders(컬럼...), products, pd 사용 가능. 매출은 취소/환불 제외."""
    try:
        return str(eval(expr, {"__builtins__": {}}, {"orders": orders, "pd": pd}))
    except Exception as e:
        return f"실행 오류: {e}"

# 규칙을 시스템 프롬프트로
agent = create_agent(llm, tools=[run_pandas],
    system_prompt="너는 데이터 분석가다. 매출 집계 시 취소/환불 제외, 이상치 처리, 한국어 답변.")

체크리스트

  • [ ] 자연어 질문이 어떻게 pandas 코드로 변환·실행되는지 설명할 수 있다.
  • [ ] 데이터 함정(취소/환불·quantity 이상치·음수 amount)을 안다.
  • [ ] 시스템 프롬프트로 분석 규칙을 주입했다.
  • [ ] 분석 전 data_quality_report로 데이터를 진단했다.
  • [ ] matplotlib으로 차트를 그려 파일로 저장했다(한글 폰트 포함).

한 줄 핵심

현실 데이터는 지저분하다. 함정(취소/환불·이상치)을 규칙으로 가르치고, 분석 전 품질을 진단하고, 결과를 차트로 전달한다.
