분석 결과를 차트로 시각화

한 줄 요약

숫자 표만으로는 추세가 잘 안 보입니다. matplotlib으로 월별 매출 꺾은선과 카테고리별 매출 막대그래프를 그려 PNG 파일로 저장합니다. 시각화는 분석의 마지막 "전달" 단계입니다.

0. 실습 준비 (설치)

conda activate agentic

# 11강 시각화에 필요한 라이브러리
#  - matplotlib           : 파이썬 대표 시각화 라이브러리 (꺾은선·막대 그래프)
#  - koreanize-matplotlib : 차트 한글 깨짐을 OS 무관하게 막아 주는 도우미
pip install matplotlib koreanize-matplotlib

이번 시각화는 data/monthly_sales.csv(컬럼: month, 카테고리들, total)를 씁니다.

1. 왜 시각화가 필요한가

분석 결과가 숫자 표로만 나오면, 사람이 한눈에 추세를 파악하기 어렵습니다.

표: 2026-01 7,151,000 / 2026-02 6,890,000 / 2026-03 7,320,000 ...
   → "오르락내리락 하는 것 같은데... 전체적으로는?"  (한눈에 안 보임)

차트: 꺾은선 그래프
   → "아, 2월에 떨어졌다가 다시 회복하는구나!"  (한눈에 보임)

비유: 길 안내를 글로 "북쪽으로 200m, 우회전, 100m..."라고 듣는 것과 지도를 보는 것의 차이입니다. 같은 정보라도 시각화하면 훨씬 빨리 이해됩니다.

2. 한글 폰트 설정 (중요!)

matplotlib은 기본적으로 한글을 네모(□)로 깨뜨립니다. 차트 제목·축에 한글을 쓰려면 폰트를 지정해야 하는데, OS마다 폰트 이름이 달라(맥 AppleGothic, 윈도우 Malgun Gothic, 리눅스 NanumGothic) 직접 분기하면 번거롭습니다. 그래서 koreanize-matplotlib 를 씁니다.

import matplotlib
matplotlib.use("Agg")  # 화면 없는 환경에서도 동작하도록 파일 저장용 백엔드

import matplotlib.pyplot as plt
import koreanize_matplotlib   # 이 import 한 줄이 한글 폰트 설정을 끝낸다
  • matplotlib.use("Agg"): 화면 없이 파일로 저장하는 모드. 서버나 자동화 환경에서 필수.
  • import koreanize_matplotlib: import 하는 것만으로 번들된 나눔고딕을 적용하고 음수 부호 깨짐(axes.unicode_minus)까지 자동으로 잡아 줍니다. 맥·윈도우·리눅스·코랩 어디서나 동일하게 한글이 나오죠. (matplotlib.pyplot을 import 한 다음 줄에 둬야 설정이 적용됩니다.)

OS별로 직접 지정하고 싶다면 plt.rcParams["font.family"] = "Malgun Gothic"(윈도우)처럼 분기를 쓸 수도 있지만, koreanize-matplotlib 한 줄이 그 모든 분기를 대신해 줍니다.

3. 차트 ① — 월별 매출 꺾은선

(실습 파일: sections/11_data_analysis_agent/07_분석결과-차트로-시각화.py)

import pandas as pd
from common import DATA, ROOT

df = pd.read_csv(DATA / "monthly_sales.csv", encoding="utf-8-sig")

# 차트를 저장할 reports 폴더 (없으면 생성)
out_dir = ROOT / "reports"
out_dir.mkdir(exist_ok=True)

# 월별 total 꺾은선
fig1, ax1 = plt.subplots(figsize=(10, 5))
ax1.plot(df["month"], df["total"], marker="o", color="#2563eb")
ax1.set_title("승승장구몰 월별 총매출 추이")
ax1.set_xlabel("월")
ax1.set_ylabel("총매출(원)")
# y축 숫자에 천단위 콤마
ax1.yaxis.set_major_formatter(lambda x, _: f"{int(x):,}")
plt.xticks(rotation=45, ha="right")     # x축 라벨 기울이기
fig1.tight_layout()
fig1.savefig(out_dir / "11_월별총매출_꺾은선.png", dpi=120)   # 파일로 저장!
plt.close(fig1)

핵심 흐름: plt.subplots()로 도화지를 만들고 → ax.plot()으로 선을 그리고 → 제목·축 설정 → savefig()로 파일 저장.

plt.show() 대신 savefig()를 쓰는 게 포인트입니다. 자동화·서버 환경에서는 화면이 없으니, 차트를 파일로 남깁니다.

4. 차트 ② — 카테고리별 매출 막대

# 가장 최근 달의 카테고리별 매출
categories = [c for c in df.columns if c not in ("month", "total")]
last = df.iloc[-1]                          # 마지막 행 (최근 달)
values = [last[c] for c in categories]

fig2, ax2 = plt.subplots(figsize=(10, 5))
ax2.bar(categories, values, color="#16a34a")     # 막대그래프
ax2.set_title(f"{last['month']} 카테고리별 매출")
ax2.set_xlabel("카테고리")
ax2.set_ylabel("매출(원)")
ax2.yaxis.set_major_formatter(lambda x, _: f"{int(x):,}")
plt.xticks(rotation=45, ha="right")
fig2.tight_layout()
fig2.savefig(out_dir / "11_카테고리별매출_막대.png", dpi=120)
plt.close(fig2)

꺾은선과 거의 같은데 ax.plot 대신 ax.bar(막대)를 씁니다. 추이는 꺾은선, 비교는 막대 — 데이터 성격에 맞는 차트 종류를 고르는 게 중요합니다.

5. 어떤 차트를 언제 쓰나

차트 종류 적합한 데이터 예시
꺾은선(line) 시간에 따른 추이 월별 매출 변화
막대(bar) 항목 간 비교 카테고리별 매출
원형(pie) 전체 중 비중 채널별 매출 점유율
산점도(scatter) 두 변수의 관계 가격 vs 판매량

"무엇을 보여 주고 싶은가"에 따라 차트를 고릅니다. 추이를 막대로 그리거나 비교를 꺾은선으로 그리면 오히려 헷갈리죠.

6. 시각화는 분석의 '전달' 단계

분석 과정을 정리하면:

1. 데이터 품질 체크 (06번)  → 데이터를 믿을 수 있나?
2. 분석/집계 (04~05번)      → 무엇을 알아냈나?
3. 시각화 (07번)            → 어떻게 전달하나?  ← 지금

아무리 좋은 분석도 전달이 안 되면 소용없습니다. 경영진은 숫자 표보다 차트 한 장을 더 빨리 이해합니다. 그래서 시각화는 분석의 마지막 마무리이자, 가장 중요한 "전달" 단계입니다. (24강에서 이 차트를 리포트에 넣습니다.)

핵심 정리

  • 11강 시각화 설치: pip install matplotlib koreanize-matplotlib.
  • 한글 깨짐 방지: import koreanize_matplotlib 한 줄(OS 무관, 음수 부호까지 자동).
  • plt.show() 대신 savefig()로 파일 저장(자동화 환경).
  • 추이는 꺾은선, 비교는 막대 — 데이터에 맞는 차트를 고른다.
  • 시각화는 분석의 "전달" 단계 — 차트가 표보다 빨리 이해된다.
