따라하기 — 자연어 질문으로 분석

목표

분석 규칙을 주입한 에이전트로, "카테고리별 매출 top3", "환불 비율", "월별 추이" 같은 질문에 데이터 함정을 피해 답하게 합니다.

1. 규칙을 주입한 에이전트

03번의 시스템 프롬프트로 분석 규칙을 가르칩니다.

SYSTEM = (
    "너는 승승장구몰의 데이터 분석가다. 계산은 반드시 run_pandas 도구로만 하라.\n"
    "규칙:\n"
    "1) 매출(amount) 집계 시 status가 '취소','환불'인 행은 제외한다.\n"
    "2) quantity=999 처럼 비정상적으로 큰 값과 음수 amount는 이상치이므로,\n"
    "   집계 전에 적절히 제외하거나 사용자에게 언급한다.\n"
    "3) 최종 답변은 한국어로 간결하게, 숫자는 천단위 콤마를 붙여 설명한다."
)
agent = create_agent(llm, tools=[run_pandas], system_prompt=SYSTEM)

2. 세 가지 분석 질문

서로 다른 유형의 분석을 던져 봅니다.

questions = [
    "배송완료된 주문 기준으로 카테고리별 매출 top3 알려줘.",   # 그룹화 + 정렬
    "전체 주문 중 환불 건수와 환불 비율(%)은?",              # 비율 계산
    "2026년 월별 매출 추이를 알려줘. (취소/환불 제외)",        # 시계열 집계
]
for q in questions:
    print("Q:", q)
    result = agent.invoke({"messages": [{"role": "user", "content": q}]})
    print("A:", result["messages"][-1].content)
    print()

예상 출력

Q: 배송완료된 주문 기준으로 카테고리별 매출 top3 알려줘.
A: 배송완료 기준 카테고리별 매출 top3는 1위 가전 약 6,855만원,
   2위 전자기기 약 4,354만원, 3위 패션의류 약 2,336만원입니다.

Q: 전체 주문 중 환불 건수와 환불 비율(%)은?
A: 전체 2,400건 중 환불은 79건으로, 환불 비율은 약 3.3%입니다.

Q: 2026년 월별 매출 추이를 알려줘. (취소/환불 제외)
A: 2026-01 ~ 2026-05 동안 월별 매출이 집계되며,
   겨울 세일이 끝난 뒤 완만하게 안정세를 보입니다.

세 질문 모두 에이전트가 적절한 pandas 식을 만들어 답했습니다.

3. 규칙이 작동하는 것 확인

첫 질문("카테고리별 매출 top3")에서 에이전트가 만든 식을 보면:

# 에이전트가 생성한 식 (규칙 반영)
# 규칙① 배송완료만(취소/환불 제외): orders['status']=='배송완료'
orders[orders['status']=='배송완료'].groupby('category')['amount'].sum().sort_values(ascending=False).head(3)

우리가 질문에서 "취소/환불 빼고"라고 명시하지 않은 두 번째·세 번째 질문에서도, 시스템 프롬프트 규칙 덕분에 에이전트가 알아서 취소/환불을 제외합니다. 규칙 주입이 작동하는 거죠.

4. 각 질문이 다른 분석 기법

세 질문은 각각 다른 pandas 기법을 씁니다. LLM이 질문 유형에 맞는 코드를 골라 만듭니다.

질문 pandas 기법
카테고리별 top3 groupby + sum + sort_values + head
환불 비율 조건 필터 + len 비율 계산
월별 추이 month 그룹화 + 시계열 정렬

우리는 이 기법들을 일일이 코딩하지 않았습니다. LLM이 자연어 질문을 보고 적절한 기법을 선택해 코드를 짰죠. 이게 데이터 분석 에이전트의 강력함입니다.

5. 한계와 주의

이 에이전트는 편리하지만, 맹신하면 안 됩니다.

  • LLM이 규칙을 놓칠 수 있음: 가끔 취소/환불을 빠뜨릴 수 있습니다.
  • 복잡한 분석은 검증 필요: 중요한 보고용 숫자는 사람이 다시 확인하세요.
  • 데이터가 더러우면 결과도 의심: 분석 전 데이터 품질 점검이 필요합니다(06번).

그래서 다음 절에서 분석 전에 데이터 품질을 진단하는 법을 배웁니다. "분석가가 데이터를 믿기 전에 먼저 살펴보는" 습관이죠.

핵심 정리

  • 규칙을 주입한 에이전트가 데이터 함정을 피해 자연어 질문에 답한다.
  • 질문에서 명시 안 해도, 시스템 프롬프트 규칙이 자동 적용된다.
  • LLM이 질문 유형에 맞는 pandas 기법을 골라 코드를 만든다.
  • 편리하지만 검증이 필요하다(맹신 금지).
  • 다음 절에서 분석 전 데이터 품질 체크를 배웁니다.
