문제 1 — 이상치 제외 도구 만들기

run_pandas와 별개로 revenue_by_channel() 함수를 직접 작성하세요.

  • status가 취소/환불인 행과 quantity==999, amount<0인 행을 제외한 뒤
  • channel별 평균 주문금액을 천단위 콤마로 출력합니다.
  • 사용 파일: data/orders.csv
  • 기대 결과: 채널별 평균 금액이 출력되고, 같은 질문을 에이전트에 물었을 때와 일치하면 성공.
해답 보기 
import sys, pathlib
sys.path.append(str(pathlib.Path(__file__).resolve().parent))
import pandas as pd
from common import DATA

orders = pd.read_csv(DATA / "orders.csv", encoding="utf-8-sig")

def revenue_by_channel():
    """이상치·취소/환불을 제외한 채널별 평균 주문금액을 출력한다."""
    # 데이터 함정 제거 (02번 규칙)
    clean = orders[
        (~orders["status"].isin(["취소", "환불"]))   # 취소/환불 제외
        & (orders["quantity"] != 999)               # quantity 이상치 제외
        & (orders["amount"] >= 0)                    # 음수 금액 제외
    ]
    avg = clean.groupby("channel")["amount"].mean().sort_values(ascending=False)
    print("[채널별 평균 주문금액] (이상치·취소/환불 제외)")
    for channel, val in avg.items():
        print(f"  - {channel}: {int(val):,}원")

if __name__ == "__main__":
    revenue_by_channel()
**예상 출력** 
[채널별 평균 주문금액] (이상치·취소/환불 제외)
  - 앱: 152,300원
  - 웹: 148,700원
  - 매장: 131,200원
**해설**: 02번에서 배운 세 함정을 **한 번에** 필터링했습니다. `~`(틸드)는 "아니다"를 뜻하는 부정 연산자로, `~isin(['취소','환불'])`는 "취소·환불이 아닌 것"입니다. 이렇게 함정을 제거한 깨끗한 데이터로 집계하면, 에이전트에게 자연어로 물었을 때와 같은 값이 나옵니다. 코드로 직접 짜 보면 에이전트가 안에서 무슨 일을 하는지 더 잘 이해됩니다.

문제 2 — 규칙 유무 A/B 비교 스크립트

시스템 프롬프트에서 "취소/환불 제외" 줄을 뺀 agent_no_rule과 원본 agent를 모두 만들고, "카테고리별 총매출"을 두 에이전트에 각각 물어 결과를 나란히 출력하세요.

  • 사용 파일: data/orders.csv
  • 기대 결과: 규칙을 뺀 쪽의 합계가 더 크게 나오며, 두 값의 차이(취소/환불 금액 합)를 pandas로 직접 계산해 검증하면 성공.
해답 보기 
import sys, pathlib
sys.path.append(str(pathlib.Path(__file__).resolve().parent))
import pandas as pd
from langchain_core.tools import tool
from langchain.agents import create_agent
from common import get_chat, DATA

llm = get_chat(provider="gemini")
orders = pd.read_csv(DATA / "orders.csv", encoding="utf-8-sig")

@tool
def run_pandas(expr: str) -> str:
    """주문 데이터 분석. orders(컬럼: category, amount, status...), pd 사용 가능."""
    try:
        return str(eval(expr, {"__builtins__": {}}, {"orders": orders, "pd": pd}))
    except Exception as e:
        return f"실행 오류: {e}"

# 규칙 있는 에이전트 vs 없는 에이전트
agent = create_agent(llm, tools=[run_pandas],
    system_prompt="너는 데이터 분석가다. 매출 집계 시 status가 '취소','환불'인 행은 제외하라.")
agent_no_rule = create_agent(llm, tools=[run_pandas],
    system_prompt="너는 데이터 분석가다.")   # 규칙 없음

q = "카테고리별 총매출을 알려줘."
print("[규칙 있음]", agent.invoke({"messages": [{"role": "user", "content": q}]})["messages"][-1].content)
print("[규칙 없음]", agent_no_rule.invoke({"messages": [{"role": "user", "content": q}]})["messages"][-1].content)

# pandas로 직접 차이 검증 (취소/환불 금액 합)
diff = orders[orders["status"].isin(["취소", "환불"])]["amount"].sum()
print(f"\n[검증] 취소/환불 금액 합계 = {int(diff):,}원 (이만큼 차이나야 함)")
**예상 출력** 
[규칙 있음] 카테고리별 총매출은 가전 6,855만원, 전자기기 4,354만원 ...
[규칙 없음] 카테고리별 총매출은 가전 7,120만원, 전자기기 4,510만원 ... (더 큼)

[검증] 취소/환불 금액 합계 = 38,200,000원 (이만큼 차이나야 함)
**해설**: 규칙을 뺀 에이전트는 취소/환불까지 매출에 포함해 **더 큰 합계**를 냅니다. 그 차이가 바로 "취소/환불 금액 합"이죠. pandas로 직접 계산한 차이와 두 에이전트 결과의 차이가 일치하면, 규칙 주입의 효과를 **숫자로** 증명한 겁니다. 03번에서 배운 "규칙이 결과를 바꾼다"를 실험으로 확인한 셈입니다.

정리

  • 문제 2로 규칙 주입의 효과를 A/B로 측정했습니다.
