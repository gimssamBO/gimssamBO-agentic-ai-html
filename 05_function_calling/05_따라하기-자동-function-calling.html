따라하기 — 자동 Function Calling

목표

04번에서 만든 도구 두 개를 LLM에 연결합니다. tools=[함수들] 한 줄이면, SDK가 "결정 → 실행 → 결과 전달 → 최종 답"의 5단계를 자동으로 돌립니다.

1. 도구를 한 줄로 연결

from common import get_genai_client, GEMINI_MODEL
from google.genai import types

client = get_genai_client()
# (get_stock, get_exchange_rate 는 04번에서 만든 함수)

question = "이어버드 재고 있어? 그리고 가격을 달러로 환산하려면 환율이 얼마야?"

resp = client.models.generate_content(
    model=GEMINI_MODEL,
    contents=question,
    config=types.GenerateContentConfig(
        tools=[get_stock, get_exchange_rate],   # ← 파이썬 함수를 그대로 도구로!
        temperature=0,
    ),
)
print(resp.text)

예상 출력

승승 무선 블루투스 이어버드 SE는 현재 재고 225개가 있습니다(서울물류).
달러 환산 시 1 USD = 1,385.50 KRW 환율을 적용하시면 됩니다.

2. 무슨 일이 일어난 걸까?

우리는 함수 두 개를 tools에 넘기고 질문만 했을 뿐입니다. 그런데 LLM이 스스로:

  1. 질문을 분석해 "재고 도구 + 환율 도구 둘 다 필요하다"고 판단했고,
  2. get_stock(product_name="이어버드")와 get_exchange_rate(currency="USD")를 호출하기로 결정했고,
  3. (SDK가 자동으로) 두 함수를 실행해 결과를 받았고,
  4. 그 결과를 종합해 최종 답을 만들었습니다.

우리는 "어떤 도구를 언제 쓰라"고 한마디도 하지 않았습니다. 모델이 알아서 골랐죠. 이게 Function Calling의 힘입니다.

temperature=0을 쓴 이유: 도구 선택은 "정답이 정해진" 판단이라, 매번 같은 도구를 고르도록 무작위성을 끕니다(2강·3강 복습).

3. 도구가 하나만 필요한 질문은?

질문에 따라 모델은 필요한 도구만 고릅니다.

# 재고만 물으면 → get_stock 만 호출
resp = client.models.generate_content(
    model=GEMINI_MODEL,
    contents="로봇청소기 재고 얼마나 있어?",
    config=types.GenerateContentConfig(tools=[get_stock, get_exchange_rate], temperature=0),
)
print(resp.text)
# → "로봇청소기 재고는 ...개 입니다." (환율 도구는 안 씀)

모델은 질문을 보고 필요한 만큼만 도구를 씁니다. 환율이 필요 없으면 환율 도구를 부르지 않죠.

4. 도구가 없으면?

비교를 위해, 도구 없이 같은 질문을 던져 봅니다.

# 도구 없이 — 1강의 그 한계로 돌아감
resp = client.models.generate_content(model=GEMINI_MODEL, contents="이어버드 재고 있어?")
print(resp.text)
# → "실시간 재고는 확인할 수 없습니다 ..." (또는 환각)

도구가 있고 없고의 차이가 명확합니다. 도구를 쥐여 주는 순간 LLM이 실제 데이터로 답하게 됩니다.

5. 자동의 한계 — 안이 안 보인다

자동은 편하지만, 중간에 무슨 일이 있었는지 보이지 않습니다. "모델이 어떤 도구를 어떤 인자로 불렀나?"를 알 수 없죠. 그걸 들여다보려면 수동 루프가 필요합니다. 다음 절에서 자동 실행을 끄고 모델의 "결정"을 직접 관찰합니다.

핵심 정리

  • tools=[함수들] 한 줄이면 자동으로 5단계가 돈다.
  • 모델은 질문을 보고 필요한 도구만 스스로 고른다.
  • 도구 선택은 temperature=0으로 일관성을 확보한다.
  • 자동은 편하지만 중간 과정이 안 보인다 → 다음 절 수동 루프.
  • 다음 절에서 모델의 "결정"을 직접 들여다봅니다.
