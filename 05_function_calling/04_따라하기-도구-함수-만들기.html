따라하기 — 도구로 쓸 함수 만들기

목표

LLM에게 쥐여 줄 도구 두 개(재고 조회·환율 조회)를 파이썬 함수로 만듭니다. 핵심은 독스트링과 타입힌트 — 이게 모델에게 주는 "사용 설명서"입니다. 실제 파일은 code/ch05_function_calling.py 입니다.

0. 실습 준비 (설치)

conda activate agentic

# 5강에 필요한 라이브러리 (앞 강에서 설치했다면 생략 가능)
pip install google-genai python-dotenv pandas

이번 강은 data/exchange_rates.csv(환율)와 data/inventory.csv(재고)를 씁니다.

1. 공통 시작부 + 데이터 로드

# 실행: python code/ch05_function_calling.py
import sys, pathlib
sys.path.append(str(pathlib.Path(__file__).resolve().parent))
from common import get_genai_client, GEMINI_MODEL, DATA
from google.genai import types
import pandas as pd

client = get_genai_client()
rates = pd.read_csv(DATA / "exchange_rates.csv")   # 환율 (currency, krw_per_unit)
inv = pd.read_csv(DATA / "inventory.csv")          # 재고 (product_name, stock, warehouse)

2. 도구 함수 ① — 환율 조회

# [중요] 함수의 독스트링과 타입힌트가 모델에게 주는 '사용 설명서'다(모델은 본문을 못 본다).
def get_exchange_rate(currency: str) -> str:
    """통화 코드(USD, EUR, JPY 등)를 받아 1단위당 원화(KRW) 환율을 반환한다."""
    row = rates[rates["currency"].str.upper() == currency.upper()]
    if row.empty:
        return f"{currency} 환율 정보가 없습니다."
    krw = float(row.iloc[0]["krw_per_unit"])
    return f"1 {currency.upper()} = {krw:,.2f} KRW"

뜯어보면:

  • 독스트링 """통화 코드를 받아...""" → 모델이 "환율 질문엔 이 도구"라고 판단하는 근거.
  • 타입힌트 currency: str → 모델이 "문자열 인자를 넣어야 한다"고 이해.
  • -> str → 결과는 문자열로 돌려준다(모델은 문자열을 읽음).
  • 없는 통화면 "...정보가 없습니다." 를 돌려줘 빈 결과도 안전하게 처리.

3. 도구 함수 ② — 재고 조회

def get_stock(product_name: str) -> str:
    """상품명(일부만 입력해도 됨)을 받아 현재 재고 수량을 반환한다."""
    row = inv[inv["product_name"].str.contains(product_name, na=False)]
    if row.empty:
        return f"'{product_name}' 재고 정보를 찾지 못했습니다."
    r = row.iloc[0]
    return f"{r['product_name']} 재고 {int(r['stock'])}개 ({r['warehouse']})"

여기서 str.contains를 쓴 게 포인트입니다. 고객은 "이어버드"라고만 입력하지만, 실제 상품명은 "승승 무선 블루투스 이어버드 SE"처럼 깁니다. 부분 일치로 찾아 줘야 실용적이죠. 독스트링에도 "(일부만 입력해도 됨)"이라고 명시해 모델이 알게 합니다.

4. 함수가 잘 도는지 먼저 확인 (모델 없이)

도구를 LLM에 붙이기 전에, 함수 자체가 제대로 도는지 직접 호출해 봅니다. (이건 디버깅의 기본입니다.)

print(get_stock("이어버드"))          # 승승 무선 블루투스 이어버드 SE 재고 225개 (...)
print(get_exchange_rate("USD"))      # 1 USD = 1,385.50 KRW

예상 출력

승승 무선 블루투스 이어버드 SE 재고 225개 (서울물류)
1 USD = 1,385.50 KRW

함수가 잘 동작하네요. 이제 이걸 LLM에 도구로 연결할 차례입니다.

5. 좋은 도구 함수의 3원칙 (미리보기)

다음 6강에서 자세히 다루지만, 핵심만 미리 봅니다.

  1. 독스트링을 명확히: 모델이 도구를 고르는 유일한 근거.
  2. 타입힌트를 정확히: 모델이 인자를 올바르게 채우게 함.
  3. 빈 결과·오류를 안전하게: 없는 상품·통화면 친절한 메시지 반환(예외로 죽지 않게 — 7강에서 심화).

핵심 정리

  • 도구 = 독스트링 + 타입힌트를 갖춘 파이썬 함수.
  • 독스트링이 모델의 도구 선택 근거이므로 명확히 쓴다.
  • 재고처럼 부분 일치가 필요하면 str.contains를 쓰고 독스트링에 명시한다.
  • LLM에 붙이기 전에 함수를 직접 호출해 동작을 확인한다.
  • 다음 절에서 이 도구들을 자동 Function Calling으로 연결합니다.
