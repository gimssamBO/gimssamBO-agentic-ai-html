자동 실행 vs 수동 루프

한 줄 요약

Function Calling의 5단계(결정→실행→전달→답)에서, 3·4단계(실행·전달)를 누가 처리하느냐에 따라 두 방식이 나뉩니다. 자동은 SDK가 알아서, 수동은 우리가 직접 합니다. 자동은 편하고, 수동은 원리를 보여 줍니다.

1. 두 방식 비교

방식 누가 함수를 실행하나 언제 쓰나
자동 SDK가 알아서 3·4단계 처리 빠르게 결과만 필요할 때
수동 우리가 직접 함수 실행·결과 전달 원리 학습, 중간 제어가 필요할 때(→ 7강 루프)

핵심은 같습니다 — "모델은 결정, 실행은 우리(또는 SDK)". 차이는 그 실행을 자동화하느냐, 손으로 보느냐입니다.

2. 자동 실행 — 한 줄로 끝

config에 tools=[함수들]만 넘기면, SDK가 5단계를 자동으로 돌립니다.

from common import get_genai_client, GEMINI_MODEL
from google.genai import types

client = get_genai_client()

resp = client.models.generate_content(
    model=GEMINI_MODEL,
    contents="이어버드 재고 있어?",
    config=types.GenerateContentConfig(
        tools=[get_stock, get_exchange_rate],   # ← 도구만 넘기면 끝
        temperature=0,
    ),
)
print(resp.text)   # 이미 도구 실행까지 끝난 최종 답변

resp.text에는 이미 도구가 실행되고 그 결과가 반영된 최종 답이 들어 있습니다. 편하죠. 하지만 중간에 무슨 일이 일어났는지는 보이지 않습니다.

3. 수동 루프 — 원리를 눈으로

자동 실행을 끄면(disable=True), 모델은 "무엇을 호출할지" 결정만 하고 멈춥니다. 그 결정을 우리가 직접 받아 실행합니다.

resp = client.models.generate_content(
    model=GEMINI_MODEL,
    contents="이어버드 재고 알려줘.",
    config=types.GenerateContentConfig(
        tools=[get_stock, get_exchange_rate],
        automatic_function_calling=types.AutomaticFunctionCallingConfig(disable=True),  # ← 자동 끔
        temperature=0,
    ),
)

# 모델은 '결정'만 했다 → resp.function_calls 에 담김
for fc in resp.function_calls:
    print("모델의 결정:", fc.name, dict(fc.args))   # 무엇을 부르려는지
    # ↑ 아직 실행 안 됨! 실행은 우리가 한다 (다음 절)

resp.function_calls에는 모델이 "부르려는 함수 목록"(이름 + 인자)이 들어 있습니다. 아직 실행은 안 됐습니다. 이걸 우리가 직접 실행하는 게 다음 단계입니다.

4. 왜 수동을 배우나?

자동이 편한데 왜 수동을 배울까요? 세 가지 이유입니다.

  1. 원리 이해: "모델은 결정만 한다"를 눈으로 봐야 에이전트를 제대로 이해합니다.
  2. 중간 제어: 실행 전 인자 검증, 권한 확인, 로깅을 끼워 넣을 수 있습니다.
  3. 7강의 토대: 7강 Agent Loop는 이 수동 루프를 while로 반복하는 것입니다.

정리하면: 자동은 실무에서 빠르게 쓰고, 수동은 원리를 익히고 정교하게 제어할 때 씁니다. 7강에서 이 수동 루프를 반복문으로 감싸 "스스로 여러 단계를 처리하는 에이전트"를 만듭니다.

핵심 정리

  • 자동 실행 = tools=[...]만 주면 SDK가 5단계를 다 처리(편함).
  • 수동 루프 = disable=True로 끄고, function_calls를 우리가 직접 실행(원리·제어).
  • 둘 다 본질은 "모델은 결정, 실행은 우리/SDK".
  • 수동 루프는 7강 Agent Loop의 토대다.
  • 다음 절부터 따라하기 — 먼저 도구 함수를 만듭니다.
