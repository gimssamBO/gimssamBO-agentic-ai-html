정리 & 체크리스트

5강에서 배운 것

5강에서는 LLM의 두뇌에 손발(도구) 을 달았습니다.

  • Function Calling: LLM이 파이썬 함수를 도구로 써서 실제 데이터를 조회한다.
  • 핵심 개념: LLM은 함수를 직접 실행하지 못한다 — "무엇을 부를지" 결정만 하고, 실행은 우리가 한다.
  • 자동 vs 수동: 자동(tools=[...])은 편하고, 수동(disable=True + function_calls)은 원리를 보여 준다.
  • 오류 처리: 도구 실패를 try/except로 잡아 친절한 메시지로 바꾸면 에이전트가 멈추지 않는다.

한눈에 보는 핵심 코드

from common import get_genai_client, GEMINI_MODEL
from google.genai import types
client = get_genai_client()

# 도구 = 독스트링 + 타입힌트를 갖춘 파이썬 함수
def get_stock(product_name: str) -> str:
    """상품명을 받아 현재 재고 수량을 반환한다."""
    try:
        ...  # 조회
        return "재고 225개"
    except Exception as e:
        return f"조회 오류: {e}"          # 예외를 친절한 문자열로

# (자동) 도구만 주면 SDK가 실행까지
resp = client.models.generate_content(
    model=GEMINI_MODEL, contents="이어버드 재고?",
    config=types.GenerateContentConfig(tools=[get_stock], temperature=0))
print(resp.text)

# (수동) 자동을 끄면 '결정'만 → 우리가 실행
resp = client.models.generate_content(
    model=GEMINI_MODEL, contents="이어버드 재고?",
    config=types.GenerateContentConfig(
        tools=[get_stock],
        automatic_function_calling=types.AutomaticFunctionCallingConfig(disable=True),
        temperature=0))
for fc in resp.function_calls:
    result = {"get_stock": get_stock}[fc.name](**dict(fc.args))   # 우리가 실행

새로 설치할 라이브러리는 없습니다.

체크리스트

  • [ ] LLM은 함수를 실행하지 못하고 "무엇을 호출할지"만 정한다는 것을 설명할 수 있다.
  • [ ] 자동 function calling으로 도구를 한 줄(tools=[...])로 연결해 봤다.
  • [ ] 수동 루프에서 response.function_calls를 직접 실행해 봤다.
  • [ ] 함수 독스트링이 모델의 도구 선택 근거임을 이해했다.
  • [ ] 도구 오류를 try/except로 잡아 친절한 메시지로 변환했다.

한 줄 핵심

"모델은 결정, 실행은 우리." LLM은 어떤 도구를 부를지 정할 뿐, 실제 실행과 오류 처리는 우리 코드가 맡는다.
