코드 생성-실행 루프

한 줄 요약

코드 실행 에이전트는 ① LLM이 코드 생성 → ② 도구가 코드 실행 → ③ LLM이 결과 해석의 세 단계로 돕니다. LLM은 "무엇을 계산할지"만 정하고, 정확한 계산은 코드가 합니다.

1. 세 단계 흐름

사용자 질문 "전체 기간 총 매출은?" 이 세 단계를 거칩니다.

  1. ① LLM: pandas 식 생성 — "df['sales'].sum() 을 실행하자"
  2. ② run_pandas 도구: 식 실행 — eval("df['sales'].sum()") → 324286050
  3. ③ LLM: 결과를 자연어로 해석 — "총 매출은 324,286,050원입니다"
단계 주체 내용
① 코드 생성 LLM 필요한 pandas 식 작성
② 코드 실행 도구 식을 평가해 결과 반환
③ 해석 LLM 결과를 자연어로 설명

2. 왜 이렇게 나누나

각 단계를 가장 잘하는 주체에게 맡깁니다.

  • ① 코드 생성 — LLM이 잘함: "총 매출을 구하려면 sum()을 써야지"라는 판단은 LLM의 강점입니다. 자연어를 코드로 번역하는 거죠.
  • ② 코드 실행 — 코드가 잘함: 정확한 계산은 pandas가 합니다. 600개를 더해도 오차가 없죠.
  • ③ 해석 — LLM이 잘함: 324286050이라는 무미건조한 숫자를 "약 3억 2천만원입니다"라고 친절히 설명하는 건 LLM의 강점입니다.

각자 잘하는 일을 하니, 전체적으로 정확하면서도 친절한 답이 나옵니다.

비유: 회계 업무와 같습니다. 회계사(LLM)가 "이 항목들을 합산해야겠다"고 판단하고, 계산기(코드)로 정확히 두드리고, 다시 회계사가 "결산 결과는 이렇습니다"라고 보고서로 풀어 씁니다.

3. 7강 ReAct 루프와의 관계

이 "생성 → 실행 → 해석"도 사실 7강 ReAct 루프입니다.

  • 생각(Thought): "총 매출을 구하려면 sum()을 써야지" → 코드 생성
  • 행동(Action): run_pandas 도구 호출
  • 관찰(Observation): 실행 결과(324286050)
  • 답변: 결과를 자연어로 정리

도구가 "코드 실행기"일 뿐, 흐름은 7강과 똑같습니다. 그리고 LangChain create_agent가 이 루프를 돌려 줍니다(8강).

4. 핵심 — LLM이 코드를 '쓸 줄 안다'

이 방식이 가능한 이유는, LLM이 학습 과정에서 엄청난 양의 코드를 봤기 때문입니다. 그래서 "총합 = sum()", "평균 = mean()", "최댓값 위치 = idxmax()" 같은 pandas 패턴을 잘 압니다.

"총 매출"        → df['sales'].sum()
"일평균 매출"     → df['sales'].mean()
"최고 매출일"     → df.loc[df['sales'].idxmax(), 'date']

우리가 pandas 문법을 일일이 안 가르쳐도, LLM이 자연어 질문을 적절한 코드로 번역합니다. 다만 가끔 틀린 코드를 만들기도 하는데(컬럼 오타 등), 그 대응은 06번(재시도)에서 배웁니다.

핵심 정리

  • 코드 실행 루프 = ① LLM 코드 생성 → ② 도구 실행 → ③ LLM 해석.
  • 각 단계를 가장 잘하는 주체에게 맡겨 정확 + 친절을 얻는다.
  • 본질은 7강 ReAct 루프(도구가 "코드 실행기"일 뿐).
  • LLM은 학습으로 pandas 코드를 쓸 줄 안다(자연어 → 코드 번역).
  • 다음 절에서 코드 실행의 보안 위험과 안전장치를 배웁니다.
