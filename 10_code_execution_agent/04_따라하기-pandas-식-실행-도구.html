따라하기 — pandas 식 실행 도구

목표

LLM이 만든 pandas 식을 안전하게 실행하는 run_pandas 도구를 만듭니다. 실제 파일은 code/ch10_code_exec.py 입니다.

이번 강은 data/sales_daily.csv(컬럼: date, sales)를 씁니다.

1. 공통 시작부 + 데이터 로드

# 실행: python code/ch10_code_exec.py
import sys, pathlib
sys.path.append(str(pathlib.Path(__file__).resolve().parent))
import pandas as pd
from langchain_core.tools import tool          # @tool: 함수를 도구로 등록
from langchain.agents import create_agent       # create_agent: ReAct 에이전트 생성
from common import get_chat, DATA

llm = get_chat(provider="gemini")
# 일자별 매출 데이터 로드 (컬럼: date, sales)
df = pd.read_csv(DATA / "sales_daily.csv")

df는 모듈을 로드할 때 한 번만 읽습니다. 이 df가 도구 안에서 계속 쓰입니다.

2. run_pandas 도구 — docstring이 핵심

03번에서 본 안전한 실행 함수에 @tool을 붙입니다. docstring에 컬럼명과 사용 예시를 적는 게 매우 중요합니다.

@tool
def run_pandas(expr: str) -> str:
    """미리 로드된 일별 매출 DataFrame(df)에 대한 pandas 식을 실행해 결과를 문자열로 반환한다.
    df 컬럼: date(날짜 문자열 'YYYY-MM-DD'), sales(정수 매출).
    예: "df['sales'].sum()", "df['sales'].mean()",
        "df.loc[df['sales'].idxmax(), 'date']".
    식 안에서는 df, pd 만 사용할 수 있다."""
    # 빌트인 차단 + df/pd 화이트리스트 (03번)
    try:
        result = eval(expr, {"__builtins__": {}}, {"df": df, "pd": pd})
    except Exception as e:
        return f"실행 오류: {e}"     # 잘못된 식이어도 에이전트가 죽지 않게
    return str(result)

docstring을 잘 보세요. 세 가지 정보를 줍니다.

  • 컬럼명: date(날짜 문자열), sales(정수 매출) → LLM이 올바른 컬럼을 씀
  • 사용 예시: df['sales'].sum() 등 → LLM이 식의 형태를 참고
  • 제약: "df, pd 만 사용 가능" → LLM이 허용 범위를 앎

이 docstring 덕분에 LLM이 올바른 pandas 식을 훨씬 잘 만듭니다. 6강에서 배운 "독스트링 = 도구 성능"이 여기서도 빛납니다.

3. 왜 docstring에 컬럼명을 적나

LLM은 df 안에 어떤 컬럼이 있는지 모릅니다. docstring에 "컬럼: date, sales"라고 알려 주지 않으면, LLM이 엉뚱한 컬럼명(revenue, amount 등)을 써서 오류가 납니다.

# docstring에 컬럼 정보 없으면:
"df['revenue'].sum()"   # → 실행 오류! (revenue 컬럼 없음)

# docstring에 "컬럼: date, sales" 있으면:
"df['sales'].sum()"     # → 정상! (올바른 컬럼명 사용)

도구가 다루는 데이터의 구조(스키마) 를 docstring으로 알려 주는 게 핵심입니다.

4. 도구 단독 테스트

에이전트에 붙이기 전, 도구가 잘 도는지 확인합니다(디버깅 습관).

# @tool로 감싼 함수는 .invoke()로 직접 호출 가능
print(run_pandas.invoke({"expr": "df['sales'].sum()"}))    # → 324286050
print(run_pandas.invoke({"expr": "len(df)"}))              # → 실행 오류 (len은 빌트인이라 차단!)
print(run_pandas.invoke({"expr": "df.shape[0]"}))          # → 600 (행 개수, 정상)

흥미로운 점: len(df)는 오류가 납니다. len이 빌트인 함수라 {"__builtins__": {}}로 차단됐기 때문이죠. 대신 df.shape[0]처럼 pandas 메서드를 써야 합니다. 안전장치가 작동하는 증거입니다.

핵심 정리

  • run_pandas 도구 = 03번의 안전한 eval + @tool 데코레이터.
  • docstring에 컬럼명·예시·제약을 적어야 LLM이 올바른 식을 만든다.
  • 도구가 다루는 데이터의 스키마(컬럼) 를 알려 주는 게 핵심.
  • len() 같은 빌트인은 차단되니 pandas 메서드(df.shape)를 쓴다.
  • 다음 절에서 이 도구로 자연어 질문에 답하는 에이전트를 만듭니다.
