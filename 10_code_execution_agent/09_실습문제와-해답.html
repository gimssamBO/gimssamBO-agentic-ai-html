실습문제와 해답

직접 코드를 고쳐 보며 10강 내용을 손에 익힙니다. 먼저 스스로 풀어 본 뒤 해답을 펼쳐 보세요.

문제 1 — 월별 매출 + 생성된 식 관찰

agent.invoke(...)를 agent.stream(..., stream_mode="values") 루프로 바꿔 pretty_print()로 출력하고, "2024년 11월 매출 합계는?"을 질문하세요.

  • 사용 파일: data/sales_daily.csv (컬럼: date, sales)
  • 기대 결과: 에이전트가 run_pandas에 넘긴 식(예: df[df['date'].str.startswith('2024-11')]['sales'].sum())이 도구 호출 로그로 보이고, 그 합계가 천단위 콤마로 출력되면 성공.
해답 보기 
import sys, pathlib
sys.path.append(str(pathlib.Path(__file__).resolve().parent))
import pandas as pd
from langchain_core.tools import tool
from langchain.agents import create_agent
from common import get_chat, DATA

llm = get_chat(provider="gemini")
df = pd.read_csv(DATA / "sales_daily.csv")

@tool
def run_pandas(expr: str) -> str:
    """일별 매출 df(컬럼: date 'YYYY-MM-DD', sales)에 pandas 식을 실행한다. df, pd 만 사용."""
    try:
        return str(eval(expr, {"__builtins__": {}}, {"df": df, "pd": pd}))
    except Exception as e:
        return f"실행 오류: {e}"

agent = create_agent(llm, tools=[run_pandas],
    system_prompt="너는 데이터 분석가다. 계산은 반드시 run_pandas로 하고 천단위 콤마로 한국어 설명하라.")

q = "2024년 11월 매출 합계는?"
for step in agent.stream({"messages": [{"role": "user", "content": q}]}, stream_mode="values"):
    step["messages"][-1].pretty_print()
**예상 출력** 
================================== Ai Message ==================================
Tool Calls:
  run_pandas
   Args:
     expr: df[df['date'].str.startswith('2024-11')]['sales'].sum()    ← LLM이 만든 식!
================================= Tool Message =================================
12345670
================================== Ai Message ==================================
2024년 11월 매출 합계는 12,345,670원입니다.
**해설**: `stream`으로 보면 LLM이 만든 식이 `Tool Calls`에 그대로 보입니다. "11월만 필터링하려면 `str.startswith('2024-11')`을 써야지"라는 LLM의 판단이 코드로 드러나죠. 날짜 문자열을 다루는 영리한 식을 LLM이 스스로 만들었습니다. 이렇게 `stream`은 에이전트의 "생각"을 들여다보는 창입니다.

문제 2 — 샌드박스 안전장치 검증

run_pandas를 직접 호출하는 테스트 코드를 추가해, 위험한 식은 막히고 정상 식은 되는지 확인하세요.

  • run_pandas.invoke({"expr": "__import__('os').listdir('.')"}) (위험)
  • run_pandas.invoke({"expr": "df['sales'].sum()"}) (정상)
  • 기대 결과: 위험한 식은 실행 오류: ..., 정상 식은 합계 숫자가 나오면 성공.
해답 보기 
import sys, pathlib
sys.path.append(str(pathlib.Path(__file__).resolve().parent))
import pandas as pd
from langchain_core.tools import tool
from common import get_chat, DATA

df = pd.read_csv(DATA / "sales_daily.csv")

@tool
def run_pandas(expr: str) -> str:
    """일별 매출 df에 pandas 식을 실행한다. df, pd 만 사용."""
    try:
        return str(eval(expr, {"__builtins__": {}}, {"df": df, "pd": pd}))
    except Exception as e:
        return f"실행 오류: {e}"

if __name__ == "__main__":
    print("위험한 식 (파일 목록 조회 시도):")
    print(" ", run_pandas.invoke({"expr": "__import__('os').listdir('.')"}))

    print("\n정상 식 (매출 합계):")
    print(" ", run_pandas.invoke({"expr": "df['sales'].sum()"}))
**예상 출력** 
위험한 식 (파일 목록 조회 시도):
  실행 오류: __import__ is not defined        ← 빌트인 차단으로 막힘!

정상 식 (매출 합계):
  324286050                                   ← 정상 작동
**해설**: 위험한 식 `__import__('os').listdir('.')`는 **막혔습니다.** `{"__builtins__": {}}`로 빌트인을 차단했기 때문에 `__import__`라는 이름이 정의되지 않아서죠("not defined"). 반면 정상 pandas 식은 잘 실행됩니다. 화이트리스트 방어가 작동하는 증거입니다. ⚠️ 단, 07번에서 배웠듯 이 방어가 **완벽하지는 않습니다.** 외부 공개 서비스라면 샌드박스가 필요합니다. 이 테스트는 "기본 방어가 작동한다"를 확인하는 것이지, "완전히 안전하다"를 보장하는 게 아닙니다.

정리

  • 문제 1로 stream으로 LLM이 만든 식을 관찰했습니다.
  • 문제 2로 화이트리스트 방어가 위험한 코드를 막는 것을 확인했습니다.
