따라하기 — 자연어로 집계 질문

목표

run_pandas 도구를 에이전트에 붙여, "총 매출은?", "일평균은?" 같은 자연어 질문에 정확한 계산으로 답하게 합니다.

실습파일: code/ch10_code_exec_basic2.py

1. 에이전트 구성 — "계산은 반드시 도구로"

create_agent에 run_pandas를 연결합니다. 시스템 프롬프트가 중요합니다.

# 자연어 위한 에이전트 구성
agent = create_agent(
    llm,
    tools=[run_pandas],
    system_prompt="너는 승승장구몰의 데이터 분석가다. 계산은 반드시 run_pandas 도구로 하고, "
                  "결과 숫자는 천단위 콤마를 붙여 한국어로 설명하라."
                  "사용자가 질문한 항목에 대해서만 답한다. "
                "질문하지 않은 추가 통계, 분석, 설명은 절대 덧붙이지 않는다. "
                "결과 숫자는 천단위 콤마를 붙여 한국어로 간단히 설명한다."
)

시스템 프롬프트에 "계산은 반드시 run_pandas 도구로" 라고 못 박은 게 핵심입니다. 이게 없으면 LLM이 도구를 안 쓰고 암산으로 때우려 할 수 있습니다(그래서 틀리죠). "직접 계산하지 말고 도구를 써라"라고 강제하는 겁니다.

2. 자연어 질문 던지기

# 자연어 질문 던지기
questions = [
    # "전체 기간 총 매출은 얼마야?",
    # "일평균 매출은?",
    # "매출이 가장 높았던 날짜와 그날의 매출을 알려줘.",
    # "2024년 11월 매출 합계는?",
    "매출 상위 3일은?"
]

for q in questions:
    print("Q:", q)
    result = agent.invoke({"messages": [{"role":"user","content":q}]})
    print("A:", result["messages"][-1].content)

예상 출력

Q: 전체 기간 총 매출은 얼마야?
A: 전체 기간 총 매출은 324,286,050원입니다.

Q: 일평균 매출은?
A: 일평균 매출은 약 414,158원입니다.

Q: 매출이 가장 높았던 날짜와 그날의 매출을 알려줘.
A: 매출이 가장 높았던 날은 2024-04-24입니다.

각 질문마다 LLM이 적절한 pandas 식을 만들고, run_pandas가 실행해 정확한 숫자를 얻고, 그걸 한국어로 설명했습니다.

3. 안에서 무슨 일이 일어났나

"전체 기간 총 매출은?" 질문을 예로 들면:

1. LLM 생각: "총 매출 = sum. df['sales'].sum()을 실행하자"
2. run_pandas("df['sales'].sum()") 실행 → 324286050
3. LLM 해석: "324286050에 콤마를 붙여... 총 매출은 324,286,050원입니다"

핵심: LLM은 324286050을 직접 계산하지 않았습니다. df['sales'].sum()이라는 코드를 만들었을 뿐이고, 정확한 합계는 pandas가 냈습니다. 만약 LLM이 직접 600개를 더했다면 틀렸을 겁니다(01번).

4. 천단위 콤마는 누가 넣는가

재미있는 점: 324286050을 324,286,050으로 콤마를 붙이는 건 LLM이 합니다. 시스템 프롬프트에 "천단위 콤마를 붙여"라고 했으니까요.

계산(정확성 필요)   → pandas (324286050)
서술·포맷(자연스러움) → LLM (324,286,050원입니다)

이게 역할 분담의 묘미입니다. 정확해야 하는 계산은 코드가, 읽기 좋게 만드는 서술은 LLM이. 이 원칙은 24강(비즈니스 리포트)에서 본격적으로 다룹니다 — "계산은 코드, 서술은 LLM".

5. 더 복잡한 질문도

이 방식의 강력함은 어떤 집계든 가능하다는 것입니다. LLM이 코드만 바꾸면 되니까요.

agent.invoke({"messages": [{"role": "user", "content": "2024년 11월 매출 합계는?"}]})
# → LLM이 만드는 식: df[df['date'].str.startswith('2024-11')]['sales'].sum()
# → 특정 월만 필터링해서 합계!

agent.invoke({"messages": [{"role": "user", "content": "매출 상위 3일은?"}]})
# → LLM이 만드는 식: df.nlargest(3, 'sales')[['date', 'sales']]

필터링, 정렬, 그룹화 — pandas로 할 수 있는 건 다 됩니다. 우리가 함수를 일일이 안 만들어도, LLM이 그때그때 코드를 짜니까요. 이게 "고정 도구"(5강)와 "코드 실행 도구"(10강)의 차이입니다.

핵심 정리

  • 시스템 프롬프트로 "계산은 반드시 도구로" 못 박아 암산을 막는다.
  • 각 질문마다 LLM이 pandas 식 생성 → 실행 → 한국어 해석.
  • 계산은 코드(정확), 서술·포맷은 LLM(자연스러움) — 역할 분담.
  • 코드만 바꾸면 어떤 집계든 가능(필터·정렬·그룹화).
  • 다음 절에서 LLM이 만든 코드가 틀렸을 때 재시도하는 법을 배웁니다.
