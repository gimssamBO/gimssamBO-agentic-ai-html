정리 & 체크리스트

10강에서 배운 것

10강에서는 LLM이 코드를 생성하고 실행해 정확한 계산을 하게 만들었습니다.

  • LLM은 계산기가 아니다: 큰 데이터 집계에 약함 → 코드에게 맡긴다.
  • 생성-실행 루프: ① LLM 코드 생성 → ② 도구 실행 → ③ LLM 해석.
  • 안전한 실행: 빌트인 차단({"__builtins__": {}}) + 화이트리스트(df, pd).
  • 자가교정: 코드 실패 시 오류를 피드백해 스스로 고친다.
  • 보안: 화이트리스트는 완벽하지 않아, 외부 서비스는 샌드박스 필수.

한눈에 보는 핵심 코드

import pandas as pd
from langchain_core.tools import tool
from langchain.agents import create_agent
from common import get_chat, DATA

llm = get_chat(provider="gemini")
df = pd.read_csv(DATA / "sales_daily.csv")

@tool
def run_pandas(expr: str) -> str:
    """일별 매출 df(컬럼: date, sales)에 pandas 식을 실행한다. df, pd 만 사용 가능."""
    try:
        result = eval(expr, {"__builtins__": {}}, {"df": df, "pd": pd})  # 안전장치
    except Exception as e:
        return f"실행 오류: {e}"
    return str(result)

agent = create_agent(llm, tools=[run_pandas],
    system_prompt="너는 데이터 분석가다. 계산은 반드시 run_pandas로 하라.")
result = agent.invoke({"messages": [{"role": "user", "content": "총 매출은?"}]})

체크리스트

  • [ ] LLM이 직접 계산하면 왜 위험한지 설명할 수 있다.
  • [ ] "코드 생성 → 실행 → 해석" 루프를 이해했다.
  • [ ] eval의 위험과 화이트리스트 네임스페이스 안전장치를 안다.
  • [ ] 코드 실패 시 오류를 피드백해 재시도하는 자가교정을 구현했다.
  • [ ] 외부 서비스에는 샌드박스가 필요한 이유를 안다.

한 줄 핵심

"무엇을 계산할지는 LLM, 정확한 계산은 코드." LLM이 pandas 식을 만들고 우리가 안전하게 실행해, 정확하고 친절한 분석을 한다.

🎉 1부를 마치며

축하합니다! 1부(1~10강) 를 완주했습니다. 여기까지 배운 것을 돌아봅시다.

  • 1~4강: LLM의 두뇌 — 호출, 프롬프트, 추론
  • 5~7강: 손발과 심장 — 도구, 도구 선택, ReAct 루프 (raw SDK로 원리 체득)
  • 8강: LangChain 도입 — 계획 에이전트
  • 9~10강: 실전 도구 — 검색, 코드 실행

이제 여러분은 에이전트의 핵심 원리를 모두 압니다. LLM에 도구를 붙이고, 루프를 돌리고, 안전하게 코드를 실행하는 법까지요.
