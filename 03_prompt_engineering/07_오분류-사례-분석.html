오분류 사례 분석

한 줄 요약

정확도 숫자 하나만 보면 "88%네" 하고 끝입니다. 하지만 틀린 건을 들여다보고 "어떤 카테고리끼리 헷갈리는지"를 집계하면, 무엇을 고쳐야 정확도가 오를지 정확히 알 수 있습니다.

1. 왜 틀린 걸 봐야 하나

정확도 88%는 "60건 중 7건 틀렸다"는 뜻입니다. 그런데 그 7건이:

  • 전부 "환불을 결제로" 잘못 분류한 거라면 → 환불/결제 경계 예시를 추가하면 됩니다.
  • 제각각 흩어져 있다면 → 다른 접근이 필요합니다.

즉, 틀린 패턴을 알아야 올바른 처방을 내릴 수 있습니다. 의사가 증상을 봐야 약을 처방하듯이요.

비유: 시험에서 70점 받았을 때, 점수만 보면 막막합니다. 하지만 틀린 문제를 모아 보면 "아, 나는 분수 계산에서 자꾸 틀리는구나"가 보입니다. 그 부분만 집중 공부하면 점수가 오릅니다.

2. 틀린 케이스만 모아 보기

(실습 파일: code/ch03_prompt_engineering_wrong)

03강의 classify 함수를 그대로 재사용해 60건을 분류한 뒤, 틀린 것만 골라 사람이 읽을 수 있게 출력합니다.

import sys, pathlib, json
sys.path.append(str(pathlib.Path(__file__).resolve().parent))
from common import get_openai_client, OPENAI_MODEL, DATA
import pandas as pd
from collections import Counter
# (classify 함수와 FEWSHOT 은 OpenAI 버전과 동일 — 재사용)
CATEGORIES = ["배송", "환불", "교환", "결제", "상품문의", "칭찬", "불만"]

FEWSHOT = """다음 고객 문의를 아래 7개 중 정확히 하나로 분류하라.
카테고리: 배송 / 환불 / 교환 / 결제 / 상품문의 / 칭찬 / 불만
카테고리 이름 한 단어만 출력하라(다른 말 금지).

[예시]
문의: 반품하면 배송비는 누가 부담하나요?           → 환불
문의: 색상이 사진과 달라요. 다른 색으로 바꿔주세요.  → 교환
문의: 상담원분이 정말 친절하셨어요. 감사합니다.      → 칭찬
문의: 카드가 두 번 청구됐어요.                      → 결제
"""
def classify(content: str) -> str:
    resp = client.chat.completions.create(
        model=OPENAI_MODEL,
        messages=[
            {"role": "user", "content": f"{FEWSHOT}\n[분류할 문의]\n문의: {content} →"}
        ],
        temperature=0,
    )
    out = resp.choices[0].message.content.strip()
    for c in CATEGORIES:
        if c in out:
            return c
    return "기타"

client = get_openai_client()

df = pd.read_csv(DATA / "cs_inquiries.csv", encoding="utf-8-sig")
df["pred"] = df["content"].apply(classify)

correct = (df["pred"] == df["category_hint"]).sum()
print(f"전체 정확도: {correct/len(df):.1%}  ({correct}/{len(df)})")

# [핵심] 틀린 케이스만 모아서 '왜 틀렸나'를 사람이 읽을 수 있게 출력
wrong = df[df["pred"] != df["category_hint"]]
print(f"틀린 케이스: {len(wrong)}건")
for i, (_, r) in enumerate(wrong.iterrows(), 1):
    print(f"[{i}] 정답={r['category_hint']} / 예측={r['pred']}")
    print(f"     내용: {r['content']}")

3. 혼동쌍 집계 — 어느 경계가 약한가

한 건씩 보는 것도 좋지만, "정답 → 예측" 쌍을 집계하면 약점이 한눈에 보입니다. collections.Counter를 씁니다.

# [왜] 혼동쌍을 집계하면 '어느 경계가 약한가'가 한눈에 보인다
confusion = Counter(
    (r["category_hint"], r["pred"]) for _, r in wrong.iterrows()
)
print("혼동쌍 집계 (정답 → 예측, 많은 순):")
for (gold, pred), cnt in confusion.most_common():
    print(f"  {gold} → {pred} : {cnt}건")

예상 출력

혼동쌍 집계 (정답 → 예측, 많은 순):
  불만 → 교환 : 5건

이제 명확합니다. 환불↔결제, 불만↔상품문의, 교환↔환불 이 세 경계가 약합니다.

4. 처방 — 약한 경계에 예시를 추가

혼동쌍을 알았으니, few-shot 예시에 그 경계를 가르는 예시를 추가하면 됩니다.

# 약한 경계(환불 vs 결제, 불만 vs 상품문의)를 콕 집은 예시 추가
FEWSHOT_PLUS = FEWSHOT + """문의: 결제는 됐는데 환불은 언제 되나요?       → 환불
문의: 결제창에서 자꾸 오류가 나요.              → 결제
문의: 배송이 자꾸 늦어서 너무 불편해요.         → 불만
문의: 이 제품 방수 되나요?                      → 상품문의
"""

이렇게 예시를 보강하면 보통 정확도가 88% → 91~93%로 오릅니다. (이 실험은 연습문제에서 직접 해 봅니다.)

5. 이 방법이 중요한 이유

이건 단순한 분류 팁이 아닙니다. "AI 시스템을 데이터로 개선하는 사고방식" 입니다.

  1. 측정한다 (정확도)
  2. 틀린 걸 분석한다 (혼동쌍)
  3. 약점을 처방한다 (예시 추가)
  4. 다시 측정한다 (개선 확인)

이 순환은 분류뿐 아니라 RAG(16강), 에이전트 평가(30강) 등 모든 AI 시스템 개선에 똑같이 적용됩니다.

핵심 정리

  • 정확도 숫자만 보지 말고 틀린 케이스를 들여다본다.
  • Counter로 "정답 → 예측" 혼동쌍을 집계하면 약한 경계가 보인다.
  • 약한 경계를 가르는 few-shot 예시를 추가해 처방한다.
  • 이 "측정 → 분석 → 처방 → 재측정" 순환은 모든 AI 개선의 핵심이다.
