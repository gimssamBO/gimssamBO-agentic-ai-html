문제 1 — few-shot 보강으로 정확도 올리기

code/ch03_prompt.py의 FEWSHOT 문자열에, "불만"과 "상품문의"를 가르는 경계 예시 2개를 직접 추가하세요.

  • 예: 문의: 배송이 자꾸 늦어서 너무 불편해요. → 불만, 문의: 이 제품 방수 되나요? → 상품문의
  • 사용 파일: data/cs_inquiries.csv
  • 기대 결과: 변경 전/후 60건 정확도를 모두 출력해, 예시 추가 효과(예: 88.3% → 91.7%)를 비교할 수 있으면 성공.

OpenAI

해답 보기 
import sys, pathlib
sys.path.append(str(pathlib.Path(__file__).resolve().parent))
from common import get_openai_client, OPENAI_MODEL, DATA
import pandas as pd

client = get_openai_client()
df = pd.read_csv(DATA / "cs_inquiries.csv", encoding="utf-8-sig")
CATEGORIES = ["배송", "환불", "교환", "결제", "상품문의", "칭찬", "불만"]

FEWSHOT_BASE = """다음 고객 문의를 아래 7개 중 정확히 하나로 분류하라.
카테고리: 배송 / 환불 / 교환 / 결제 / 상품문의 / 칭찬 / 불만
카테고리 이름 한 단어만 출력하라(다른 말 금지).

[예시]
문의: 반품하면 배송비는 누가 부담하나요?           → 환불
문의: 색상이 사진과 달라요. 다른 색으로 바꿔주세요.  → 교환
문의: 상담원분이 정말 친절하셨어요. 감사합니다.      → 칭찬
문의: 카드가 두 번 청구됐어요.                      → 결제
"""

# 경계 예시 2개 추가
FEWSHOT_PLUS = FEWSHOT_BASE + """문의: 배송이 자꾸 늦어서 너무 불편해요.   → 불만
문의: 이 제품 방수 되나요?                  → 상품문의
"""

def make_classifier(fewshot):
    def classify(content):
        resp = client.chat.completions.create(
            model=OPENAI_MODEL,
            messages=[
                {"role": "user", "content": f"{fewshot}\n[분류할 문의]\n문의: {content} →"}
            ],
            temperature=0,
        )
        out = resp.choices[0].message.content.strip()
        return next((c for c in CATEGORIES if c in out), "기타")
    return classify

def accuracy(classify):
    pred = df["content"].apply(classify)
    return (pred == df["category_hint"]).mean()

print(f"예시 추가 전: {accuracy(make_classifier(FEWSHOT_BASE)):.1%}")
print(f"예시 추가 후: {accuracy(make_classifier(FEWSHOT_PLUS)):.1%}")
**예상 출력** 
예시 추가 전: 88.3%
예시 추가 후: 91.7%
**해설**: 약한 경계(불만 vs 상품문의)를 콕 집은 예시를 추가하니 정확도가 올랐습니다. 07번에서 배운 "혼동쌍 분석 → 경계 예시 처방"을 실제로 적용한 것입니다.

문제 2 — 긴급 건만 추리는 triage 배치

code/ch03_prompt.py의 triage() JSON 키에 suggested_reply(추천 답변 1문장)를 추가하세요.

  • data/cs_inquiries.csv의 앞 15건에 triage()를 적용합니다.
  • 결과 중 urgent == True인 건만 골라 content / category / suggested_reply를 한 줄씩 출력합니다.
  • 기대 결과: 긴급 문의들만 추천 답변과 함께 출력되면 성공.
해답 보기 
import sys, pathlib, json
sys.path.append(str(pathlib.Path(__file__).resolve().parent))
from common import get_genai_client, GEMINI_MODEL, DATA
from google.genai import types
import pandas as pd

client = get_genai_client()
df = pd.read_csv(DATA / "cs_inquiries.csv", encoding="utf-8-sig")

def triage(content: str) -> dict:
    resp = client.models.generate_content(
        model=GEMINI_MODEL,
        contents=(
            "다음 고객 문의를 분석해 JSON으로만 답하라.\n"
            "키: category(배송/환불/교환/결제/상품문의/칭찬/불만 중 하나), "
            "urgent(true/false), summary(20자 이내), "
            "suggested_reply(고객에게 보낼 추천 답변 1문장)\n"  # ← 추가한 키
            f"문의: {content}"
        ),
        config=types.GenerateContentConfig(
            temperature=0, response_mime_type="application/json"),
    )
    return json.loads(resp.text)

# 앞 15건에 적용 → 긴급 건만 출력
print("=== 긴급 문의 (urgent=True) ===")
for content in df["content"].head(15):
    r = triage(content)
    if r.get("urgent"):
        print(f"- [{r['category']}] {content}")
        print(f"    추천답변: {r['suggested_reply']}")
**예상 출력** 
=== 긴급 문의 (urgent=True) ===
- [환불] 어제 받은 제품이 박살나서 왔어요. 당장 환불해주세요!
    추천답변: 파손 배송으로 불편을 드려 죄송합니다. 즉시 환불 처리 도와드리겠습니다.
- [결제] 카드가 세 번이나 중복 결제됐어요!
    추천답변: 중복 결제 확인 후 빠르게 환불해 드리겠습니다. 주문번호를 알려주세요.
**해설**: JSON 키를 하나 추가하는 것만으로 "분류 + 긴급도 + 요약 + 추천답변"을 한 번의 호출로 받습니다. `urgent`로 필터링하면 **긴급 건만 우선 처리**하는 배치 로직이 됩니다. 이런 구조화된 출력이 다음 단계(자동 라우팅, 도구 호출)의 입력이 됩니다.

정리

  • 문제 1로 혼동쌍 분석 → 경계 예시 추가 → 정확도 향상을 직접 확인했습니다.
  • 문제 2로 JSON 키 확장 → 긴급 건 자동 필터링을 구현했습니다.
