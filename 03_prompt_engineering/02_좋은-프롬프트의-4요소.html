좋은 프롬프트의 4요소 — 역할·지시·맥락·형식

한 줄 요약

좋은 프롬프트는 네 가지를 갖춥니다: 역할(Role)·지시(Instruction)·맥락(Context)·형식(Format). 이 4요소를 다 채우면 출력이 안정됩니다.

1. 4요소란?

요소 무엇을 정하나 예시
역할 (Role) AI가 누구인가 "너는 승승장구몰의 CS 분류 담당자다"
지시 (Instruction) 무엇을 하라는가 "아래 문의를 7개 중 하나로 분류하라"
맥락 (Context) 참고할 정보·제약 "카테고리: 배송/환불/교환/결제/상품문의/칭찬/불만"
형식 (Format) 어떻게 답하라는가 "카테고리 한 단어만, 다른 말 금지"

이 네 가지가 모이면, LLM은 "내가 누구이고(역할), 뭘 해야 하고(지시), 어떤 정보로(맥락), 어떻게 답할지(형식)"를 명확히 알게 됩니다. 그러면 결과가 들쭉날쭉할 이유가 없습니다.

비유: 신입사원에게 일을 시킬 때와 똑같습니다. "당신은 분류 담당입니다(역할). 이 문의를 분류하세요(지시). 카테고리는 이 7개입니다(맥락). 한 단어로만 답하세요(형식)." — 이렇게 시키면 누구든 일관되게 합니다.

2. 어디에 넣을까? (2강 복습)

2강에서 배운 요청 구조를 떠올려 봅시다.

  • 역할·지시·맥락 → 보통 system_instruction(시스템 지시)에
  • 처리할 실제 데이터 → contents(사용자 입력)에
from common import get_genai_client, GEMINI_MODEL
from google.genai import types

client = get_genai_client()

# 역할 + 지시 + 맥락(제약)을 시스템 지시에 담는다
ROLE = (
    "너는 승승장구몰의 친절한 CS 상담원이다. "          # 역할(Role)
    "고객 문의에 존댓말로 공감하며 간결하게 답하라. "    # 지시(Instruction)
    "확실하지 않은 정보는 '확인 후 안내드리겠습니다'라고 답하라."  # 맥락(Context: 제약)
)

def reply(content: str) -> str:
    """고객 문의에 ROLE 페르소나로 정중한 답변을 생성한다."""
    resp = client.models.generate_content(
        model=GEMINI_MODEL,
        contents=f"고객 문의: {content}",                  # 실제 데이터
        config=types.GenerateContentConfig(
            system_instruction=ROLE, temperature=0.3),
    )
    return resp.text

3. 실행해 보기

print(reply("카드 결제가 두 번 청구된 것 같아요. 확인 부탁드립니다."))

예상 출력

고객님, 불편을 드려 죄송합니다. 카드 이중 청구 건은 결제 내역을
확인 후 안내드리겠습니다. 주문번호를 알려주시면 빠르게 도와드리겠습니다.

세 번째 요소(맥락)에 넣은 안전장치 — "확실하지 않으면 확인 후 안내드리겠습니다" — 가 잘 작동해서, 모델이 함부로 단정하지 않고 정중히 답합니다. 이게 환각을 줄이는 효과도 냅니다(1강 복습).

4. 4요소 체크리스트

프롬프트를 쓸 때 스스로 물어보세요.

  • [ ] 역할: AI가 누구인지 정했는가?
  • [ ] 지시: 무엇을 하라는지 명확한가?
  • [ ] 맥락: 필요한 정보·제약(카테고리 목록 등)을 줬는가?
  • [ ] 형식: 어떻게 답할지(길이·형태) 정했는가?

네 개를 다 채울수록 결과가 안정됩니다. 특히 형식은 다음 단계에서 코드로 받아 쓰려면 필수입니다(04번 JSON 강제).

핵심 정리

  • 좋은 프롬프트 = 역할 + 지시 + 맥락 + 형식.
  • 역할·지시·맥락은 system_instruction에, 데이터는 contents에 넣는다.
  • 맥락에 "모르면 모른다"는 안전장치를 넣으면 환각이 준다.
  • 다음 절에서는 정확도를 끌어올리는 few-shot 기법을 배웁니다.
