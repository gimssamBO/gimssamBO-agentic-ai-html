JSON 출력 강제하기

한 줄 요약

에이전트는 LLM의 답을 다음 단계의 입력으로 씁니다. 그러려면 답이 사람 말이 아니라 기계가 읽는 구조(JSON) 여야 합니다. response_mime_type="application/json"으로 JSON만 나오도록 강제할 수 있습니다.

1. 왜 JSON이 필요한가

사람에게 보여 줄 답이면 자연어로 충분합니다. 하지만 그 답을 코드가 받아서 다음 일에 써야 한다면 이야기가 다릅니다.

# 자연어 답 — 코드가 쓰기 어렵다
"이 문의는 긴급한 환불 요청으로 보입니다."
# → 여기서 'category'와 'urgent'를 어떻게 뽑아내지? 매번 문장이 달라서 곤란.

# JSON 답 — 코드가 바로 쓴다
{"category": "환불", "urgent": true, "summary": "파손품 환불 요청"}
# → json.loads 하면 파이썬 dict! r["category"], r["urgent"] 로 즉시 사용

비유: 자연어 답은 손으로 쓴 메모, JSON 답은 빈칸이 정해진 양식 서류입니다. 서류는 "이름 칸", "금액 칸"이 정해져 있어 기계가 자동으로 처리할 수 있습니다.

2. 방법 ① — 프롬프트로 유도 (가장 단순)

그냥 "JSON으로만 답하라"고 시키고 json.loads로 파싱하는 방법입니다.

OpenAI

import json
messages = [
    {
        "role": "user",
        "content": (
            "다음 고객 문의를 분석해 JSON으로만 답하라.\n"
            "key: category, urgent, summary\n"
            "문의: 어제 받은 제품이 박살나서 왔어요."
        ),
    }
]
resp = client.chat.completions.create(model=OPENAI_MODEL, messages=messages)
data = json.loads(resp.choices[0].message.content)  # 운이 나쁘면 모델이 설명을 덧붙여 실패할 수 있음

Gemini

import json
contents = (
    "다음 고객 문의를 분석해 JSON으로만 답하라.\n"
    'key: category, urgent, summary\n'
    "문의: 어제 받은 제품이 박살나서 왔어요."
)
resp = client.models.generate_content(model=GEMINI_MODEL, contents=contents)
data = json.loads(resp.text)   # 운이 나쁘면 모델이 설명을 덧붙여 실패할 수 있음

단점: 모델이 가끔 다음과 같습니다: {...} 처럼 군더더기를 붙이면 json.loads가 깨집니다.

3. 방법 ② — response_mime_type으로 강제 (더 안전)

config에 response_mime_type="application/json"을 주면, 모델이 JSON만 내도록 강제됩니다. 군더더기가 사라져 json.loads가 항상 성공합니다.

OpenAI

import json
from common import get_openai_client, OPENAI_MODEL

client = get_openai_client()

def triage(content: str) -> dict:
    """문의를 분석해 category/urgent/summary 를 담은 dict로 돌려준다."""
    resp = client.chat.completions.create(
        model=OPENAI_MODEL,
        messages=[
            {
                "role": "user",
                "content": (
                    "다음 고객 문의를 분석해 JSON으로만 답하라.\n"
                    "키: category(배송/환불/교환/결제/상품문의/칭찬/불만 중 하나), "
                    "urgent(true/false), summary(20자 이내 한국어)\n"
                    f"문의: {content}"
                ),
            }
        ],
        temperature=0,
        response_format={"type": "json_object"},  # ← JSON만 출력하도록 강제
    )
    return json.loads(resp.choices[0].message.content)  # JSON 문자열 → 파이썬 dict

r = triage("어제 받은 제품이 박살나서 왔어요. 당장 환불해주세요!")
print(r)
print("긴급?", r["urgent"], "/ 분류:", r["category"])

Gemini

import json
from common import get_genai_client, GEMINI_MODEL
from google.genai import types

client = get_genai_client()

def triage(content: str) -> dict:
    """문의를 분석해 category/urgent/summary 를 담은 dict로 돌려준다."""
    resp = client.models.generate_content(
        model=GEMINI_MODEL,
        contents=(
            "다음 고객 문의를 분석해 JSON으로만 답하라.\n"
            "키: category(배송/환불/교환/결제/상품문의/칭찬/불만 중 하나), "
            "urgent(true/false), summary(20자 이내 한국어)\n"
            f"문의: {content}"
        ),
        config=types.GenerateContentConfig(
            temperature=0,
            response_mime_type="application/json",   # ← JSON만 출력하도록 강제
        ),
    )
    return json.loads(resp.text)   # JSON 문자열 → 파이썬 dict

r = triage("어제 받은 제품이 박살나서 왔어요. 당장 환불해주세요!")
print(r)
print("긴급?", r["urgent"], "/ 분류:", r["category"])

예상 출력

{'category': '환불', 'urgent': True, 'summary': '파손품 환불 요청'}
긴급? True / 분류: 환불

이렇게 나온 dict는 다음 단계의 도구 입력이 됩니다. 예를 들어 urgent가 True면 우선 처리 큐로 보내는 식이죠.

4. 방법 ③ — 스키마로 구조까지 못 박기 (한 단계 더)

response_schema에 Pydantic 모델이나 스키마를 주면, JSON의 키 이름과 타입까지 강제할 수 있습니다. (이 방식은 8강에서 LangChain의 with_structured_output으로 본격적으로 씁니다.)

OpenAI

from pydantic import BaseModel

class Triage(BaseModel):
    category: str
    urgent: bool
    summary: str

resp = client.beta.chat.completions.parse(
    model=OPENAI_MODEL,
    messages=[
        {"role": "user", "content": "어제 받은 제품이 박살나서 왔어요. 당장 환불해주세요!"}
    ],
    response_format=Triage,        # ← 키·타입까지 Pydantic 스키마로 강제 (Structured Outputs)
)

print(resp.choices[0].message.content)       # JSON 문자열 출력
# parsed 객체로 바로 접근도 가능:
# parsed_result: Triage = resp.choices[0].message.parsed

Gemini

from pydantic import BaseModel

class Triage(BaseModel):
    category: str
    urgent: bool
    summary: str

resp = client.models.generate_content(
    model=GEMINI_MODEL,
    contents="어제 받은 제품이 박살나서 왔어요. 당장 환불해주세요!",
    config=types.GenerateContentConfig(
        response_mime_type="application/json",
        response_schema=Triage,        # ← 키·타입까지 스키마로 강제
    ),
)
print(resp.text)   # Triage 구조에 정확히 맞는 JSON

세 방법 모두 본질은 같습니다 — "형식을 강제한다". 단순한 순서대로 ① 프롬프트 유도 → ② mime_type 강제 → ③ 스키마 강제 입니다. 실무에서는 ②, ③을 주로 씁니다.

핵심 정리

  • 답을 코드로 쓰려면 JSON처럼 구조화된 형식이 필요하다.
  • response_mime_type="application/json"으로 JSON만 나오게 강제할 수 있다(군더더기 제거).
  • response_schema로 키·타입까지 못 박을 수 있다(→ 8강 심화).
  • JSON 결과(dict)는 다음 단계의 도구 입력이 된다.
