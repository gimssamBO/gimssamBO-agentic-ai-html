실습문제와 해답

직접 코드를 고쳐 보며 20강 내용을 손에 익힙니다. 먼저 스스로 풀어 본 뒤 해답을 펼쳐 보세요. (이 실습은 GOOGLE_API_KEY가 필요합니다.)

문제 1 — 프로필 읽기/쓰기 도구 작성

get_profile(user_id)와 update_profile(user_id, key, value) 두 도구를 직접 작성해 에이전트에 붙이세요.

  • 두 도구는 data/user_profiles.json을 읽고 씁니다.
  • 기대 결과: "내 선호 카테고리를 가전으로 바꿔줘" 호출 후 JSON 파일의 해당 사용자 선호카테고리가 실제로 가전으로 변경되면 성공.
해답 보기 
import sys, pathlib, json, shutil
sys.path.append(str(pathlib.Path(__file__).resolve().parent))
from common import get_chat, DATA
from langchain_core.tools import tool
from langchain.agents import create_agent

STORE = DATA / "user_profiles_rw.json"
SRC = DATA / "user_profiles.json"

def _load():
    if not STORE.exists():
        shutil.copy(SRC, STORE)
    return json.load(open(STORE, encoding="utf-8"))

def _save(data):
    json.dump(data, open(STORE, "w", encoding="utf-8"), ensure_ascii=False, indent=2)

@tool
def get_profile(user_id: str) -> str:
    """고객ID로 프로필을 조회한다."""
    return json.dumps(_load().get(user_id, {}), ensure_ascii=False)

@tool
def update_profile(user_id: str, key: str, value: str) -> str:
    """프로필의 한 항목을 갱신해 영속 저장한다."""
    data = _load()
    data.setdefault(user_id, {})[key] = value
    _save(data)
    return f"{user_id}의 {key}를 {value}로 저장했습니다."

agent = create_agent(get_chat(temperature=0), tools=[get_profile, update_profile],
    system_prompt="너는 상담원이다. 선호를 말하면 update_profile로 저장하라.")

out = agent.invoke({"messages": [{"role": "user",
    "content": "나 C0001인데 선호 카테고리를 가전으로 바꿔줘"}]})
print(out["messages"][-1].content)

# 파일에서 검증
print("파일 확인:", _load()["C0001"].get("선호카테고리"))
**예상 출력** 
네, C0001님의 선호 카테고리를 가전으로 변경했습니다.
파일 확인: 가전
**해설**: `update_profile`이 호출되면서 `_save`로 파일에 쓰였고, 파일을 다시 읽으니 "가전"으로 바뀐 게 확인됩니다. 핵심은 `_save`가 **디스크에 쓰기** 때문에 변경이 영속된다는 것입니다. 에이전트가 "선호를 말하면 저장하라"는 지침에 따라 알아서 도구를 호출했죠.

문제 2 — 세션 종료 후에도 기억

스크립트를 두 번 실행하는 시나리오를 만드세요. 1차에서 update_profile로 관심사를 저장하고, 2차(재시작 가정)에서 get_profile로 그 값을 읽어 답하세요.

  • 사용 파일: data/user_profiles.json
  • 기대 결과: 재실행 후에도 1차에서 저장한 값이 답변에 나타나면 성공.
해답 보기 
import sys, pathlib, json, shutil
sys.path.append(str(pathlib.Path(__file__).resolve().parent))
from common import DATA

STORE = DATA / "user_profiles_rw.json"
SRC = DATA / "user_profiles.json"

def _load():
    if not STORE.exists():
        shutil.copy(SRC, STORE)
    return json.load(open(STORE, encoding="utf-8"))

def _save(data):
    json.dump(data, open(STORE, "w", encoding="utf-8"), ensure_ascii=False, indent=2)

import sys as _s
# 실행 인자로 단계 구분: python script.py 1  /  python script.py 2
phase = _s.argv[1] if len(_s.argv) > 1 else "1"

if phase == "1":
    # 1차 실행: 관심사 저장
    data = _load()
    data.setdefault("C0001", {})["관심사"] = "캠핑 용품"
    _save(data)
    print("[1차 실행] C0001 관심사를 '캠핑 용품'으로 저장하고 종료합니다.")
else:
    # 2차 실행 (재시작 가정): 저장한 값 읽기
    data = _load()
    관심사 = data.get("C0001", {}).get("관심사", "(없음)")
    print(f"[2차 실행] 재시작 후 읽은 C0001 관심사: {관심사}")
    print("→ 프로그램을 껐다 켰는데도 값이 살아있음 = 장기 기억!")
**실행 방법과 출력** 
$ python script.py 1
[1차 실행] C0001 관심사를 '캠핑 용품'으로 저장하고 종료합니다.

$ python script.py 2        ← 프로그램 완전히 새로 실행
[2차 실행] 재시작 후 읽은 C0001 관심사: 캠핑 용품
→ 프로그램을 껐다 켰는데도 값이 살아있음 = 장기 기억!
**해설**: 1차 실행에서 파일에 "캠핑 용품"을 저장하고 **프로그램을 완전히 종료**했습니다. 그 다음 2차 실행(완전히 새 프로세스)에서 그 값을 읽으니, **그대로 살아 있습니다.** 만약 단기 기억(InMemorySaver, 메모리)이었다면 1차 종료 시 다 사라져 2차에서 "(없음)"이 나왔을 겁니다. 하지만 파일(장기 기억)은 디스크에 영속되니, 프로세스가 바뀌어도 유지되죠. 이게 19강(단기)과 20강(장기)의 결정적 차이를 가장 명확히 보여 주는 실험입니다.

정리

  • 문제 1로 프로필 읽기/쓰기 도구를 만들어 파일 변경을 확인했습니다.
  • 문제 2로 프로그램 재시작 후에도 유지되는 장기 기억을 검증했습니다.

이것으로 20강과 3부(RAG·메모리)를 마칩니다. 다음 21강부터 4부 — 워크플로우와 멀티 에이전트로 들어갑니다!
