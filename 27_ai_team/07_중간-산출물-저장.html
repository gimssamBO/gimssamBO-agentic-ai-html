[신규] 중간 산출물 저장

한 줄 요약

파이프라인이 만든 중간 산출물(정리된 사실·분석·리포트)을 화면에만 띄우고 버리지 말고, 파일로 남깁니다. 디스크에 저장하면 디버깅·재현·감사(누가 무엇을 만들었나)에 큰 도움이 됩니다. 각 노드를 감싸는 저장 래퍼 노드로 깔끔하게 구현합니다.

실습 파일: sections/27_ai_team/07_중간-산출물-저장.py

1. 왜 중간 산출물을 저장하나

지금까지는 최종 report만 화면에 출력하고 끝이었습니다. 중간 결과(raw, analysis)는 사라지죠. 하지만 실무에선 중간물이 중요합니다.

- 디버깅: 리포트가 이상하다 → 분석이 문제였나? 사실 정리가 문제였나?
          중간물이 있어야 어느 단계에서 틀렸는지 추적 가능
- 재현:   같은 입력으로 다시 안 돌려도, 저장된 중간물을 재사용
- 감사:   "이 리포트는 어떤 사실·분석을 근거로 나왔나" 를 파일로 증빙
- 운영:   산출물을 로그처럼 쌓아두는 운영 자산

특히 LLM 파이프라인은 매 실행이 비용이라, 중간물을 저장해두면 다시 안 돌려도 됩니다.

2. 저장 함수 — 타임스탬프 파일로

산출물 한 건을 reports/ 폴더에 타임스탬프 이름으로 저장합니다.

import datetime
from common import ROOT          # 프로젝트 루트 경로 (common.py 제공)

REPORTS = ROOT / "reports"       # 산출물을 코드와 분리해 한 폴더에 모음


def save_artifact(name: str, content: str, ext: str = "md") -> pathlib.Path:
    """산출물 한 건을 reports/ 아래 타임스탬프 파일로 저장하고 경로를 반환한다."""
    REPORTS.mkdir(parents=True, exist_ok=True)        # reports/ 자동 생성
    stamp = datetime.datetime.now().strftime("%Y%m%d_%H%M%S")
    path = REPORTS / f"{stamp}_{name}.{ext}"
    path.write_text(content, encoding="utf-8")        # 한글 안전하게 utf-8
    print(f"  [저장] {name} → {path}")
    return path
  • REPORTS.mkdir(parents=True, exist_ok=True) — 폴더가 없으면 만들고, 있으면 그냥 넘어감(에러 안 남).
  • datetime.now().strftime("%Y%m%d_%H%M%S") — 20260607_143022 같은 시각 도장. 실행마다 다른 파일명이 되어 덮어쓰기 방지.
  • write_text(..., encoding="utf-8") — 한글이 깨지지 않게 인코딩 지정.

산출물을 코드와 섞지 않고 reports/ 한 폴더에 모으는 게 포인트입니다. 로그처럼 쌓이는 운영 자산으로 관리하는 거죠.

3. 저장 래퍼 노드 — 기존 노드를 감싸기

기존 노드를 수정하지 않고, 실행 후 저장만 덧붙이는 래퍼 노드를 만듭니다.

from ch27_ai_team import (              # 기존 노드 그대로 재사용
    TeamState as BaseState,
    researcher, analyst, writer, load_competitor_text,
)


def researcher_save(state: BaseState) -> dict:
    """Researcher 실행 → 정리된 사실(raw)을 .txt로 저장."""
    upd = researcher(state)                            # 기존 노드 그대로 실행
    save_artifact("01_raw", upd["raw"], ext="txt")     # 산출물 저장
    return upd


def analyst_save(state: BaseState) -> dict:
    """Analyst 실행 → 분석 결과(analysis)를 .md로 저장."""
    upd = analyst(state)
    save_artifact("02_analysis", upd["analysis"])
    return upd


def writer_save(state: BaseState) -> dict:
    """Writer 실행 → 최종 리포트(report)를 .md로 저장."""
    upd = writer(state)
    save_artifact("03_report", upd["report"])
    return upd

설계 포인트 — 각 래퍼는 기존 노드 실행 → 결과 저장 → 결과 반환. 기존 researcher/analyst/writer는 건드리지 않습니다. 저장이라는 부가 기능을 덧입히는 거죠(데코레이터 패턴의 정신). 파일명에 01_, 02_, 03_ 접두사를 붙여 단계 순서를 드러냅니다.

4. 그래프 조립과 실행

흐름은 27강 원본과 똑같고, 노드만 저장 래퍼로 바꿉니다.

def build_team():
    """저장 래퍼 노드로 묶은 파이프라인(흐름은 27강과 동일)."""
    g = StateGraph(BaseState)
    g.add_node("researcher", researcher_save)   # 래퍼 노드 등록
    g.add_node("analyst", analyst_save)
    g.add_node("writer", writer_save)

    g.add_edge(START, "researcher")
    g.add_edge("researcher", "analyst")
    g.add_edge("analyst", "writer")
    g.add_edge("writer", END)
    return g.compile()


if __name__ == "__main__":
    team = build_team()
    initial = {"raw": load_competitor_text(), "analysis": "", "report": ""}
    print(f"저장 위치: {REPORTS}")
    final = initial
    for state in team.stream(initial, stream_mode="values"):
        final = state
    print(final["report"])

예상 출력

저장 위치: /.../reports
  [저장] 01_raw → /.../reports/20260607_143022_01_raw.txt
  [저장] 02_analysis → /.../reports/20260607_143041_02_analysis.md
  [저장] 03_report → /.../reports/20260607_143103_03_report.md
# 승승장구몰 경쟁사 분석 리포트 ...

실행 후 reports/ 폴더에 3개 파일이 단계별로 쌓입니다. 리포트가 이상하면 02_analysis.md를 열어 "분석이 부실했나"를 바로 확인할 수 있죠.

5. 응용 — 한 폴더로 묶기

실행마다 타임스탬프가 달라 파일이 흩어진다면, 실행 단위 폴더로 묶을 수도 있습니다.

# 한 번 실행 = 한 폴더 (선택적 개선)
run_dir = REPORTS / datetime.datetime.now().strftime("%Y%m%d_%H%M%S")
run_dir.mkdir(parents=True, exist_ok=True)
# 이후 save_artifact가 run_dir 아래에 01_raw, 02_analysis, 03_report 저장

이러면 reports/20260607_143022/ 안에 그 실행의 산출물 3개가 모입니다. "이 실행의 결과물 묶음"을 한눈에 보기 좋죠. (29강 운영 로깅과 연결되는 발상입니다.)

핵심 정리

  • 중간 산출물을 파일로 저장하면 디버깅·재현·감사·운영에 유리.
  • save_artifact: reports/에 타임스탬프 파일로 저장(mkdir(exist_ok=True), utf-8).
  • 저장 래퍼 노드: 기존 노드를 감싸 실행 → 저장 → 반환 — 원본 노드는 안 건드림.
  • 흐름(그래프)은 원본과 동일, 노드만 래퍼로 교체.
