정리 & 체크리스트

24강에서 배운 것

24강에서는 데이터를 사람이 읽는 보고서로 자동 변환하는 비즈니스 리포트 에이전트를 만들었습니다.

  • 핵심 원칙: 계산은 코드(pandas), 서술은 LLM — 산술 환각 방지.
  • facts 집계: 최신 달 총매출·증감률·카테고리 1·2위를 코드로 정확히.
  • 서술 위임: facts를 프롬프트에 박아 넣고 "새 숫자 금지" → LLM은 글만.
  • 단일 진입점: generate_monthly_report() 한 함수로 배치·API 공유.
  • [신규] 예외 처리: load_facts_safe로 파일 없음·컬럼 변경에 죽지 않게.
  • [신규] 차트 시각화: matplotlib로 막대그래프 png + 리포트에 이미지 삽입.

한눈에 보는 핵심 코드

import pandas as pd

# 1) 계산은 코드 — facts(단일 진실)
def load_facts():
    df = pd.read_csv(DATA / "monthly_sales.csv").sort_values("month").reset_index(drop=True)
    cur, prev = df.iloc[-1], df.iloc[-2]
    growth = (cur["total"] - prev["total"]) / prev["total"] * 100
    return {"month": cur["month"], "total": int(cur["total"]),
            "growth_pct": round(growth, 1), "by_category": {...}}

# 2) 서술은 LLM — facts만 주고 "새 숫자 금지"
def write_report(facts):
    return get_chat(temperature=0.3).invoke(
        f"아래 확정 수치만 근거로 보고서를 써라. 숫자를 지어내지 마라.\n"
        f"총매출 {facts['total']:,}원, 전월 대비 {facts['growth_pct']}%...").content

# 3) 단일 진입점
def generate_monthly_report():
    facts = load_facts(); body = write_report(facts); return save_report(facts, body)

# [신규] 예외 처리 — 항상 dict 반환(ok 플래그)
facts = load_facts_safe()
if not facts["ok"]:
    notify_admin(facts["error"])      # 죽지 말고 알림
else:
    save_report(facts, write_report(facts))

# [신규] 차트 — 계산은 코드, facts로 그림
matplotlib.use("Agg")                 # 화면 없는 배치 대응
ax.bar(cats, [v/10000 for v in facts["by_category"].values()])
plt.savefig(REPORTS_DIR / f"chart_{facts['month']}.png"); plt.close(fig)

체크리스트

  • [ ] "계산은 코드, 서술은 LLM" 원칙을 설명할 수 있다.
  • [ ] pandas로 핵심 수치(facts)를 정확히 집계했다.
  • [ ] facts를 근거로 LLM이 마크다운 리포트를 작성하게 했다(새 숫자 금지).
  • [ ] 단일 함수(generate_monthly_report)로 배치·엔드포인트화할 수 있다.
  • [ ] 파일 없음·컬럼 변경 등에 죽지 않는 예외 처리를 구현했다.
  • [ ] 차트 png를 만들어 리포트에 이미지로 삽입했다.

한 줄 핵심

비즈니스 리포트는 "계산은 코드, 서술은 LLM"으로 나눈다. 숫자는 facts로 확정해 환각을 막고, 배치는 예외에 죽지 않게 감싸며, 글에 차트를 더해 한눈에 보이게 한다.
