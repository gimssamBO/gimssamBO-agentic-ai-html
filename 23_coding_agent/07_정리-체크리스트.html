정리 & 체크리스트

23강에서 배운 것

23강에서는 LLM이 코드를 읽고 버그를 고치는 코딩 에이전트를 만들었습니다.

  • 핵심 루프: 읽기 → 수정 → 실행 → 오류 확인.
  • 실행 검증: "고쳤다는 말"이 아니라 실제 실행 + 종료코드로 객관적 판정.
  • 코드 추출: LLM 응답에서 정규식으로 코드블록만 뽑아 SyntaxError 방지.
  • 격리 실행: subprocess + timeout으로 무한루프·부작용 차단.
  • 원본 보존: 수정은 새 파일에, 원본은 비교·복구 기준으로 그대로.
  • [신규] 재귀적 버그 수정: 오류를 다시 피드백해 자동 재수정(self-debugging, 상한 필수).

한눈에 보는 핵심 코드

import sys, subprocess, re

def extract_code(text):                          # LLM 응답에서 코드블록만 추출
    m = re.search(r"```(?:python)?\s*(.*?)```", text, re.DOTALL)
    return (m.group(1) if m else text).strip()

def ask_fix(source, error=""):                   # 버그 수정 요청(오류 있으면 피드백)
    llm = get_chat(temperature=0)                # 코드 수정은 일관·정확 → 0
    fb = f"\n[직전 오류]\n{error[:1500]}" if error else ""
    return extract_code(llm.invoke(
        f"버그를 고친 전체 코드만 코드블록으로 출력하라.{fb}\n```python\n{source}\n```").content)

def run_code(code):                              # 새 파일 저장 → 격리 실행 → 종료코드
    FIXED.write_text(code, encoding="utf-8")
    p = subprocess.run([sys.executable, str(FIXED)],
                       cwd=str(ROOT), capture_output=True, text=True, timeout=60)
    return p.returncode, p.stdout + p.stderr

# 재귀 루프 (self-debugging)
source, error = read_code(TARGET), ""
for i in range(MAX_TRIES):                        # 상한 필수!
    fixed = ask_fix(source, error)
    code, out = run_code(fixed)
    if code == 0: break                           # 성공
    error, source = out, fixed                    # 오류 피드백 + 수정본 누적

#   subprocess, re, pathlib, sys : 파이썬 표준 라이브러리
#   get_chat (Gemini)           : 2강에서 설치한 langchain-google-genai
모듈 용도 비고
subprocess 수정 코드 격리 실행 표준 라이브러리
re 코드블록 추출 표준 라이브러리
pathlib 파일 경로·읽기·쓰기 표준 라이브러리

23강은 새로 설치할 라이브러리가 없습니다. LLM 호출(get_chat) 외에는 전부 파이썬 표준 라이브러리로 구현됩니다.

체크리스트

  • [ ] 코딩 에이전트의 생성→실행→오류확인 루프를 설명할 수 있다.
  • [ ] LLM 응답에서 코드블록만 추출해 새 파일로 저장했다.
  • [ ] subprocess로 실행해 종료코드로 성공을 검증했다.
  • [ ] 원본 보존·타임아웃 등 안전장치의 필요성을 안다.
  • [ ] 오류를 다시 피드백하는 재귀적 버그 수정을 구현했다.
  • [ ] 무한 재시도를 막는 횟수 상한(MAX_TRIES)의 필요성을 안다.

한 줄 핵심

코딩 에이전트는 "만들고 끝"이 아니라 "만들고 실행해 검증"한다. 원본은 보존하고, 실패하면 오류를 피드백해 재수정하되, 반드시 시도 횟수에 상한을 둔다.
