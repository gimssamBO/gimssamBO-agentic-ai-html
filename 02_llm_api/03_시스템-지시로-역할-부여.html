시스템 지시로 역할 부여

한 줄 요약

시스템 지시(system instruction) 는 모델에게 미리 주는 "너는 누구이고, 어떻게 답해야 한다"는 규칙입니다. 같은 질문이라도 시스템 지시만 바꾸면 말투·성격·답변 형식이 통째로 바뀝니다.

1. 시스템 지시란?

대화에는 두 종류의 말이 있습니다.

  • 사용자 지시(user): 그때그때 던지는 질문 — "환불 얼마나 걸려요?"
  • 시스템 지시(system): 대화 전체에 깔리는 기본 규칙 — "너는 친절한 상담원이고, 항상 존댓말로 답해."

비유하자면, 시스템 지시는 배우에게 주는 배역 설명서입니다. "당신은 무뚝뚝한 형사입니다"라고 정해 두면, 어떤 대사를 쳐도 그 캐릭터를 유지하죠. 사용자 질문이 바뀌어도 역할은 그대로 유지됩니다.

2. 코드로 역할 입히기

config의 system_instruction에 역할을 적습니다.

from common import get_genai_client, GEMINI_MODEL
from google.genai import types

client = get_genai_client()

def chat(system: str, user: str, temperature: float = 0.3) -> str:
    """시스템 지시(system)와 사용자 입력(user)을 받아 답변 텍스트를 돌려준다."""
    resp = client.models.generate_content(
        model=GEMINI_MODEL,
        contents=user,                                    # 사용자 질문
        config=types.GenerateContentConfig(
            system_instruction=system,                    # ← 역할/규칙
            temperature=temperature,
        ),
    )
    return resp.text

이제 같은 질문에 다른 역할을 입혀 봅니다.

q = "환불 얼마나 걸려요?"

print("[친절한 상담원]")
print(chat("너는 승승장구몰의 친절한 CS 상담원이다. 존댓말로 간결히 답하라.", q))

print("\n[무뚝뚝한 엔지니어]")
print(chat("너는 무뚝뚝한 엔지니어다. 핵심만 한 줄로 답하라.", q))

예상 출력

[친절한 상담원]
안녕하세요 고객님! 환불은 영업일 기준 평균 3~5일 정도 소요됩니다. 도움이 더 필요하시면 말씀해 주세요 :)

[무뚝뚝한 엔지니어]
환불 3~5영업일.

질문은 똑같은데 말투·길이·태도가 완전히 달라졌습니다. 이게 시스템 지시의 힘입니다.

3. 좋은 시스템 지시 작성법

시스템 지시는 보통 세 가지를 담으면 좋습니다.

요소 예시
역할(누구) "너는 승승장구몰의 CS 상담원이다."
태도(어떻게) "항상 존댓말로 공감하며 간결히 답하라."
안전장치(모르면) "확실하지 않으면 '확인 후 안내드리겠습니다'라고 답하라." 
ROLE = (
    "너는 승승장구몰의 친절한 CS 상담원이다. "          # 역할
    "고객 문의에 존댓말로 공감하며 간결하게 답하라. "    # 태도
    "확실하지 않은 정보는 '확인 후 안내드리겠습니다'라고 답하라."  # 안전장치
)

세 번째 "안전장치"가 특히 중요합니다. 환각을 줄이는 첫 번째 방어선이기 때문입니다(1강 4절 참고). "모르면 모른다고 말하라"는 지시 한 줄이 엉뚱한 답을 크게 줄입니다.

4. 시스템 지시 vs 사용자 지시, 무엇이 우선인가

시스템 지시는 사용자 지시보다 우선하도록 설계돼 있습니다. 그래서 "너는 존댓말만 쓴다"는 시스템 지시가 있으면, 사용자가 "반말로 해"라고 해도 어느 정도 존댓말을 유지하려 합니다. (단, 100% 보장은 아닙니다. 악의적으로 규칙을 깨려는 입력을 프롬프트 인젝션이라 하며, 3강에서 방어법을 배웁니다.)

핵심 정리

  • 시스템 지시 = 대화 전체에 깔리는 역할·규칙. system_instruction에 적는다.
  • 같은 질문도 시스템 지시에 따라 말투·형식이 통째로 바뀐다.
  • 좋은 지시는 역할 + 태도 + 안전장치(모르면 모른다) 를 담는다.
  • 다음 절에서는 비용의 단위인 토큰을 배웁니다.
