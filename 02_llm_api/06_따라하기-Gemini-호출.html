2. 재사용할 chat() 함수

시스템 지시와 사용자 입력을 받아 답을 돌려주는 함수입니다. 03번에서 본 그 함수입니다.

OpenAI

def chat(system: str, user: str, temperature: float = 0.3) -> str:
    """시스템 지시(system)와 사용자 입력(user)을 받아 답변 텍스트를 돌려준다.

    핵심은 messages와 파라미터 두 가지다.
      - role 'system': 모델의 '역할·말투'를 지정.
      - temperature: 생성의 무작위성(0=일관, 높을수록 다양).
    """
    resp = client.chat.completions.create(
        model=OPENAI_MODEL,
        messages=[
            {"role": "system", "content": system},
            {"role": "user", "content": user},
        ],
        temperature=temperature,
    )
    return resp.choices[0].message.content

Gemini

def chat(system: str, user: str, temperature: float = 0.3) -> str:
    """시스템 지시(system)와 사용자 입력(user)을 받아 답변 텍스트를 돌려준다.

    핵심은 config 안의 두 가지다.
      - system_instruction: 모델의 '역할·말투'를 지정.
      - temperature: 생성의 무작위성(0=일관, 높을수록 다양).
    """
    resp = client.models.generate_content(
        model=GEMINI_MODEL,
        contents=user,
        config=types.GenerateContentConfig(
            system_instruction=system, temperature=temperature),
    )
    return resp.text

3. (4-1) 기본 호출 + 토큰 확인

OpenAI

# 시스템 지시 없이 가장 단순하게 호출. temperature=0.7 로 다양한 홍보 문구를 유도.
resp = client.chat.completions.create(
    model=OPENAI_MODEL,
    messages=[{"role": "user", "content": "승승장구몰을 한 문장으로 홍보해줘."}],
    temperature=0.7,
)
print("답변:", resp.choices[0].message.content)
# usage = 이번 호출에 쓴 토큰 수(prompt/응답/합계). 토큰이 곧 과금 기준이다.
print("토큰:", resp.usage)

Gemini

# 시스템 지시 없이 가장 단순하게 호출. temperature=0.7 로 다양한 홍보 문구를 유도.
resp = client.models.generate_content(
    model=GEMINI_MODEL,
    contents="승승장구몰을 한 문장으로 홍보해줘.",
    config=types.GenerateContentConfig(temperature=0.7),

# usage_metadata = 이번 호출에 쓴 토큰 수(prompt/응답/합계). 토큰이 곧 과금 기준이다.
print("토큰:", resp.usage_metadata)

6. 무엇을 확인했나

  • OpenAI 한 번의 호출에 model·messages·roll·content·temperature·max_tokens를 어떻게 채우는지
  • Gemini 한 번의 호출에 model·contents·config를 어떻게 채우는지
  • 시스템 지시로 말투가 어떻게 바뀌는지
  • useage(OpenAI), usage_metadata(Gemini)로 토큰(=비용)을 어떻게 확인하는지

이 세 가지가 모든 LLM 호출의 기본기입니다. 다음 절에서는 똑같은 구조를 OpenAI(GPT) 로도 호출해, "구조는 같다"는 것을 직접 봅니다.

핵심 정리

  • chat(system, user, temperature) 한 함수로 대부분의 호출을 재사용할 수 있다.
  • OpenAI messages의 system 역할에 시스템 지시를, 매개변수로 온도를 전달하며, 응답에서 choices[0].message.content·usage를 꺼낸다.
  • Gemini config에 시스템 지시·온도를, 응답에서 text·usage_metadata를 꺼낸다.
  • 다음 절: 같은 일을 OpenAI SDK로 해 보며 모델 교체를 연습합니다.
