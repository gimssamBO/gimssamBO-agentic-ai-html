temperature와 생성 제어

한 줄 요약

temperature(온도)는 답변의 무작위성을 조절하는 손잡이입니다.
0에 가까우면 일관되고 안정적, 높으면 다양하고 창의적입니다. 분류·계산 같은 일은 0, 홍보 문구·아이디어 같은 일은 0.7처럼 씁니다.

1. temperature란

1강에서 LLM은 "다음에 올 가장 그럴듯한 단어"를 고른다고 했습니다. 이때 얼마나 모험적으로 고를지를 정하는 게 temperature입니다.

  • 낮은 temperature(0~0.2): 항상 "가장 확률 높은 단어"만 고름 → 매번 거의 같은 답 (일관·안정)
  • 높은 temperature(0.7~1.0): 확률이 좀 낮은 단어도 과감히 시도 → 다양하고 창의적인 답

비유: temperature는 주사위의 크기입니다. 0이면 주사위를 안 던지고 늘 1번 답만 말합니다. 높을수록 큰 주사위를 굴려 색다른 답이 나올 여지를 줍니다.

2. 작업마다 적절한 온도가 다르다

작업 유형 권장 temperature 이유
분류, 추출, 계산 0 정답이 정해져 있어 일관성이 중요
일반 상담, 설명 0.3 자연스럽되 너무 튀지 않게
홍보 문구, 아이디어 0.7 ~ 1.0 다양성이 곧 가치

에이전트에서 도구를 고르거나 데이터를 분류하는 일은 거의 항상 temperature=0을 씁니다. "이 질문은 환불 카테고리"라는 판단이 호출할 때마다 바뀌면 곤란하니까요.

3. 코드로 온도의 효과 보기

같은 질문을 온도만 바꿔 여러 번 호출해, 답이 얼마나 다양해지는지 봅니다.

code/ch02_temperature.py

Openai

from common import get_openai_client, OPENAI_MODEL

client = get_openai_client()

def promote(temperature: float) -> str:
    resp = client.chat.completions.create(
        model=OPENAI_MODEL,
        messages=[{"role": "user", "content": "승승장구몰을 한 문장으로 홍보해줘."}],
        temperature=temperature,
    )
    return resp.choices[0].message.content

# 온도 0: 여러 번 불러도 거의 같은 답
print("[temperature=0]")
for _ in range(3):
    print("-", promote(0.0))

# 온도 1.0: 부를 때마다 색다른 답
print("\n[temperature=1.0]")
for _ in range(3):
    print("-", promote(1.0))

제미나이

from common import get_genai_client, GEMINI_MODEL
from google.genai import types

client = get_genai_client()

def promote(temperature: float) -> str:
    resp = client.models.generate_content(
        model=GEMINI_MODEL,
        contents="승승장구몰을 한 문장으로 홍보해줘.",
        config=types.GenerateContentConfig(temperature=temperature),
    )
    return resp.text

# 온도 0: 여러 번 불러도 거의 같은 답
print("[temperature=0]")
for _ in range(3):
    print("-", promote(0.0))

# 온도 1.0: 부를 때마다 색다른 답
print("\n[temperature=1.0]")
for _ in range(3):
    print("-", promote(1.0))

온도 0에서는 답이 거의 고정, 온도 1.0에서는 매번 다릅니다. 이 차이를 숫자로 재는 게 이 강의 연습문제(09번)입니다.

4. 다른 생성 파라미터(맛보기)

temperature 외에도 답변을 통제하는 설정이 있습니다. 지금은 이름만 알아두면 됩니다.

OpenAI

  • max_tokens(또는 max_completion_tokens): 답변 최대 길이(토큰). 길이를 강제로 잘라 비용을 통제.
  • top_p / top_k: OpenAI는 미지원. 보통 temperature만으로 충분.
resp = client.chat.completions.create(
    model=OPENAI_MODEL,
    messages=[
        {"role": "system", "content": "너는 친절한 상담원이다."},
        {"role": "user", "content": "환불 얼마나 걸려요?"},
    ],
    temperature=0.3,
    max_tokens=200,  # 답변을 200토큰 이내로 제한 (최신 SDK는 max_completion_tokens도 지원)
)

Gemini

  • max_output_tokens(Gemini): 답변 최대 길이(토큰). 길이를 강제로 잘라 비용을 통제.
  • top_p / top_k: temperature와 비슷하게 "후보 단어 범위"를 좁히는 방법. 보통 temperature만으로 충분.
config = types.GenerateContentConfig(
    system_instruction="너는 친절한 상담원이다.",
    temperature=0.3,
    max_output_tokens=200,   # 답변을 200토큰 이내로 제한
)

핵심 정리

  • temperature는 답변의 무작위성을 조절한다. 낮으면 일관, 높으면 다양.
  • 분류·도구 선택·계산 = 0, 상담 = 0.3, 창작 = 0.7~1.0.
  • max_tokens(OpenAI),max_output_tokens(Gemini)로 답변 길이(=비용)도 제한할 수 있다.
