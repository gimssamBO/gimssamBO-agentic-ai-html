문제 1 — temperature 다양성 측정 스크립트

code/ch02_llm_api.py에 함수 diversity(temp) 를 추가하세요.

  • 같은 질문 "승승장구몰을 한 문장으로 홍보해줘." 를 주어진 temperature로 5번 호출합니다.
  • 답변 5개를 리스트에 모으고, len(set(답변리스트))(중복 제거 후 개수)를 출력합니다.
  • diversity(0.0) 과 diversity(1.0) 을 각각 실행합니다.
  • 기대 결과: 0.0일 때는 고유 답변 수가 1에 가깝고, 1.0일 때는 더 큰 수가 나와 temperature가 다양성을 키운다는 것이 숫자로 확인되면 성공.
해답 보기 
import sys, pathlib
sys.path.append(str(pathlib.Path(__file__).resolve().parent))
from common import get_genai_client, GEMINI_MODEL
from google.genai import types

client = get_genai_client()

def diversity(temp: float) -> int:
    """같은 질문을 temp로 5번 호출해, 서로 다른 답이 몇 개인지 센다."""
    answers = []
    for _ in range(5):
        resp = client.models.generate_content(
            model=GEMINI_MODEL,
            contents="승승장구몰을 한 문장으로 홍보해줘.",
            config=types.GenerateContentConfig(temperature=temp),
        )
        answers.append(resp.text.strip())
    unique = len(set(answers))          # 중복 제거 후 개수 = 다양성 지표
    print(f"temperature={temp}: 고유 답변 {unique}/5개")
    return unique

if __name__ == "__main__":
    diversity(0.0)   # 거의 같은 답 → 1에 가까움
    diversity(1.0)   # 매번 다른 답 → 더 큰 수
**예상 출력** 
temperature=0.0: 고유 답변 1/5개
temperature=1.0: 고유 답변 5/5개
**해설**: `set()`은 중복을 제거하므로, 답이 다양할수록 길이가 커집니다. `temperature=0`은 "가장 확률 높은 단어"만 골라 매번 같은 답을, `1.0`은 모험적으로 골라 다른 답을 만듭니다. 다양성을 **숫자로** 측정한 셈입니다.

문제 2 — 초등학생 말투 + 토큰 비교

기존 chat() 함수를 활용해 다음을 수행하세요.

  • system 인자에 "너는 초등학생도 이해하도록 쉬운 단어와 짧은 문장으로만 설명한다." 를 넣어 "환불 얼마나 걸려요?" 에 답하게 합니다.
  • chat() 이 답변과 함께 total_token_count 도 반환하도록 수정합니다.
  • "친절한 상담원" 말투와 "초등학생" 말투의 총 토큰 수를 함께 출력합니다.
  • 기대 결과: 두 말투의 답변과 각각의 토큰 수가 나란히 출력되면 성공.
해답 보기 
import sys, pathlib
sys.path.append(str(pathlib.Path(__file__).resolve().parent))
from common import get_genai_client, GEMINI_MODEL
from google.genai import types

client = get_genai_client()

def chat(system: str, user: str, temperature: float = 0.3):
    """답변 텍스트와 총 토큰 수를 함께 돌려주도록 수정한 버전."""
    resp = client.models.generate_content(
        model=GEMINI_MODEL,
        contents=user,
        config=types.GenerateContentConfig(
            system_instruction=system, temperature=temperature),
    )
    # (답변, 총 토큰 수) 튜플로 반환
    return resp.text, resp.usage_metadata.total_token_count

if __name__ == "__main__":
    q = "환불 얼마나 걸려요?"

    text1, tok1 = chat("너는 승승장구몰의 친절한 CS 상담원이다. 존댓말로 간결히 답하라.", q)
    text2, tok2 = chat("너는 초등학생도 이해하도록 쉬운 단어와 짧은 문장으로만 설명한다.", q)

    print(f"[친절한 상담원] (토큰 {tok1})\n{text1}\n")
    print(f"[초등학생 말투] (토큰 {tok2})\n{text2}")
**예상 출력** 
[친절한 상담원] (토큰 95)
안녕하세요 고객님! 환불은 영업일 기준 평균 3~5일 정도 소요됩니다 ...

[초등학생 말투] (토큰 80)
돈은 보통 3일에서 5일 사이에 다시 들어와요. 조금만 기다리면 돼요!
**해설**: `chat()`이 이제 **튜플 `(답변, 토큰수)`** 를 반환하도록 바뀌었습니다. 말투(시스템 지시)에 따라 답변 길이가 달라지면 출력 토큰도 달라져, 토큰 수도 함께 변합니다. "말투를 바꾸면 비용도 바뀐다"를 눈으로 확인할 수 있습니다.

정리

  • 문제 1로 temperature ↔ 다양성의 관계를 숫자로 측정했습니다.
  • 문제 2로 시스템 지시 ↔ 토큰(비용) 의 관계를 확인했습니다.

이것으로 2강을 마칩니다. 다음은 프롬프트 엔지니어링입니다!
