정리 & 체크리스트

2강에서 배운 것

1강에서 "한 번 호출"만 해 봤다면, 2강에서는 그 호출을 통제하는 법을 배웠습니다.

  • 요청-응답 구조: 요청은 model·contents·config, 응답은 text·usage_metadata.
  • 시스템 지시: 모델에게 역할·말투·안전장치를 부여 → 같은 질문도 답이 통째로 바뀜.
  • 토큰과 비용: 요금은 토큰으로 매겨지고, 한국어가 더 많이 쓴다. OpenAI는 usage로 확인·예측.
  • 토큰과 비용: 요금은 토큰으로 매겨지고, 한국어가 더 많이 쓴다. Gemini는 usage_metadata로 확인·예측.
  • temperature: 무작위성 손잡이. 분류=0, 상담=0.3, 창작=0.7.
  • OpenAI 호출: 회사가 달라도 요청-응답 구조는 같다 → 모델 교체가 쉽다.

한눈에 보는 핵심 코드

OpenAI

from common import get_openai_client, OPENAI_MODEL

client = get_openai_client()

resp = client.chat.completions.create(
    model=OPENAI_MODEL,                                  # 어떤 모델
    messages=[                                           # 무슨 말 + 역할
        {"role": "system", "content": "너는 친절한 상담원이다."},  #   역할
        {"role": "user", "content": "환불 얼마나 걸려요?"},      #   사용자 질문
    ],
    temperature=0.3,                                     # 어떤 설정 (무작위성)
)
print(resp.choices[0].message.content)  # 답변
print(resp.usage)                       # 토큰(=비용)

Gemini

from common import get_genai_client, GEMINI_MODEL
from google.genai import types

client = get_genai_client()

resp = client.models.generate_content(
    model=GEMINI_MODEL,                                  # 어떤 모델
    contents="환불 얼마나 걸려요?",                        # 무슨 말
    config=types.GenerateContentConfig(                  # 어떤 설정
        system_instruction="너는 친절한 상담원이다.",      #   역할
        temperature=0.3,                                 #   무작위성
    ),
)
print(resp.text)                 # 답변
print(resp.usage_metadata)       # 토큰(=비용)

체크리스트

  • [ ] 요청 3종 세트(model/contents/config)와 응답 2종 세트(text/usage)를 설명할 수 있다.
  • [ ] 시스템 지시로 말투를 바꿀 수 있다.
  • [ ] usage, usage_metadata로 토큰을 확인하고, 한국어가 더 많이 쓴다는 걸 안다.
  • [ ] temperature를 작업에 맞게(분류 0, 창작 0.7) 고를 수 있다.
  • [ ] OpenAI 호출도 "요청-응답 구조는 같다"는 걸 확인했다.

한 줄 핵심

LLM 호출은 '요청(model·contents·config) → 응답(text·usage)'의 함수다. 이 구조를 통제하면 말투·비용·일관성을 모두 다룰 수 있다.
