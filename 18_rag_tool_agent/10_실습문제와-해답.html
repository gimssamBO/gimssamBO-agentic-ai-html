문제 1 — RAG + 데이터 도구 통합 에이전트

문서검색(retriever) 도구와 run_pandas 데이터 도구를 한 에이전트에 함께 붙이세요.

  • 사용 파일: data/docs/멤버십정책.pdf, data/orders.csv
  • 기대 결과: "VIP 적립률이 얼마고, 그걸 5월 총매출에 적용하면 적립금은?"
    질문에서 retriever로 적립률을, run_pandas로 매출을 구해 곱한 값을 답하면 성공.

실습코드: ch18_rag_tool_ex01.py

해답 보기 
import pathlib
import sys
import pandas as pd

# 1. 경로 설정 및 대문자 경로 상수 사용
sys.path.append(str(pathlib.Path(__file__).resolve().parent))
from common import DATA, DOCS, get_chat, get_embeddings

# 2. 필수 라이브러리 모듈 임포트
from langchain_community.document_loaders import PyPDFLoader
from langchain_community.vectorstores import FAISS
from langchain_core.tools import create_retriever_tool, tool
from langchain_text_splitters import RecursiveCharacterTextSplitter

# 최신 LangChain 표준 임포트 (경고 문구 해결)
from langchain.agents import create_agent

# 3. 데이터 로드 및 month 컬럼 추가 (%y-%m 형태: 예 '26-05')
orders = pd.read_csv(DATA / "orders.csv", encoding="utf-8-sig")
orders["month"] = pd.to_datetime(orders["order_date"]).dt.strftime("%y-%m")

# 4. RAG 도구 (멤버십 정책 문서 인덱싱)
policy_docs = PyPDFLoader(str(DOCS / "멤버십정책.pdf")).load()
chunks = RecursiveCharacterTextSplitter(
    chunk_size=500, chunk_overlap=50
).split_documents(policy_docs)
retriever = FAISS.from_documents(chunks, get_embeddings()).as_retriever(
    search_kwargs={"k": 4}
)
policy_tool = create_retriever_tool(
    retriever,
    "policy_search",
    "멤버십 등급·적립률 등 정책 문서 검색. 정책 질문에 사용.",
)

# 5. Pandas 코드 실행 도구 (안전성 강화 및 예시 명시)
@tool
def run_pandas(expr: str) -> str:
    """주문 데이터 분석 도구.
    사용 가능 변수: orders (컬럼: month, status, amount, order_date ...), pd
    예시 표현식: orders[(orders['month']=='26-05') & (~orders['status'].isin(['취소', '환불']))]['amount'].sum()
    """
    try:
        # 따옴표나 공백 정제 후 eval 실행
        clean_expr = expr.strip().strip("`").strip()
        result = eval(clean_expr, {"__builtins__": {}}, {"orders": orders, "pd": pd})
        return str(result)
    except Exception as e:
        return f"실행 오류: {e}. 올바른 파이썬 pandas 표현식만 입력하세요."

# 6. 에이전트 생성 (create_agent 적용 및 시스템 프롬프트 구체화)
llm = get_chat(temperature=0)
prompt_text = (
    "너는 승승장구몰 CS 에이전트다.\n"
    "1. 멤버십 등급 및 적립률 정보는 반드시 policy_search 도구로 검색하라.\n"
    "2. 매출 계산은 run_pandas 도구를 사용하되, month 컬럼 형식은 '26-05'와 같은 '%y-%m' 형태임을 명심하라.\n"
    "3. 두 결과를 종합하여 정확한 최종 금액과 함께 한글로 답하라."
)

agent = create_agent(
    model=llm,
    tools=[policy_tool, run_pandas],
    system_prompt=prompt_text
)

# 7. 질의 실행
if __name__ == "__main__":
    q = "VIP 적립률이 얼마고, 그걸 2026-05 총매출(취소/환불 제외)에 적용하면 적립금은?"
    print("에이전트 실행 중...")
    out = agent.invoke({"messages": [{"role": "user", "content": q}]})

    # 8. 최종 답변 출력
    print("\n=== 최종 답변 ===")
    print(out["messages"][-1].content)
**예상 출력** 
vip 등급의 적립률은 5%입니다. 2026년 5월 총매출(취소/환불 제외)은 약 10,234,050원이며,
여기에 5%를 적용하면 적립금은 약 511,703원입니다.
**해설**: RAG 도구(적립률)와 데이터 도구(매출)를 한 에이전트에 넣으니,
"적립률 검색 → 매출 계산 → 곱하기"의 멀티스텝이 일어납니다.
정책 문서의 지식(적립률 5%)과 DB 분석(매출)을 **결합한 계산**까지 한 거죠.
18강의 "RAG + 도구 통합"이 실제 가치를 내는 예입니다.

문제 2 — 라우팅 검증 로그

질문 유형에 따라 어떤 도구가 호출되는지 보여주는 테스트 스크립트를 작성하세요.

  • 정책 질문/데이터 질문/복합 질문 3개를 넣고 각 호출된 도구명을 출력
  • 기대 결과: 정책 질문은 retriever만, 데이터 질문은 run_pandas만, 복합 질문은 둘 다 호출됨을 로그로 확인하면 성공.

실습코드: ch18_rag_tool_ex02.py

해답 보기 
# (위 문제 1의 agent 재사용)

import pathlib
import sys
import pandas as pd

# 1. 경로 설정 및 대문자 경로 상수 사용
sys.path.append(str(pathlib.Path(__file__).resolve().parent))
from common import DATA, DOCS, get_chat, get_embeddings

# 2. 필수 라이브러리 모듈 임포트
from langchain_community.document_loaders import PyPDFLoader
from langchain_community.vectorstores import FAISS
from langchain_core.tools import create_retriever_tool, tool
from langchain_text_splitters import RecursiveCharacterTextSplitter

# 최신 LangChain 표준 임포트
from langchain.agents import create_agent

# 3. 데이터 로드 및 month 컬럼 추가 (%y-%m 형태: 예 '26-05')
orders = pd.read_csv(DATA / "orders.csv", encoding="utf-8-sig")
orders["month"] = pd.to_datetime(orders["order_date"]).dt.strftime("%y-%m")

# 4. RAG 도구 (멤버십 정책 문서 인덱싱)
policy_docs = PyPDFLoader(str(DOCS / "멤버십정책.pdf")).load()
chunks = RecursiveCharacterTextSplitter(
    chunk_size=500, chunk_overlap=50
).split_documents(policy_docs)
retriever = FAISS.from_documents(chunks, get_embeddings()).as_retriever(
    search_kwargs={"k": 4}
)
policy_tool = create_retriever_tool(
    retriever,
    "policy_search",
    "멤버십 등급·적립률 등 정책 문서 검색. 정책 질문에 사용.",
)

# 5. Pandas 코드 실행 도구
@tool
def run_pandas(expr: str) -> str:
    """주문 데이터 분석 도구.
    사용 가능 변수: orders (컬럼: month, status, amount, order_date ...), pd
    예시 표현식: orders[(orders['month']=='26-05') & (~orders['status'].isin(['취소', '환불']))]['amount'].sum()
    """
    try:
        clean_expr = expr.strip().strip("`").strip()
        result = eval(clean_expr, {"__builtins__": {}}, {"orders": orders, "pd": pd})
        return str(result)
    except Exception as e:
        return f"실행 오류: {e}. 올바른 파이썬 pandas 표현식만 입력하세요."

# 6. 에이전트 생성
llm = get_chat(temperature=0)
prompt_text = (
    "너는 승승장구몰 CS 에이전트다.\n"
    "1. 멤버십 등급 및 적립률 정보는 반드시 policy_search 도구로 검색하라.\n"
    "2. 매출 계산은 run_pandas 도구를 사용하되, month 컬럼 형식은 '26-05'와 같은 '%y-%m' 형태임을 명심하라.\n"
    "3. 두 결과를 종합하여 정확한 최종 금액과 함께 한글로 답하라."
)

agent = create_agent(
    model=llm,
    tools=[policy_tool, run_pandas],
    system_prompt=prompt_text
)

# 7. 도구 사용 기록 추출 함수
def tools_used(agent, q):
    """질문 실행 후 호출된 도구명 리스트를 반환."""
    out = agent.invoke({"messages": [{"role": "user", "content": q}]})
    names = []
    for m in out["messages"]:
        # none -> None 오타 교정
        for tc in getattr(m, "tool_calls", None) or []:
            names.append(tc["name"])
    return names

# 8. 실행 및 결과 검증
if __name__ == "__main__":
    print("=== [1] 기본 복합 질문 실행 ===")
    q = "VIP 적립률이 얼마고, 그걸 2026-05 총매출(취소/환불 제외)에 적용하면 적립금은?"
    print("에이전트 실행 중...")
    out = agent.invoke({"messages": [{"role": "user", "content": q}]})
    print("\n=== 최종 답변 ===")
    print(out["messages"][-1].content)

    print("\n" + "=" * 50)
    print("=== [2] 질문 유형별 호출 도구 검증 ===")
    print("=" * 50 + "\n")

    tests = [
        ("vip 등급 적립률이 얼마예요?", "정책"),       # → policy_search만 호출 예상
        ("2026-05 총매출은 얼마예요?", "데이터"),       # → run_pandas만 호출 예상
        ("vip 적립률을 5월 매출에 곱하면?", "복합"),    # → 둘 다 호출 예상
    ]

    for test_q, kind in tests:
        used = tools_used(agent, test_q)
        print(f"[{kind}] '{test_q}'\n   호출된 도구: {used}\n")
**예상 출력** 
[정책] 'vip 등급 적립률이 얼마예요?'
   호출된 도구: ['policy_search']

[데이터] '2026-05 총매출은 얼마예요?'
   호출된 도구: ['run_pandas']

[복합] 'vip 적립률을 5월 매출에 곱하면?'
   호출된 도구: ['policy_search', 'run_pandas']
**해설**: 질문 유형에 따라 호출되는 도구가 다릅니다.
정책 질문엔 `policy_search`만, 데이터 질문엔 `run_pandas`만, 복합 질문엔 **둘 다** 호출됐죠.
우리가 정해 주지 않았는데 에이전트가 질문을 보고 알맞은 도구를 라우팅한 겁니다(12·17강).
`tool_calls`를 모아 보면 에이전트의 "판단 결과"를 객관적으로 검증할 수 있습니다
— 라우팅이 제대로 되는지 자동 확인하는 방법이죠.
