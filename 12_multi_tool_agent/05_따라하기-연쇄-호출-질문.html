따라하기 — 연쇄 호출 질문

목표

한 문장에 세 가지 일이 섞인 복합 질문으로, 에이전트가 여러 도구를 순서대로 연쇄 호출하는 과정을 stream으로 관찰합니다.

1. 복합 질문

세 가지 일이 한 문장에 섞인 질문을 던집니다.

q = (
    "C0001 고객의 최근 주문 상태와, 그 상품의 재고, "
    "그리고 2026-05월 전체 매출을 알려줘."
)

이 질문에는 ① 주문 조회 ② 재고 조회 ③ 매출 분석이 들어 있습니다. 특히 ②는 ①의 결과(product_id)가 있어야 합니다 — 연쇄가 필요하죠.

2. stream으로 과정 관찰

for step in agent.stream(
    {"messages": [{"role": "user", "content": q}]}, stream_mode="values"
):
    step["messages"][-1].pretty_print()

예상 출력

================================ Human Message =================================
C0001 고객의 최근 주문 상태와, 그 상품의 재고, 그리고 2026-05월 전체 매출을 알려줘.

================================== Ai Message ==================================
Tool Calls: get_order_status(customer_id='C0001')               ← ① 주문 조회
================================= Tool Message =================================
최근 주문: 승승 현미 잡곡 10kg(product_id=P0025), 상태 '배송완료'

================================== Ai Message ==================================
Tool Calls: get_stock(product_id='P0025')                       ← ② 재고 (P0025 이어받음!)
================================= Tool Message =================================
승승 현미 잡곡 10kg(P0025) 재고 155개, 창고 부산물류

================================== Ai Message ==================================
Tool Calls: run_pandas(expr="orders[...month=='2026-05'...]['amount'].sum()")  ← ③ 매출
================================= Tool Message =================================
10234050

================================== Ai Message ==================================
- 최근 주문: 승승 현미 잡곡 10kg, 상태 '배송완료'
- 재고: 155개 (부산물류, 여유 있음)
- 2026-05월 전체 매출(취소/환불 제외): 약 10,234,050원

3. 연쇄의 핵심 — 결과를 이어받기

가장 중요한 순간은 ② 재고 조회입니다.

  1. get_order_status(customer_id='C0001') → 결과: "…product_id=P0025…"
  2. get_stock(product_id='P0025') — ①의 product_id를 이어받아 재고 조회!

에이전트는 ①의 결과에서 product_id=P0025를 읽어서, ②의 입력으로 넣었습니다. 우리가 "P0025"라고 알려 주지 않았는데도요. 질문에는 "그 상품의 재고"라고만 했는데, 에이전트가 "그 상품 = 방금 조회한 P0025"임을 이해하고 이어받은 거죠.

비유: 비서에게 "김 대리 최근 보고서랑, 그 보고서에 나온 프로젝트 예산도 알려줘"라고 하면, 비서가 먼저 보고서를 찾고(① ), 거기서 프로젝트명을 읽어, 그 프로젝트 예산을 조회합니다(②). "그 프로젝트 = 방금 본 보고서의 것"임을 이해하는 거죠. 에이전트도 똑같습니다.

4. 세 도구가 한 번에 협력

이 출력에서 보이는 것은:

  1. 라우팅: 질문의 각 부분을 알맞은 도구로 보냄 (주문→재고→매출)
  2. 연쇄: 앞 결과(P0025)를 뒤 도구에 이어줌
  3. 종합: 세 결과를 모아 항목별로 정리

우리는 if-else도, 연쇄 로직도 짜지 않았습니다. 시스템 프롬프트에 "도구를 골라 순서대로, 앞 결과를 이어 써라"라고 한 줄 지시했을 뿐이죠. 나머지는 에이전트가 알아서 했습니다.

5. 1부의 모든 것이 여기에

이 한 번의 실행에 1부에서 배운 게 다 들어 있습니다.

  • 도구 호출(5강), 도구 선택(6강), 루프(7강)
  • LangChain 에이전트(8강), 데이터 분석(10·11강)

7강에서 while 루프로 손수 만들던 ReAct 루프를, 이제 create_agent 한 줄로 만들고 세 도구를 연쇄시킵니다. 1부를 제대로 배웠기에 이 통합이 자연스럽게 이해되는 겁니다.

핵심 정리

  • 복합 질문에 에이전트가 세 도구를 순서대로 연쇄 호출한다.
  • 핵심: ①의 결과(product_id)를 ②의 입력으로 이어받기.
  • 에이전트가 "그 상품 = 방금 조회한 것"을 이해한다.
  • 라우팅·연쇄·종합을 우리가 안 짜도 에이전트가 알아서 한다.
  • 다음 절에서 도구가 실패할 때 폴백하는 법을 배웁니다.
