실습문제와 해답

직접 코드를 고쳐 보며 12강 내용을 손에 익힙니다. 먼저 스스로 풀어 본 뒤 해답을 펼쳐 보세요.

문제 1 — 세 번째 도구 추가 (FAQ)

멀티툴 에이전트에 lookup_faq(keyword) 도구를 추가하세요.

  • data/faq.csv(컬럼: faq_id, question, answer)를 읽어 question에 키워드가 포함된 행의 answer를 반환합니다.
  • 사용 파일: data/faq.csv, data/orders.csv
  • 기대 결과: "환불 정책 알려주고, 이번 달 환불 건수도 알려줘" 같은 복합 질문에서 FAQ 도구와 데이터 도구를 모두 호출하면 성공.
해답 보기 
import sys, pathlib
sys.path.append(str(pathlib.Path(__file__).resolve().parent))
import pandas as pd
from langchain_core.tools import tool
from langchain.agents import create_agent
from common import get_chat, DATA

llm = get_chat(provider="gemini")
orders = pd.read_csv(DATA / "orders.csv", encoding="utf-8-sig")
orders["month"] = pd.to_datetime(orders["order_date"]).dt.strftime("%Y-%m")
faq = pd.read_csv(DATA / "faq.csv", encoding="utf-8-sig")

@tool
def lookup_faq(keyword: str) -> str:
    """FAQ에서 키워드가 포함된 질문의 답변을 반환한다. 정책·이용안내 질문에 사용."""
    hit = faq[faq["question"].str.contains(keyword, na=False)]
    if hit.empty:
        return f"[조회실패] '{keyword}' 관련 FAQ가 없습니다."
    return "\n".join(f"Q: {r.question}\nA: {r.answer}" for r in hit.itertuples())

@tool
def run_pandas(expr: str) -> str:
    """주문 데이터 분석. orders(컬럼: month, status, amount...), pd 사용 가능."""
    try:
        return str(eval(expr, {"__builtins__": {}}, {"orders": orders, "pd": pd}))
    except Exception as e:
        return f"실행 오류: {e}"

agent = create_agent(llm, tools=[lookup_faq, run_pandas],
    system_prompt="너는 운영 비서다. FAQ와 데이터 도구를 골라 쓰고 한국어로 답하라.")

q = "환불 정책 알려주고, 이번 달(2026-05) 환불 건수도 알려줘."
for step in agent.stream({"messages": [{"role": "user", "content": q}]}, stream_mode="values"):
    step["messages"][-1].pretty_print()
**예상 출력** 
Tool Calls: lookup_faq(keyword='환불')              ← FAQ 도구
Tool Message: Q: 환불은 어떻게 하나요? A: 수령 후 7일 이내 ...
Tool Calls: run_pandas(expr="len(orders[(orders['status']=='환불')&(orders['month']=='2026-05')])")  ← 데이터 도구
Tool Message: 12
Ai Message: 환불 정책은 수령 후 7일 이내 신청 가능하며, 2026년 5월 환불은 12건입니다.
**해설**: "환불 정책"(FAQ)과 "환불 건수"(데이터)는 서로 다른 도구가 필요합니다. 에이전트가 docstring을 보고 각각을 알맞은 도구로 라우팅했죠. 도구를 추가하는 건 `TOOLS` 리스트에 넣기만 하면 됩니다 — 라우팅은 LLM이 알아서 합니다.

문제 2 — 도구 선택 로그 출력

에이전트 실행 시 어떤 도구가 어떤 인자로 호출됐는지 한 줄씩 출력하세요(메시지의 tool_calls 순회).

  • 사용 파일: data/products.csv, data/orders.csv
  • 기대 결과: "상품 가격 조회 후 그 상품의 총 판매수량 계산" 질문에서 도구 2개가 순서대로 호출된 로그가 출력되면 성공.
해답 보기 
import sys, pathlib
sys.path.append(str(pathlib.Path(__file__).resolve().parent))
import pandas as pd
from langchain_core.tools import tool
from langchain.agents import create_agent
from common import get_chat, DATA

llm = get_chat(provider="gemini")
products = pd.read_csv(DATA / "products.csv", encoding="utf-8-sig")
orders = pd.read_csv(DATA / "orders.csv", encoding="utf-8-sig")

@tool
def get_price(product_name: str) -> str:
    """상품명으로 판매가와 product_id를 조회한다."""
    hit = products[products["product_name"].str.contains(product_name, na=False)]
    if hit.empty:
        return f"[조회실패] '{product_name}' 없음"
    r = hit.iloc[0]
    return f"{r['product_name']}(id={r['product_id']}) 가격 {int(r['price']):,}원"

@tool
def total_quantity(product_id: str) -> str:
    """product_id의 총 판매수량(quantity 합계)을 계산한다."""
    qty = int(orders[orders["product_id"] == product_id]["quantity"].sum())
    return f"{product_id} 총 판매수량 {qty}개"

agent = create_agent(llm, tools=[get_price, total_quantity],
    system_prompt="너는 운영 비서다. 앞 도구 결과(product_id)를 다음 도구에 이어 써라.")

q = "이어버드 가격 조회하고, 그 상품의 총 판매수량도 알려줘."
for step in agent.stream({"messages": [{"role": "user", "content": q}]}, stream_mode="values"):
    msg = step["messages"][-1]
    # 도구 호출 로그 출력
    if getattr(msg, "tool_calls", None):
        for tc in msg.tool_calls:
            print(f"🔧 도구 호출: {tc['name']}({tc['args']})")
**예상 출력** 
🔧 도구 호출: get_price({'product_name': '이어버드'})
🔧 도구 호출: total_quantity({'product_id': 'P0001'})    ← 앞 결과 P0001을 이어받음!
**해설**: `msg.tool_calls`를 순회하면 각 도구 호출의 이름과 인자를 볼 수 있습니다. 출력을 보면 `get_price`가 돌려준 `product_id='P0001'`을 `total_quantity`가 **이어받은** 게 보이죠(연쇄 호출). 이렇게 도구 호출 로그를 찍으면 "에이전트가 무슨 생각으로 어떤 도구를 썼는지" 디버깅할 수 있습니다.

정리

  • 문제 1로 새 도구를 추가하고 라우팅을 확인했습니다.
  • 문제 2로 도구 호출 로그로 연쇄 과정을 관찰했습니다.
