정리 & 체크리스트

12강에서 배운 것

12강에서는 1부의 도구들을 한 에이전트에 통합한 종합편을 다뤘습니다.

  • 도구 라우팅: LLM이 docstring을 보고 적절한 도구를 스스로 고름.
  • 연쇄 호출: 앞 도구의 결과(product_id)를 다음 도구 입력으로 이어 씀.
  • 폴백 처리: 도구 실패를 신호 문자열로 반환 + 시스템 프롬프트로 대체 안내.
  • 입력 검증: 형식이 틀린 입력을 정규화·검증으로 걸러냄.

체크리스트

  • [ ] 실무 에이전트가 여러 도구를 갖는 이유를 설명할 수 있다.
  • [ ] LLM이 docstring을 보고 도구를 라우팅한다는 것을 이해했다.
  • [ ] 도구 3종을 한 에이전트에 통합하고 연쇄 호출을 관찰했다.
  • [ ] 도구 실패 시 폴백(신호 문자열 + 대체 안내)을 구현했다.
  • [ ] 입력 검증/정규화로 잘못된 인자를 걸러냈다.

한 줄 핵심

여러 도구를 한 에이전트에 통합하면 LLM이 알아서 라우팅·연쇄한다. 폴백과 입력 검증을 더하면 진짜 서비스가 된다.

🎉 1부 종합 완료

12강으로 에이전트의 기본기(도구 활용) 가 완성됐습니다. 이제 여러분은 도구를 만들고, 통합하고, 실패에 대비하는 법까지 압니다. 진짜 상담봇의 뼈대가 갖춰진 거죠.
