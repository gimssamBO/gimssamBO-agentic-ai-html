실습문제와 해답

직접 코드를 고쳐 보며 17강 내용을 손에 익힙니다. 먼저 스스로 풀어 본 뒤 해답을 펼쳐 보세요. (이 실습은 GOOGLE_API_KEY가 필요합니다.)

문제 1 — retriever 도구화

create_retriever_tool로 사내 문서 검색 도구를 만들어 에이전트에 붙이세요.

  • 사용 파일: data/docs/직원핸드북.pdf 기반 FAISS 인덱스
  • 기대 결과: "연차 며칠이야?" 질문에 에이전트가 retriever 도구를 호출하고 핸드북 조항을 근거로 답하면 성공.
해답 보기 
import sys, pathlib
sys.path.append(str(pathlib.Path(__file__).resolve().parent))
from common import get_chat, get_embeddings, DOCS
from langchain_community.document_loaders import PyPDFLoader
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain_community.vectorstores import FAISS
from langchain_core.tools.retriever import create_retriever_tool
from langchain.agents import create_agent

# 핸드북 인덱싱
docs = PyPDFLoader(str(DOCS / "직원핸드북.pdf")).load()
chunks = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50).split_documents(docs)
retriever = FAISS.from_documents(chunks, get_embeddings()).as_retriever(search_kwargs={"k": 4})

# retriever를 도구로
handbook_tool = create_retriever_tool(
    retriever,
    name="employee_handbook_search",
    description="승승장구몰 직원핸드북(인사·복지·휴가 규정)을 검색한다. 연차·휴가·근무 규정 질문에 사용.")

agent = create_agent(get_chat(temperature=0), tools=[handbook_tool],
                     system_prompt="너는 인사 담당자다. 규정은 반드시 도구로 검색해 답하라.")

out = agent.invoke({"messages": [{"role": "user", "content": "연차 며칠이야?"}]})
for m in out["messages"]:
    m.pretty_print()
print("\n검색 사용?", any(getattr(m, "tool_calls", None) for m in out["messages"]))
**예상 출력** 
Ai Message — Tool Calls: employee_handbook_search({'query': '연차 휴가 일수'})
Tool Message — 연차 유급휴가는 근속 1년당 15일이 부여되며 ...
Ai Message — 연차 유급휴가는 근속 1년당 15일이 부여됩니다.

검색 사용? True
**해설**: 핸드북을 인덱싱해 retriever를 만들고, `create_retriever_tool`로 도구화한 뒤 에이전트에 붙였습니다. "연차 며칠?" 질문에 에이전트가 핸드북 검색 도구를 호출하고, 그 조항(근속 1년당 15일)을 근거로 답했죠. 17강 전체 흐름(인덱싱 → 도구화 → 에이전트)을 직접 구현한 것입니다.

문제 2 — 도구 description 튜닝

retriever 도구의 description을 모호하게("search") 했을 때와 명확하게("사내 인사·복지 규정 검색") 했을 때 도구 호출 여부를 비교하세요.

  • 사용 파일: 위와 동일
  • 기대 결과: 같은 질문에서 description이 명확할 때 도구 호출이 일어남을 로그로 보이면 성공.
해답 보기 
import sys, pathlib
sys.path.append(str(pathlib.Path(__file__).resolve().parent))
from common import get_chat, get_embeddings, DOCS
from langchain_community.document_loaders import PyPDFLoader
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain_community.vectorstores import FAISS
from langchain_core.tools.retriever import create_retriever_tool
from langchain.agents import create_agent

docs = PyPDFLoader(str(DOCS / "직원핸드북.pdf")).load()
chunks = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50).split_documents(docs)
vs = FAISS.from_documents(chunks, get_embeddings())   # 1회 생성, 공유

def make_agent(description):
    tool = create_retriever_tool(vs.as_retriever(search_kwargs={"k": 4}),
                                 name="search_tool", description=description)
    return create_agent(get_chat(temperature=0), tools=[tool],
                        system_prompt="너는 승승장구몰 상담원이다.")

def used_search(agent, q):
    out = agent.invoke({"messages": [{"role": "user", "content": q}]})
    return any(getattr(m, "tool_calls", None) for m in out["messages"])

q = "연차 휴가 며칠이야?"
print(f"[모호한 description 'search'] 검색함? {used_search(make_agent('search'), q)}")
print(f"[명확한 description] 검색함? {used_search(make_agent('승승장구몰 직원 인사·복지·휴가 규정을 검색한다. 휴가·근무 규정 질문에 사용.'), q)}")
**예상 출력** 
[모호한 description 'search'] 검색함? False (또는 불안정)
[명확한 description] 검색함? True
**해설**: 같은 retriever, 같은 질문인데 **description만** 바꿨더니 검색 여부가 달라졌습니다. `"search"`처럼 모호하면 에이전트가 "이 도구가 휴가 질문에 맞나?" 확신하지 못해 검색을 안 하거나 흔들립니다. `"인사·복지·휴가 규정 검색"`처럼 명확하면 "연차 질문엔 이 도구"라고 정확히 판단해 검색하죠. 06번에서 배운 "description = 라우팅 규칙"을 직접 확인한 실험입니다.

정리

  • 문제 1로 RAG를 도구로 만들어 에이전트에 연결했습니다.
  • 문제 2로 description이 도구 호출을 좌우함을 확인했습니다.
