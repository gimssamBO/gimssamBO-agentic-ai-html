따라하기 — 일상 질문 vs 정책 질문

목표

같은 에이전트에 일상 질문과 정책 질문을 던져, 에이전트가 검색 여부를 스스로 판단하는 것을 확인합니다.

1. 일상 질문 — 검색하지 않음

먼저 일상 인사를 던집니다.

ans, used = ask("안녕하세요! 오늘 기분 어때요?")
print("답변:", ans)
print("검색 도구 사용?", used)

예상 출력

답변: 안녕하세요! 무엇을 도와드릴까요?
검색 도구 사용? False

used가 False입니다. 에이전트가 "이건 일상 인사라 정책 검색이 필요 없다"고 판단해, 검색 도구를 안 쓰고 바로 답했습니다. 인사 한마디에 정책 PDF를 뒤지지 않은 거죠. 효율적입니다.

2. 정책 질문 — 검색함

이번엔 정책 질문을 던집니다.

ans, used = ask("단순 변심으로 반품하면 배송비는 누가 부담하나요?")
print("답변:", ans)
print("검색 도구 사용?", used)

예상 출력

답변: 단순 변심으로 인한 반품의 경우, 왕복 배송비는 고객님께서 부담하셔야 합니다.
검색 도구 사용? True

이번엔 used가 True입니다. 에이전트가 "이건 정책 질문이라 문서를 찾아야 한다"고 판단해, 검색 도구를 호출하고 그 근거로 답했습니다.

3. 과정 들여다보기 (stream)

pretty_print로 정책 질문 처리 과정을 보면 ReAct 루프가 보입니다.

out = agent.invoke({"messages": [{"role": "user", "content": "반품 배송비 누가 내요?"}]})
for m in out["messages"]:
    m.pretty_print()

예상 출력

================================ Human Message ===
반품 배송비 누가 내요?

================================== Ai Message ====
Tool Calls: company_policy_search({'query': '단순 변심 반품 배송비'})   ← 검색 도구 호출!

================================ Tool Message ====
교환·반품 시 단순 변심의 경우 왕복 배송비는 고객이 부담합니다 ...   ← 검색 결과

================================== Ai Message ====
단순 변심으로 인한 반품의 경우, 왕복 배송비는 고객님께서 부담하셔야 합니다.   ← 근거로 답

7강에서 배운 ReAct 흐름 그대로입니다:
1. 생각: "정책 질문이네, 검색해야겠다"
2. 행동: company_policy_search 호출 (검색어도 스스로 생성)
3. 관찰: 검색 결과(반품 배송비 조항)
4. 답변: 근거로 정확히 답

4. 같은 에이전트, 다른 판단

핵심은 같은 에이전트가 질문에 따라 다르게 행동한다는 것입니다.

"안녕하세요" → 검색 안 함 (False) → 바로 답
"반품 배송비?" → 검색함 (True) → 근거로 답

우리가 "이건 검색해, 저건 하지 마"라고 일일이 정하지 않았습니다. 에이전트가 도구의 description과 질문을 비교해 스스로 판단했죠. 이게 16강 고정 파이프라인(무조건 검색)과의 결정적 차이입니다.

5. 왜 이게 더 나은가

Knowledge Agent의 장점을 정리하면:

  • 효율: 일상 질문에 불필요한 검색·임베딩 비용 절감
  • 자연스러움: 인사엔 인사로, 정책엔 근거로 — 사람 상담원처럼
  • 유연성: 다양한 질문(일상+정책+계산 등)을 한 에이전트로 처리

특히 종합 상담봇처럼 온갖 질문이 섞여 들어오는 경우, "필요할 때만 검색"이 빛을 발합니다. 모든 질문에 정책 문서를 뒤지는 건 낭비니까요.

6. 판단이 틀릴 수도 있다

단, 에이전트의 판단이 항상 완벽하진 않습니다.

  • 정책 질문인데 검색 안 함 → 환각 위험
  • 일상 질문인데 검색함 → 불필요한 비용

이 판단 정확도는 도구의 description에 크게 좌우됩니다(다음 절). description이 모호하면 판단이 흔들리죠. 그래서 description을 잘 쓰는 게 Knowledge Agent의 핵심 기술입니다.

핵심 정리

  • 일상 질문엔 검색 안 함(used=False), 정책 질문엔 검색함(used=True).
  • 정책 질문 처리는 7강 ReAct 루프(생각→검색→관찰→답) 그대로.
  • 같은 에이전트가 질문에 따라 스스로 판단(우리가 안 정함).
  • 장점: 효율·자연스러움·유연성.
  • 판단 정확도는 도구 description에 좌우됨(다음 절).
  • 다음 절에서 description 개선으로 판단을 정확하게 합니다.
