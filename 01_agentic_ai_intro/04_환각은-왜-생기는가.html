환각(Hallucination)은 왜 생기는가

한 줄 요약

LLM은 "사실을 검색"하는 게 아니라 "다음에 올 가장 그럴듯한 단어"를 확률로 이어 붙이는 기계입니다. 그래서 모르는 것도 자신 있게 지어냅니다. 이걸 환각이라 부르고, 에이전트는 도구로 사실에 근거(grounding) 해 환각을 줄입니다.

1. 환각이란?

환각은 LLM이 사실이 아닌 내용을 사실인 것처럼 그럴듯하게 만들어 내는 현상입니다. 가장 무서운 점은 틀렸는데도 말투가 확신에 차 있다는 것입니다.

예: "주문 O000123 배송 상태 알려줘"라고 물으면, 실제 데이터에 접근 못 하는 LLM이

"현재 동대구 물류센터를 출발해 내일 오전 도착 예정입니다. 운송장 번호는 1234-5678입니다."

라고 운송장 번호까지 지어낼 수 있습니다. 그럴듯하지만 전부 거짓입니다.

2. 왜 생길까? — LLM의 작동 원리

>> TRANSFORMER EXPLAINER LLM 작동 이해

LLM은 속으로 이런 일을 합니다.

"지금까지의 문장 다음에 올 가장 확률 높은 단어는 무엇일까?" → 한 단어 고르기 → 그걸 포함해 다시 "다음 단어는?" → 반복

즉 거대한 '다음 단어 맞히기' 기계입니다. 진짜로 DB를 조회하거나 사실을 확인하는 단계가 없습니다.

# LLM이 속으로 하는 일을 아주 단순화하면 이런 느낌입니다 (개념용 의사코드)
문장 = "주문 O000123의 배송 상태는"
while 문장_안끝남:
    다음단어 = 확률이_가장_높은_단어(문장)   # ← '사실 확인'이 아니라 '확률 예측'
    문장 = 문장 + 다음단어
# "배송중입니다" 같은 자연스러운 말이 만들어지지만,
# 그게 '진짜 그 주문의 상태'라는 보장은 어디에도 없다.

그래서:
- 학습 데이터에 있던 패턴은 잘 맞힙니다 (일반 상식).
- 학습 데이터에 없던 것(특정 주문 상태, 사내 정책, 어제 일어난 뉴스)은 그럴듯하게 지어냅니다.

3. 환각이 잘 나오는 상황 3가지

상황 예시 왜
실시간/사내 정보 "내 주문 어디 왔어?" 학습에 없는 데이터
최신 사건 "어제 환율 얼마였어?" 지식 컷오프 이후 정보 (9강)
아주 구체적인 숫자/이름 "그 논문 저자가 누구지?" 비슷한 패턴으로 지어냄

4. 코드로 환각을 관찰하기

LLM에게 존재하지 않을 법한 아주 구체적인 사내 정보를 물어보면 환각을 유도할 수 있습니다.

from google import genai
client = genai.Client(api_key="...")

q = "승승장구몰 주문번호 O000123의 운송장 번호와 배송 단계를 정확히 알려줘."
resp = client.models.generate_content(model="gemini-3.6-flash", contents=q)
print(resp.text)
# 출력 예: "운송장 번호는 1234-5678이며 현재 배송중입니다" 처럼
#          그럴듯하지만 근거 없는 답(=환각)이 나올 수 있다.

같은 질문을, 우리가 가진 실제 데이터(CSV) 로 답하면 환각이 사라집니다.

import pandas as pd
orders = pd.read_csv("data/orders.csv", encoding="utf-8-sig")

row = orders[orders["order_id"] == "O000123"]
if row.empty:
    print("해당 주문번호가 없습니다.")        # ← '없으면 없다'고 말함 (정직)
else:
    print("실제 상태:", row.iloc[0]["status"])  # ← DB 사실에 근거

차이가 보이시나요? LLM 혼자는 "모른다"고 말하기보다 지어내는 경향이 있고, 도구(CSV 조회)는 사실 그대로 답하거나 없으면 없다고 말합니다.

5. 환각을 줄이는 방법 (앞으로 배울 것)

  1. 도구로 사실에 근거(grounding) — 주문은 DB에서, 정책은 문서에서 (5강, 13강 RAG)
  2. "모르면 모른다고 답하라"고 지시 — 프롬프트로 통제 (3강, 16강)
  3. 출처를 함께 제시 — 어느 문서 몇 페이지에서 왔는지 (16강)

핵심 마인드셋: "LLM의 말을 그냥 믿지 말고, 사실은 도구로 확인하게 만든다." 이게 이 과정 전체를 관통하는 원칙입니다.

핵심 정리

  • 환각 = LLM이 확률로 단어를 잇다 보니 모르는 것도 자신 있게 지어내는 현상.
  • 원인은 LLM이 '사실 확인'이 아니라 '다음 단어 예측' 기계이기 때문.
  • 해법은 도구·문서로 사실에 근거하게 만드는 것 → 이게 에이전트의 존재 이유.
