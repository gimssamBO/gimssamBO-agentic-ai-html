AI 앱 vs AI 에이전트 — "누가 다음 행동을 결정하는가"

한 줄 요약

AI 앱은 사람이 매번 다음 할 일을 정해 주는 1회성 도구이고, AI 에이전트는 LLM이 스스로 "다음에 뭘 할지" 정하며 목표를 끝낼 때까지 반복하는 시스템입니다.

1. 두 가지를 나란히 놓고 보기

구분 AI 애플리케이션 (AI App) AI 에이전트 (Agent)
흐름 입력 → LLM → 출력 (1회로 끝) 목표 → 계획·도구사용·관찰을 반복 → 완료
제어 주체 사람이 매번 지시 AI가 다음 행동을 스스로 결정
외부 연결 거의 없음 도구(검색·DB·코드실행·API) 사용
예시 번역기, 요약기, 단순 챗봇 주문 조회 상담봇, 리서치봇, 코딩봇

핵심 차이는 딱 하나, "누가 다음에 무엇을 할지 결정하는가" 입니다.
- AI 앱 → 사람이 정합니다. ("이거 번역해줘" → 번역 끝. 다음은 또 사람이 시켜야 함)
- AI 에이전트 → LLM이 정합니다. ("환불해줘" → LLM이 스스로 '주문 조회 → 정책 확인 → 안내' 순서를 짜서 실행)

비유: AI 앱은 시키는 메뉴만 만드는 자판기입니다. AI 에이전트는 "오늘 저녁 알아서 차려줘"라고 하면 냉장고를 열고(도구), 어제 뭘 먹었는지 떠올리고(기억), 장을 봐 와서(반복), 상을 차리는 요리사입니다.

2. 코드로 보는 차이

(가) AI 앱 — 한 번 호출하고 끝

from google import genai
client = genai.Client(api_key="...")

# 사람이 질문 → LLM이 답 → 끝. 다음 행동은 사람이 또 정해야 함.
resp = client.models.generate_content(
    model="gemini-2.5-flash",
    contents="이 문장을 영어로 번역해줘: 안녕하세요",
)
print(resp.text)   # "Hello" → 여기서 종료

흐름이 일직선입니다. 입력 한 번, 출력 한 번. LLM은 "그 다음에 뭘 할지" 고민하지 않습니다.

(나) AI 에이전트 — 스스로 판단하고 반복 (개념 미리보기)

아래는 7강에서 제대로 만들 구조를 개념만 보여 주는 의사코드(pseudo-code)입니다. 지금 이해 못 해도 괜찮습니다. "반복(while)이 돈다"는 점만 느끼면 됩니다.

# 개념 미리보기 — 에이전트의 뼈대 (자세한 구현은 7강)
목표 = "주문 O000123의 배송 상태를 알려줘"
대화기록 = [목표]

while True:                              # 목표가 끝날 때까지 반복
    결정 = LLM에게_묻기(대화기록)          # ① LLM이 "다음에 뭘 할지" 스스로 결정
    if 결정.종류 == "도구사용":
        결과 = 도구실행(결정.도구, 결정.입력)   # ② 도구로 실제 행동 (DB 조회 등)
        대화기록.append(결과)               # ③ 관찰 결과를 기억에 추가 → 다시 ①로
    else:
        print(결정.최종답변)               # ④ 더 할 일이 없으면 답하고 종료
        break

여기서 while 루프와 LLM에게_묻기가 매번 다음 행동을 고른다는 점이 AI 앱과의 결정적 차이입니다.

3. 에이전트가 항상 정답은 아니다

아닙니다. 단순 번역·요약처럼 한 번에 끝나는 일은 AI 앱이 더 빠르고 싸고 안전합니다. 에이전트는 "여러 단계를 거쳐야 하고, 도구가 필요한 일"에 어울립니다. 무엇을 만들지는 문제의 성격이 정합니다. (이 판단 기준은 28강 '프로젝트 설계'에서 자세히 다룹니다.)

핵심 정리

  • AI 앱 = 사람이 운전, AI 에이전트 = AI가 운전.
  • 에이전트의 특징은 반복 루프 + 스스로 다음 행동 결정.
  • 모든 일에 에이전트가 정답은 아니며, 문제에 맞게 고릅니다.
  • 다음 절에서는 에이전트를 이루는 4가지 부품을 들여다봅니다.
