CoT가 효과 없는 경우

한 줄 요약

CoT는 강력하지만 만능이 아닙니다. (a) 단순 사실/상식 질문에는 토큰만 낭비하고, (b) 함정 문제에서는 잘못된 중간 단계가 오히려 오답을 부를 수 있습니다. "언제 CoT를 끄는가" 도 알아야 합니다.

1. CoT의 두 가지 함정

앞에서 CoT가 정답률을 63% → 100%로 올리는 걸 봤습니다. 그래서 "무조건 CoT를 켜자"고 생각하기 쉽지만, 두 가지 경우엔 손해입니다.

  • (a) 단순 질문: "대한민국 수도는?" 같은 건 직접 답변도 맞습니다. CoT는 토큰(비용)만 더 씁니다.
  • (b) 함정 문제: 직관적인 중간 계산이 함정인 문제에서는, CoT가 그 함정에 빠져 오답을 낼 수 있습니다.

(실습 파일: sections/04_reasoning_prompt/06_CoT가-효과없는-경우.py)

2. (a) 단순 질문 — 토큰 낭비

usage_metadata로 토큰을 비교하면 낭비가 보입니다.

from common import get_genai_client, GEMINI_MODEL
from google.genai import types

client = get_genai_client()

def ask_direct(question: str):
    resp = client.models.generate_content(
        model=GEMINI_MODEL,
        contents=f"{question}\n설명 없이 정답만 한 단어로 답하라.",
        config=types.GenerateContentConfig(temperature=0),
    )
    return resp.text.strip(), resp.usage_metadata.total_token_count

def ask_cot(question: str):
    resp = client.models.generate_content(
        model=GEMINI_MODEL,
        contents=f"{question}\n단계적으로 풀어라. 마지막 줄에 '정답: <값>'.",
        config=types.GenerateContentConfig(temperature=0),
    )
    return resp.text.strip(), resp.usage_metadata.total_token_count

d_txt, d_tok = ask_direct("대한민국의 수도는 어디인가?")
c_txt, c_tok = ask_cot("대한민국의 수도는 어디인가?")
print(f"직접: {d_txt} (토큰 {d_tok})")
print(f"CoT : 토큰 {c_tok}  ← 같은 정답인데 토큰만 더 씀")

예상 출력

직접: 서울 (토큰 8)
CoT : 토큰 45  ← 같은 정답인데 토큰만 더 씀

둘 다 "서울"로 정답이지만, CoT는 토큰을 5배 넘게 썼습니다. 단순 질문에는 직접 답변이 빠르고 쌉니다.

3. (b) 함정 문제 — CoT도 흔들린다

유명한 함정 문제가 있습니다.

야구 배트와 공이 합쳐서 1,100원이다. 배트는 공보다 1,000원 비싸다. 공은 얼마인가?

많은 사람이 직관적으로 "100원!"이라 답하지만, 정답은 50원입니다. (공 50 + 배트 1,050 = 1,100, 차이 1,000 ✓)

cases = [
    ("배트와 공이 합쳐서 1,100원. 배트는 공보다 1,000원 비싸다. 공은?", "50"),
    ("5대 기계가 5개를 5분에 만든다. 100대가 100개를 만드는 데 몇 분?", "5"),  # 정답 5분
]

for q, gold in cases:
    d_txt, _ = ask_direct(q)
    c_txt, _ = ask_cot(q)
    print(f"Q: {q}")
    print(f"  정답: {gold} / 직접: {d_txt[:20]} / CoT 마지막줄: {c_txt.splitlines()[-1]}")

이런 문제는 CoT를 써도, 모델이 직관적인(틀린) 중간 단계를 밟으면 그대로 오답으로 이어질 수 있습니다. CoT가 "생각을 글로 쓴다"고 해서 그 생각이 항상 옳은 건 아니니까요.

핵심: CoT는 계산을 정리해 주지만, 추론 방향이 틀리면 정리된 오답이 나옵니다. 이런 문제엔 검산(03번)이나 다른 접근이 더 필요합니다.

4. 토큰 총량 비교

# (전체 케이스의 토큰을 합산)
print(f"총 토큰 — 직접: {direct_tok_sum} / CoT: {cot_tok_sum} "
      f"(CoT가 {cot_tok_sum - direct_tok_sum}토큰 더 사용)")

예상 출력

총 토큰 — 직접: 60 / CoT: 320 (CoT가 260토큰 더 사용)

CoT는 정확도를 위해 토큰을 몇 배 더 씁니다. 대량 처리(수만 건)에서는 이 차이가 비용으로 직결됩니다.

5. 그래서, 언제 CoT를 쓰나

상황 CoT? 이유
다단계 계산·논리 ✅ 켠다 정답률 크게 향상
단순 사실·상식·룩업 ❌ 끈다 추론 불필요, 토큰 낭비
지연·비용 민감한 대량 처리 ⚠️ 신중 토큰이 몇 배로 늘어남
함정·역설 문제 ⚠️ 검산 병행 CoT도 틀릴 수 있음

정리하면: CoT는 "다단계 계산·논리"일 때만 켜는 것이 비용 대비 효과가 큽니다. 무조건 켜는 게 아니라, 문제의 성격을 보고 켜고 끄는 판단이 중요합니다.

핵심 정리

  • CoT는 만능이 아니다 — 단순 질문엔 토큰 낭비, 함정 문제엔 오답 위험.
  • 단순 질문은 직접 답변이 빠르고 싸다.
  • 함정 문제는 CoT + 검산을 병행한다.
  • CoT는 다단계 계산·논리일 때만 켜는 것이 비용 대비 효과적이다.
