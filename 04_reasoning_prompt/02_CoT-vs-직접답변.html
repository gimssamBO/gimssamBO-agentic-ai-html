CoT vs 직접 답변

한 줄 요약

직접 답변은 중간 과정 없이 답만, CoT는 풀이를 한 줄씩 쓴 뒤 답을 냅니다. CoT는 토큰을 더 쓰지만 계산·다단계 문제의 정답률이 훨씬 높습니다.

1. 두 방식 비교표

구분 직접 답변 Chain-of-Thought
프롬프트 "답(숫자)만 말해" "단계적으로 풀이를 쓴 뒤 마지막에 답해"
토큰/속도 적음 / 빠름 많음 / 느림
정답률 낮음(특히 계산·다단계) 높음
쓰는 곳 단순 사실 질의 계산·추론·다단계 판단

핵심 트레이드오프는 "비용·속도 ↔ 정확도" 입니다. CoT는 풀이를 쓰느라 토큰(=비용)과 시간을 더 쓰지만, 그 대가로 정확도를 얻습니다.

2. 직접 답변 함수

중간 과정을 막고 최종 숫자만 시킵니다.

OpenAI

from common import get_openai_client, OPENAI_MODEL

client = get_openai_client()

def ask_direct(question: str) -> str:
    """직접 답변: 중간 과정 없이 최종 숫자만 시킨다 → 다단계 계산에서 자주 틀림."""
    resp = client.chat.completions.create(
        model=OPENAI_MODEL,
        messages=[
            {"role": "user", "content": f"{question}\n설명 없이 최종 숫자(원)만 답하라."}
        ],
        temperature=0,
    )
    return resp.choices[0].message.content

Gemini

from common import get_genai_client, GEMINI_MODEL
from google.genai import types

client = get_genai_client()

def ask_direct(question: str) -> str:
    """직접 답변: 중간 과정 없이 최종 숫자만 시킨다 → 다단계 계산에서 자주 틀림."""
    resp = client.models.generate_content(
        model=GEMINI_MODEL,
        contents=f"{question}\n설명 없이 최종 숫자(원)만 답하라.",
        config=types.GenerateContentConfig(temperature=0),
    )
    return resp.text

"설명 없이 최종 숫자만" 이라는 지시가 모델의 손발을 묶습니다. 작업 공간이 없으니 찍을 수밖에요.

3. CoT 함수

반대로 한 줄씩 풀이를 쓰게 하고, 마지막 줄에 정답 형식을 정해 줍니다.

OpenAI

def ask_cot(question: str) -> str:
    """CoT: 한 줄씩 풀이를 쓰게 한다.

    [왜] 모델은 앞서 쓴 자기 출력을 다시 입력으로 참고한다. 풀이를 글로 쓰게 하면
    그 풀이가 다음 토큰 생성의 '작업 공간(근거)'이 되어 마지막 답이 정확해진다.
    """
    resp = client.chat.completions.create(
        model=OPENAI_MODEL,
        messages=[
            {
                "role": "user",
                "content": (
                    f"{question}\n"
                    "단계적으로 풀어라. 각 계산을 한 줄씩 쓰고, "
                    "맨 마지막 줄에 '정답: <숫자>' 형식으로 답하라."
                ),
            }
        ],
        temperature=0,
    )
    return resp.choices[0].message.content

Geimini

def ask_cot(question: str) -> str:
    """CoT: 한 줄씩 풀이를 쓰게 한다.

    [왜] 모델은 앞서 쓴 자기 출력을 다시 입력으로 참고한다. 풀이를 글로 쓰게 하면
    그 풀이가 다음 토큰 생성의 '작업 공간(근거)'이 되어 마지막 답이 정확해진다.
    """
    resp = client.models.generate_content(
        model=GEMINI_MODEL,
        contents=(
            f"{question}\n"
            "단계적으로 풀어라. 각 계산을 한 줄씩 쓰고, "
            "맨 마지막 줄에 '정답: <숫자>' 형식으로 답하라."
        ),
        config=types.GenerateContentConfig(temperature=0),
    )
    return resp.text

두 가지 장치가 있습니다.

  • "단계적으로 풀어라": 작업 공간(풀이)을 만들게 한다.
  • "마지막 줄에 '정답: <숫자>' 형식": 답을 일정한 위치·형식으로 고정해 추출하기 쉽게 한다.

4. 답에서 숫자만 뽑아내기

CoT 답변은 풀이가 길어서, 그 안에서 최종 숫자를 뽑아야 채점할 수 있습니다. 정규식으로 "마지막 숫자"를 정답으로 봅니다.

import re

def extract_number(text: str):
    """답변에서 마지막 숫자를 정수로 반환(콤마 제거)."""
    nums = re.findall(r"-?\d[\d,]*", text.replace(" ", ""))
    if not nums:
        return None
    return int(nums[-1].replace(",", ""))

re.findall로 모든 숫자를 찾고, 마지막 것(nums[-1])을 답으로 씁니다. "정답: 213300"이 맨 끝에 오게 프롬프트로 유도했기 때문이죠.

1,000 같은 콤마는 .replace(",", "")로 제거해 int()로 변환합니다.

5. 한 문제로 차이 보기

q = "이어버드를 79000원에 3개 샀는데 10% 쿠폰을 받았습니다. 총 결제액은?"
print("[직접] ", ask_direct(q))
print("[CoT]\n", ask_cot(q))

예상 출력

[직접]  213000        ← 한 번에 답 → 틀림

[CoT]
1) 상품 합계: 79000 × 3 = 237000
2) 쿠폰 할인: 237000 × 10% = 23700
3) 결제액: 237000 - 23700 = 213300
정답: 213300         ← 단계를 거쳐 정확

같은 모델, 같은 문제인데 프롬프트 한 줄 차이로 정답이 갈렸습니다. 다음 절(자기검증) 후, 04번에서 8문제 전체 정답률을 비교합니다.

핵심 정리

  • 직접 답변 = 빠르지만 다단계 계산에 약함. CoT = 느리지만 정확.
  • CoT 프롬프트는 "단계적으로 풀어라" + "마지막 줄에 정답 형식" 으로 구성한다.
  • extract_number로 풀이 속 마지막 숫자를 정답으로 뽑는다.
  • 다음 절에서는 답을 한 번 더 확인하는 자기검증(검산) 을 배웁니다.
