따라하기 — CoT 정답률 비교

목표

쇼핑 계산 문제 8개를 직접 답변과 CoT 두 방식으로 풀어, 정답률을 숫자로 비교합니다. "단계적으로 풀어라" 한 줄의 효과를 눈으로 확인합니다. 실제 파일은 code/ch04_cot.py 입니다.

import sys, pathlib, re
sys.path.append(str(pathlib.Path(__file__).resolve().parent))
from common import get_openai_client, OPENAI_MODEL, DATA
import pandas as pd

client = get_openai_client()
# math_word_problems.csv = 쇼핑 계산 문제 8개. answer 컬럼이 정수 정답.
df = pd.read_csv(DATA / "math_word_problems.csv")
print("문제 수:", len(df))
print(df.iloc[0]["question"], "→ 정답:", df.iloc[0]["answer"])


def extract_number(text: str):
    """답변에서 마지막 숫자를 정수로 반환(콤마 제거)."""
    nums = re.findall(r"-?\d[\d,]*", text.replace(" ", ""))
    return int(nums[-1].replace(",", "")) if nums else None

def ask_direct(question: str) -> str:
    resp = client.chat.completions.create(
        model=OPENAI_MODEL,
        messages=[
            {"role": "user", "content": f"{question}\n설명 없이 최종 숫자(원)만 답하라."}
        ],
        temperature=0,
    )
    return resp.choices[0].message.content

def ask_cot(question: str) -> str:
    resp = client.chat.completions.create(
        model=OPENAI_MODEL,
        messages=[
            {
                "role": "user",
                "content": (
                    f"{question}\n단계적으로 풀어라. 각 계산을 한 줄씩 쓰고, "
                    "맨 마지막 줄에 '정답: <숫자>' 형식으로 답하라."
                ),
            }
        ],
        temperature=0,
    )
    return resp.choices[0].message.content

direct_ok = cot_ok = 0
for _, row in df.iterrows():
    ans = int(row["answer"])
    d = extract_number(ask_direct(row["question"]))   # 직접 답변의 숫자
    c = extract_number(ask_cot(row["question"]))      # CoT 답변의 숫자
    direct_ok += (d == ans)     # bool(True/False)은 1/0으로 더해진다
    cot_ok += (c == ans)
    print(f"{row['problem_id']} 정답={ans:>7} | 직접={d} {'O' if d==ans else 'X'}"
          f" | CoT={c} {'O' if c==ans else 'X'}")

n = len(df)
print(f"\n직접 답변 정답률 : {direct_ok}/{n} = {direct_ok/n:.0%}")
print(f"CoT  정답률      : {cot_ok}/{n} = {cot_ok/n:.0%}")

def extract_number(text: str):
    """답변에서 마지막 숫자를 정수로 반환(콤마 제거)."""

def ask_direct(question: str) -> str:

    return resp.text

                  "맨 마지막 줄에 '정답: <숫자>' 형식으로 답하라."),
        config=types.GenerateContentConfig(temperature=0),
    )
    return resp.text

3. 8문제 전체 정답률 비교

이게 이 강의 핵심 실험입니다. 8문제를 두 방식으로 풀고, 정답(answer)과 비교해 각각 몇 개 맞혔는지 셉니다.

direct_ok = cot_ok = 0
for _, row in df.iterrows():
    ans = int(row["answer"])
    d = extract_number(ask_direct(row["question"]))   # 직접 답변의 숫자
    c = extract_number(ask_cot(row["question"]))      # CoT 답변의 숫자
    direct_ok += (d == ans)     # bool(True/False)은 1/0으로 더해진다
    cot_ok += (c == ans)
    print(f"{row['problem_id']} 정답={ans:>7} | 직접={d} {'O' if d==ans else 'X'}"
          f" | CoT={c} {'O' if c==ans else 'X'}")

n = len(df)
print(f"\n직접 답변 정답률 : {direct_ok}/{n} = {direct_ok/n:.0%}")
print(f"CoT  정답률      : {cot_ok}/{n} = {cot_ok/n:.0%}")

예상 출력

M01 정답= 213300 | 직접=213000 X | CoT=213300 O
M02 정답= 386650 | 직접=386650 O | CoT=386650 O
M03 정답=  45000 | 직접=44000 X | CoT=45000 O
...
직접 답변 정답률 : 5/8 = 63%
CoT  정답률      : 8/8 = 100%

파이썬 팁: direct_ok += (d == ans) 에서 (d == ans)는 True/False인데, 파이썬은 이를 1/0으로 취급해 더합니다. 그래서 "맞은 개수"가 자동으로 쌓입니다.

4. 결과 해석

같은 모델, 같은 문제인데 프롬프트 한 줄("단계적으로 풀어라") 로 정답률이 63% → 100% 로 뛰었습니다.

  • 직접 답변이 틀린 문제(M01, M03 …)는 모두 다단계 계산입니다.
  • M02처럼 단순한 건 직접 답변도 맞힙니다.

즉, 계산 단계가 많을수록 CoT의 우위가 뚜렷합니다. (모델 버전에 따라 수치는 달라질 수 있지만 경향은 동일합니다.)

핵심 정리

  • 8문제 비교로 CoT가 직접 답변보다 정답률이 크게 높음을 확인했다(예: 63% → 100%).
  • (예측 == 정답)을 더해 맞은 개수를 세는 패턴을 익혔다.
  • CoT의 우위는 다단계 계산에서 특히 뚜렷하다.
  • 다음 절에서는 답에 검산을 더해 신뢰도를 높입니다.
