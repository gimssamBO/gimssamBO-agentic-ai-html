문제 1 — CoT 문구 효과 A/B 측정

ask_cot()를 복제해 ask_nostep()을 만들되, 프롬프트에서 "단계적으로 풀어라" 문구만 제거하세요(나머지 형식은 동일). 같은 8문제에 두 함수를 적용해 각각의 정답 개수를 출력하세요.

  • 사용 파일: data/math_word_problems.csv
  • 기대 결과: CoT 정답률: x/8 | 단계제거 정답률: y/8 형태로 두 수치가 나와 "단계적으로" 한 줄의 효과를 비교할 수 있으면 성공.
해답 보기 
import sys, pathlib, re
sys.path.append(str(pathlib.Path(__file__).resolve().parent))
from common import get_genai_client, GEMINI_MODEL, DATA
from google.genai import types
import pandas as pd

client = get_genai_client()
df = pd.read_csv(DATA / "math_word_problems.csv")

def extract_number(text):
    nums = re.findall(r"-?\d[\d,]*", text.replace(" ", ""))
    return int(nums[-1].replace(",", "")) if nums else None

def ask_cot(q):
    r = client.models.generate_content(
        model=GEMINI_MODEL,
        contents=f"{q}\n단계적으로 풀어라. 각 계산을 한 줄씩 쓰고, 맨 마지막 줄에 '정답: <숫자>'.",
        config=types.GenerateContentConfig(temperature=0))
    return r.text

def ask_nostep(q):   # "단계적으로 풀어라" 문구만 제거 (형식은 동일)
    r = client.models.generate_content(
        model=GEMINI_MODEL,
        contents=f"{q}\n각 계산을 한 줄씩 쓰고, 맨 마지막 줄에 '정답: <숫자>'.",
        config=types.GenerateContentConfig(temperature=0))
    return r.text

cot_ok = nostep_ok = 0
for _, row in df.iterrows():
    ans = int(row["answer"])
    cot_ok    += (extract_number(ask_cot(row["question"]))    == ans)
    nostep_ok += (extract_number(ask_nostep(row["question"])) == ans)

n = len(df)
print(f"CoT 정답률: {cot_ok}/{n} | 단계제거 정답률: {nostep_ok}/{n}")
**예상 출력** 
CoT 정답률: 8/8 | 단계제거 정답률: 6/8
**해설**: 형식("한 줄씩, 마지막에 정답")은 똑같이 두고 **"단계적으로 풀어라"** 라는 지시어만 뺐는데 정답률이 떨어집니다. 이 한 문구가 모델에게 "차근차근 추론하라"는 신호를 준다는 걸 보여 줍니다. (이런 식으로 프롬프트의 한 요소만 바꿔 효과를 재는 것을 A/B 테스트라고 합니다.)

문제 2 — self-consistency 다중 풀이

한 문제를 ask_cot()로 3번 호출하고, 각 답의 숫자를 모아 collections.Counter로 최빈값(다수결 답) 을 출력하는 함수 self_consistency(question, n=3)를 작성하세요.

  • 답을 다양하게 얻으려면 temperature를 약간 높입니다(예: 0.7).
  • 사용 파일: data/math_word_problems.csv
  • 기대 결과: 3개의 개별 답과 최종 다수결 답이 출력되고, 정답과 일치하면 성공.
해답 보기 
import sys, pathlib, re
from collections import Counter
sys.path.append(str(pathlib.Path(__file__).resolve().parent))
from common import get_genai_client, GEMINI_MODEL, DATA
from google.genai import types
import pandas as pd

client = get_genai_client()
df = pd.read_csv(DATA / "math_word_problems.csv")

def extract_number(text):
    nums = re.findall(r"-?\d[\d,]*", text.replace(" ", ""))
    return int(nums[-1].replace(",", "")) if nums else None

def self_consistency(question: str, n: int = 3):
    """같은 문제를 n번 풀어 가장 많이 나온 답(다수결)을 채택한다."""
    answers = []
    for _ in range(n):
        r = client.models.generate_content(
            model=GEMINI_MODEL,
            contents=f"{question}\n단계적으로 풀고 마지막 줄에 '정답: <숫자>'.",
            config=types.GenerateContentConfig(temperature=0.7),  # 다양성 위해 약간 높임
        )
        answers.append(extract_number(r.text))
    print("개별 답:", answers)
    winner = Counter(answers).most_common(1)[0][0]   # 최빈값
    print("다수결 답:", winner)
    return winner

if __name__ == "__main__":
    row = df.iloc[0]
    result = self_consistency(row["question"], n=3)
    print("실제 정답:", int(row["answer"]), "→", "맞음" if result == int(row["answer"]) else "틀림")
**예상 출력** 
개별 답: [213300, 213300, 213000]
다수결 답: 213300
실제 정답: 213300 → 맞음
**해설**: 세 번 풀어 `[213300, 213300, 213000]`이 나왔는데, 다수결로 `213300`을 채택해 정답을 맞혔습니다. 한 번의 풀이가 우연히 틀려도, **여러 번 풀어 가장 많이 나온 답**을 고르면 더 안정적입니다. 이게 self-consistency의 핵심입니다. (대신 호출을 n배 하므로 비용도 n배입니다.)

정리

  • 문제 1로 "단계적으로" 문구 하나의 효과를 A/B로 측정했습니다.
  • 문제 2로 여러 번 풀고 다수결을 취하는 self-consistency를 구현했습니다.
