1. 검산 함수 (03번 복습)

CoT로 푼 답을 모델에게 다시 검토시킵니다.

OpenAI

from common import get_openai_client, OPENAI_MODEL

client = get_openai_client()

def verify(question: str, cot_answer: str) -> str:
    """제출한 풀이를 모델에게 다시 검산시켜 신뢰도를 높인다."""
    resp = client.chat.completions.create(
        model=OPENAI_MODEL,
        messages=[
            {
                "role": "user",
                "content": (
                    f"[문제] {question}\n[제출한 풀이]\n{cot_answer}\n\n"
                    "위 풀이가 맞는지 다시 계산해 검산하라. "
                    "틀렸다면 올바른 값을, 맞다면 그대로 '정답: <숫자>'로 확정하라."
                ),
            }
        ],
        temperature=0,
    )
    return resp.choices[0].message.content

Gemini

from common import get_genai_client, GEMINI_MODEL
from google.genai import types

client = get_genai_client()

def verify(question: str, cot_answer: str) -> str:
    """제출한 풀이를 모델에게 다시 검산시켜 신뢰도를 높인다."""
    resp = client.models.generate_content(
        model=GEMINI_MODEL,
        contents=(
            f"[문제] {question}\n[제출한 풀이]\n{cot_answer}\n\n"
            "위 풀이가 맞는지 다시 계산해 검산하라. "
            "틀렸다면 올바른 값을, 맞다면 그대로 '정답: <숫자>'로 확정하라."
        ),
        config=types.GenerateContentConfig(temperature=0),
    )
    return resp.text

2. "풀이 → 검산" 2단계 실행

import pandas as pd
df = pd.read_csv(DATA / "math_word_problems.csv")

q = df.iloc[0]["question"]

# 1단계: CoT로 푼다
first = ask_cot(q)
print("[1차 풀이]\n", first)

# 2단계: 그 풀이를 검산한다
print("\n[검산 결과]\n", verify(q, first))

예상 출력

[1차 풀이]
1) 79000 × 3 = 237000
2) 237000 × 10% = 23700
3) 237000 - 23700 = 213300
정답: 213300

[검산 결과]
제출한 풀이를 검토합니다.
79000 × 3 = 237000 ✓
237000 × 0.1 = 23700 ✓
237000 - 23700 = 213300 ✓
정답: 213300

검산을 거쳐 답이 확정되었습니다. 1차 풀이에 오류가 있었다면 여기서 바로잡혔겠죠.

3. 검산이 오류를 잡는 예 (개념)

만약 1차 풀이가 틀렸다고 가정해 봅시다.

wrong_solution = """1) 79000 × 3 = 237000
2) 237000 × 10% = 23700
3) 237000 - 23700 = 213000   ← 계산 실수!
정답: 213000"""

print(verify(q, wrong_solution))

예상 출력

검토 결과, 3단계에 오류가 있습니다.
237000 - 23700 = 213300 이어야 합니다.
정답: 213300   ← 검산이 실수를 바로잡음

검산 단계가 틀린 답을 고쳐 줬습니다. 이것이 자기검증의 가치입니다.

4. 비용을 고려한 사용 전략

검산은 호출을 한 번 더 하므로 토큰(비용)이 약 2배입니다. 그래서 모든 질문에 쓰지 않고, 전략적으로 씁니다.

def answer_with_optional_verify(question: str, critical: bool) -> str:
    """critical=True(돈·재고 등 민감)일 때만 검산을 추가한다."""
    first = ask_cot(question)
    if critical:
        return verify(question, first)   # 민감한 계산 → 검산
    return first                          # 일반 질문 → 그대로

"이 계산이 틀리면 큰일 나는가?"를 기준으로 critical을 정하면 됩니다. 환불액·발주량 같은 건 True, 단순 안내는 False.

핵심 정리

  • "CoT 풀이 → 검산"의 2단계로 답을 확정한다.
  • 검산은 1차 풀이의 계산 실수를 잡아낸다.
  • 비용이 2배이므로 민감한 계산에만 선택적으로 적용한다.
  • 다음 절에서는 CoT가 오히려 손해인 경우를 살펴봅니다.
