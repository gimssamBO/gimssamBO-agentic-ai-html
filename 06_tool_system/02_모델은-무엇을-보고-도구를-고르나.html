모델은 무엇을 보고 도구를 고르나

한 줄 요약

모델은 함수 본문을 보지 못합니다. 오직 함수 이름 + 인자 + 독스트링(설명) 만 봅니다. 이 셋과 사용자 질문을 비교해 가장 잘 맞는 도구를 고릅니다. 그래서 독스트링이 곧 도구 선택의 정확도입니다.

1. 모델이 보는 것 vs 못 보는 것

5강에서 배웠듯, 모델은 함수의 코드(본문) 를 절대 못 봅니다. 모델이 보는 건 이것뿐입니다.

함수 이름     : get_price
인자          : product_name (문자열)
독스트링(설명): "상품명을 받아 판매가(원)를 반환한다. 가격/얼마 질문에 사용."

함수 안에서 products.csv를 읽든 뭘 하든, 모델은 모릅니다. 이름·인자·설명, 이 세 가지가 모델이 가진 정보의 전부입니다.

2. 도구 선택은 '매칭'이다

모델은 사용자 질문과 각 도구의 (이름+인자+설명) 을 비교해, 가장 잘 맞는 걸 고릅니다. "청바지 얼마야?"라는 질문이 오면 이런 일이 일어납니다.

질문 "슬림핏 청바지 얼마야?" 를 각 도구 설명과 견줘 봅니다.

도구(설명) 질문과의 매칭
get_stock (재고 수량 반환) '얼마'와 안 맞음 ✗
get_price (판매가 반환, 얼마 질문) '얼마 = 가격' 딱 맞음 ✓ 선택!
get_order_status (주문 배송 상태) 주문번호 없음 ✗
search_product (키워드로 상품 검색) 특정 상품이 지목됨 ✗

get_price의 독스트링에 "가격/얼마 질문에 사용" 이라고 적어 둔 게 결정적이었습니다. 질문의 "얼마"와 설명의 "얼마"가 매칭된 거죠.

비유: 모델은 도서관 사서입니다. 책 내용(함수 본문)은 안 읽었지만, 책 제목과 요약(이름·설명) 을 보고 "이 질문엔 이 책!"을 골라 줍니다. 그래서 요약을 잘 써 두는 게 중요합니다.

3. 코드로 도구 선택 들여다보기

5강의 which_tool처럼, 자동 실행을 끄고 모델이 무엇을 골랐는지 봅니다.

from common import get_genai_client, GEMINI_MODEL
from google.genai import types

client = get_genai_client()
TOOLS = [get_price, get_stock, get_order_status, search_product]

def which_tool(question: str):
    """자동 호출을 끄고 모델이 '어떤 도구를 고를지'만 출력한다."""
    resp = client.models.generate_content(
        model=GEMINI_MODEL,
        contents=question,
        config=types.GenerateContentConfig(
            tools=TOOLS,
            automatic_function_calling=types.AutomaticFunctionCallingConfig(disable=True),
            temperature=0,
        ),
    )
    for fc in (resp.function_calls or []):
        print(f"  '{question}' → {fc.name}({dict(fc.args)})")

which_tool("슬림핏 청바지 얼마야?")
which_tool("이어버드 재고 있어?")

예상 출력

  '슬림핏 청바지 얼마야?' → get_price({'product_name': '슬림핏 청바지'})
  '이어버드 재고 있어?' → get_stock({'product_name': '이어버드'})

모델이 질문에 딱 맞는 도구를, 인자까지 정확히 채워 골랐습니다.

4. 좋은 독스트링의 두 가지 조건

매칭이 잘 되려면 독스트링이 두 가지를 담아야 합니다.

  1. 무엇을 하는가: "상품명을 받아 판매가(원)를 반환한다"
  2. 언제 쓰는가: "가격/얼마 질문에 사용"

특히 2번("언제 쓰는가")이 도구 선택에 큰 도움이 됩니다. 모델이 "이 질문이 이 도구를 써야 하는 상황인가?"를 판단하는 힌트가 되니까요.

def get_stock(product_name: str) -> str:

    # 독스트링 = '무엇을 하는가'(상품명→재고) + '언제 쓰는가'(재고/품절 질문)
    ...

핵심 정리

  • 모델은 함수 본문을 못 보고, 이름 + 인자 + 독스트링만 본다.
  • 도구 선택 = 질문과 도구 설명의 매칭.
  • 좋은 독스트링은 "무엇을 하는가" + "언제 쓰는가" 를 담는다.
  • which_tool로 모델의 선택을 직접 관찰할 수 있다.
