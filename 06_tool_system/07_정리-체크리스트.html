정리 & 체크리스트

6강에서 배운 것

6강에서는 도구가 여러 개일 때 모델이 올바른 도구를 고르게 만드는 법을 배웠습니다.

  • 도구 선택 문제: 도구가 많아지면 "어떤 도구를 쓸지" 고르는 게 과제가 된다.
  • 모델이 보는 것: 함수 본문이 아니라 이름 + 인자 + 독스트링.
  • 5가지 설계 원칙: 한 가지 일·이름이 곧 기능·명확한 인자·구체적 설명·일관된 반환.
  • 독스트링의 힘: 망가뜨리면 선택이 흔들린다 → "독스트링 = 도구 성능".
  • 비슷한 도구 구분: 입력 형태·결과 건수·부정 조건을 명시해 경계를 못 박는다.

한눈에 보는 핵심 코드

from common import get_genai_client, GEMINI_MODEL
from google.genai import types
client = get_genai_client()

# 설계 원칙을 지킨 도구 — "무엇을 + 언제"를 독스트링에
def get_price(product_name: str) -> str:
    """상품명을 받아 판매가(원)를 반환한다. 가격/얼마 질문에 사용."""
    ...

TOOLS = [get_price, get_stock, get_order_status, search_product]

# 자동: 모델이 알아서 고름
resp = client.models.generate_content(
    model=GEMINI_MODEL, contents="청바지 얼마야?",
    config=types.GenerateContentConfig(tools=TOOLS, temperature=0))

# 선택 관찰: 자동을 끄고 function_calls 확인
def which_tool(q):
    r = client.models.generate_content(
        model=GEMINI_MODEL, contents=q,
        config=types.GenerateContentConfig(
            tools=TOOLS,
            automatic_function_calling=types.AutomaticFunctionCallingConfig(disable=True),
            temperature=0))
    for fc in (r.function_calls or []):
        print(fc.name, dict(fc.args))

체크리스트

  • [ ] 모델이 (이름+인자+설명)만 보고 도구를 고른다는 것을 안다.
  • [ ] 도구 4개를 등록해 질문별로 다른 도구가 선택되는 것을 확인했다.
  • [ ] 좋은 도구 설계 5원칙을 적용했다.
  • [ ] 독스트링을 망가뜨리면 선택이 흔들린다는 것을 실험했다.
  • [ ] 비슷한 도구를 입력 형태·결과 건수·부정 조건으로 구분할 수 있다.

한 줄 핵심

"도구 설명은 모델을 위한 프롬프트다." 좋은 독스트링이 곧 정확한 도구 선택이고, 그게 곧 에이전트의 품질이다.
