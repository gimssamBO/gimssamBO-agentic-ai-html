방금 말한 걸 또 묻는 봇

한 줄 요약

지금까지 만든 에이전트는 대화를 기억하지 못합니다. "내 이름은 민준이야" 다음에 "내 이름 뭐랬지?"라고 물으면 "모르겠어요"라고 답하죠. 원인은 LLM이 stateless(무상태) 라서입니다. 이 강에서 단기 기억을 붙입니다.

1. 금붕어 같은 봇

지금까지의 에이전트로 이런 대화를 해 보면 문제가 드러납니다.

사용자: 내 이름은 민준이야.
봇:    네, 민준님 반갑습니다!
사용자: 내 이름 뭐랬지?
봇:    죄송하지만 성함을 알려주지 않으셨어요.   ← 방금 들었는데 잊어버림!

방금 "민준"이라고 말했는데, 다음 질문에서 까먹습니다. 마치 금붕어처럼 3초 전을 기억 못 하죠. 이래선 상담봇으로 쓸 수 없습니다. "방금 말한 주문번호로 환불해줘"라고 하면 "어떤 주문번호요?"라고 되묻을 테니까요.

2. 왜 기억을 못 하나

원인은 단순합니다. LLM API는 상태를 저장하지 않습니다(stateless). 매 호출은 완전히 백지에서 시작합니다.

호출 1: "내 이름은 민준이야" → "반갑습니다"  (호출 끝, 다 잊음)
호출 2: "내 이름 뭐랬지?"    → "모르겠어요"  (백지에서 시작, 호출 1을 모름)

호출 2는 호출 1을 전혀 모릅니다. 각 호출이 독립적이거든요. 백엔드 개발자라면 익숙할 겁니다 — 세션이 없는 순수 함수(stateless HTTP) 와 같죠. 이전 요청을 기억하지 못합니다.

비유: 매번 기억이 지워지는 영화 주인공 같습니다(메멘토). 방금 만난 사람도 다음 순간 처음 보는 사람이 되죠. 그래서 매번 "저는 누구입니다"를 다시 말해 줘야 합니다.

3. ChatGPT는 어떻게 기억하는가

"ChatGPT는 대화를 기억하잖아?"라고 생각할 수 있습니다. 사실 ChatGPT도 LLM 자체는 기억 못 합니다. 비결은 따로 있습니다.

ChatGPT 내부에서는, 호출 2 때 지금까지의 모든 대화를 매번 다시 보냅니다.

호출 2 입력 = ["내 이름은 민준", "반갑습니다", "내 이름 뭐랬지?"]

ChatGPT는 지금까지의 대화 전체를 매번 다시 전송합니다. 모델이 기억하는 게 아니라, 애플리케이션이 대화 기록을 들고 있다가 매 호출에 끼워 넣는 거죠. 그래서 기억하는 "것처럼" 보입니다.

4. 해법 — 대화를 누적해 주입

기억을 만들려면 우리가 직접 이전 대화를 매번 다시 실어 보내야 합니다.

  • 기억 없음: 호출2 = ["내 이름 뭐랬지?"] → 모름
  • 기억 있음: 호출2 = ["내 이름은 민준", "반갑습니다", "내 이름 뭐랬지?"] → "민준님!" (이전 대화를 누적해 함께 보냄)

직접 구현하면 "메시지 리스트를 매번 append 해서 보내는" 코드가 됩니다. 번거롭죠. LangGraph의 InMemorySaver가 이 누적·저장·재주입을 자동화해 줍니다. 우리는 그냥 thread_id만 넘기면 되죠.
